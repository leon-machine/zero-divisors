# v1.0.0 (2026-11-22)

The first archived release of the Physics Graph of the Transport Papers (T0 to T17 and the companion notes T0a and T14a to T14c). Each result is held once, with its statement, proof, premises and exact machine check. The site at https://zerodivisors.org presents the graph, and an AI agent can read it through the MCP server; corrections and new results come in as pull requests, under the rules in CONTRIBUTING.md.

Contributions: every person credited in a pull request gives an ORCID iD, and the public ORCID record of the person who opens it must list their GitHub account; work done by an AI alone is credited to the model and to the person who submits it. A pull request may change results only: a guard check, run from main so that a pull request cannot alter it, refuses changes to the toolkit, the checks or the rules. Every pull request runs the full validation, with each contributed check in a sealed container with no network; results unchanged since the last run on main are reused, and only new or changed results are mutation-tested. Accepted contributors are listed on this record from the next release.

Coming soon: expert reviews. Qualified physicists and mathematicians will be able to endorse or object to individual results under their own name, each review signed through ORCID; the records and their checks are in this release, and the sign-in service will follow.

The first release of the Physics Graph: 2452 results, 1094 of them with proofs, each with its premises, evidence and credit.
