By (L$_E$, \claimref{state-selection.l-ledger-locality}) the generators are polynomials in the commuting $\sigma_k = 2N_k - 1$, which are simultaneously diagonal in the joint number basis; a polynomial in commuting diagonal operators is diagonal, and its exponential is a diagonal unitary. A diagonal unitary multiplies each joint-number amplitude by a phase, leaving every joint-number probability unchanged, hence leaving every marginal population unchanged. Combined with Theorem \claimref{state-selection.ascended-marginals-are-diagonal}, which pins the off-diagonal entries to zero, the marginal $\rho_k$ is constant in time.
