The $\sigma_k = 2N_k - 1$ commute and are simultaneously diagonal in the joint number basis; a polynomial in commuting diagonal operators is diagonal and its exponential is a diagonal unitary, which multiplies each joint-number amplitude by a phase and so leaves every joint-number probability, hence every marginal population, unchanged. With Theorem \claimref{singularity.ascended-marginals-are-diagonal} fixing the off-diagonal entries at zero, each $\varrho_k$ is constant in time. The script verifies the invariance for a controlled-$Z$ circuit on the model's mode space and exhibits an orthogonal, parity-preserving hopping rotation that does change the marginal populations, which is exactly the generator (L$_E$, \claimref{singularity.l-boundary-mode-locality}) excludes.
