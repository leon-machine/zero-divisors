## formal
On $S(v)$ define $\sigma \sim \sigma'$ iff $\sigma - \sigma' \in v\,\Cl(\mathbb{V}')$, the left ideal generated by $v$. Then:
\begin{enumerate}
\item Each class contains a unique representative of the form $w_0 + \alpha$ with $\alpha \in \Cl(U')$, so the quotient $T(v) := S(v)/\!\sim$ is an affine space with translation space $\Cl(U')$, via $[w_0 + \alpha] + \xi = [w_0 + \alpha + \xi]$.
\item $N_v$ preserves $S(v)$ and the equivalence, hence acts on $T(v)$; the action is by translations along the grade-one subspace $U \subseteq \Cl(U')$:
\[
R_u \cdot [\,w_0 + \alpha\,] \;=\; [\,w_0 + \alpha - u\,].
\]
\item The $N_v$-orbit of any class is a torsor under $(U, +)$, and its translation cocycle, with respect to any base point, is the tautological homomorphism $\theta : N_v \to U$, $\theta(R_u) = u$.
\end{enumerate}

## technical
Let $S(v)$ be the set of pseudo-inverses of a null vector $v$ in $\Cl(\mathbb{V}')$, and set $\sigma \sim \sigma'$ when $\sigma - \sigma'$ lies in the left ideal $v\,\Cl(\mathbb{V}')$. Each class has a unique representative $w_0 + \alpha$ with $\alpha \in \Cl(U')$, so $T(v) = S(v)/{\sim}$ is an affine space with translation space $\Cl(U')$. The null rotations act on $T(v)$ by translation along the grade-one subspace $U$: $R_u \cdot [w_0 + \alpha] = [w_0 + \alpha - u]$.

Hence every $N_v$-orbit is a torsor under $(U, +)$, and its translation cocycle with respect to any base point is the tautological homomorphism $\theta(R_u) = u$.

## lay
A light-like direction has many partial inverses. After discarding differences that do not matter, the remaining choices form a flat space, like a plane with no chosen origin. The symmetries that fix the light-like direction slide this space along itself, so, except in the smallest case where there is no extra direction to slide along, no choice is left unmoved.

## one-liner
Modulo the left ideal of $v$, the pseudo-inverses of a null vector form an affine space on which the null rotations act by the translations $[w_0 + \alpha] \mapsto [w_0 + \alpha - u]$, a torsor with tautological cocycle $\theta$.
