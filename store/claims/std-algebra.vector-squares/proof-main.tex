The first identity is the defining relation of \claimref{obj.std-algebra.clifford-algebra}. Applying it to $u + v$: $(u + v)^{2} = u^{2} + uv + vu + v^{2}$, so $uv + vu = Q(u + v) - Q(u) - Q(v) = 2B(u, v)$ by the definition of the polar form and \claimref{std-algebra.polarisation}. The splitting is $uv = \tfrac12(uv + vu) + \tfrac12(uv - vu)$.
