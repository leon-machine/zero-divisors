The operators live in the tower's canonical anticommutation algebra; the check realises it in $\Cl(6,6)$ with six modes, $a_{m} = \tfrac12(e_{m} + f_{m})$, $a_{m}^{*} = \tfrac12(e_{m} - f_{m})$, $e_{m}^{2} = 1$, $f_{m}^{2} = -1$, so that $\{a_{m}, a_{n}^{*}\} = \delta_{mn}$ and $\{a_{m}, a_{n}\} = 0$, with the tower's grading the grade involution. Modes $3, 4, 5$ carry the pairs, which are odd as in Fact \claimref{standard-model.imported-pair-systems-two-chirality-halves}; the sixth supplies a Majorana generator $K = e_{6}$, $K^{2} = 1$.

(i) Let $c, d$ be real with $c^{2} + d^{2} = 1$ and $cd \ne 0$, and let $s' = cs_{1} + ds_{2}$, the image of $s_{1}$ under a rotation in $U(2)$. By (b) for $s_{1}, s_{2}$, $s'^{2} = cd\{s_{1}, s_{2}\}$, and (c) requires $s'^{2} = 0$, so $\{s_{1}, s_{2}\} = 0$. Likewise $\{s', s'^{*}\} = 1 + cd(\{s_{1}, s_{2}^{*}\} + \{s_{2}, s_{1}^{*}\})$, so the bracket sum vanishes; repeating with $s'' = cs_{1} + i d s_{2}$, also the image under an element of $U(2)$, gives $\{s_{2}, s_{1}^{*}\} - \{s_{1}, s_{2}^{*}\} = 0$, hence both vanish. If instead $s_{1}s_{2} = s_{2}s_{1}$ with $s_{1}s_{2} \neq 0$, then $s'^{2} = 2cd\,s_{1}s_{2} \neq 0$, and on the doubly occupied state $(cs_{1}^{*} + ds_{2}^{*})(-ds_{1}^{*} + cs_{2}^{*})\lvert 0 \rangle = (c^{2} - d^{2})s_{1}^{*}s_{2}^{*}\lvert 0 \rangle$, the permanent of the rotation, which is not multiplicative; the check realises this with $h_{1} = a_{1}$, $h_{2} = a_{2}(1 - 2n_{1})$ and $(c, d) = (\tfrac35, \tfrac45)$, permanent $-\tfrac{7}{25}$ against determinant $1$.

(ii) By (i) and (b) the slot operators generate a two-mode Fock system and the pair operators a three-mode one (Fact \claimref{standard-model.imported-pair-systems-two-chirality-halves}). By (d) each $s_{J}^{*}b_{K}^{*}\lvert 0 \rangle$ is, up to a sign, the product state with $J$ slots and $K$ pairs occupied, and moving a slot operator past a pair operator only changes signs; so the thirty-two states are independent and span $\Lambda^{\bullet}\C^{2} \otimes \Lambda^{\bullet}W$, on which $(A, B)$ acts as $\Lambda^{\bullet}A \otimes \Lambda^{\bullet}B$. By Fact \claimref{standard-model.imported-cauchy-decomposition-exterior-power} this is $\Lambda^{\bullet}(\C^{2} \oplus W)$ with $\Lambda^{\bullet}(A \oplus B)$. The check builds both parities: $s_{i} = a_{i}$ ($\pi = 1$) and $s_{i} = a_{i}K$, $s_{i}^{*} = Ka_{i}^{*}$ ($\pi = 0$), each also multiplied by $(-1)^{N_{\mathrm{pair}}}$ to realise the other mutual sign; it verifies (b), the mutual relation, the common vacuum, the rotated relations under $(\tfrac35, \tfrac45)$, the determinant law on the doubly occupied state, and rank thirty-two of the states.

(iii) The vacuum projector is even. A slot creator has parity $\pi$ and a pair creator is odd, so $s_{J}^{*}b_{K}^{*}\lvert 0 \rangle$ has parity $(-1)^{\pi j + k}$, independently of the mutual sign. This equals $(-1)^{j + k}$ on every component if and only if $\pi = 1$; for $\pi = 0$ it differs on $j = 1$. The check computes the grade involution of every state.

(iv) Writing the abelian factor as $(A, B) = (\lambda^{3}a, \lambda^{-2}b)$, $a \in SU(2)$, $b \in SU(3)$, as in Theorem \claimref{standard-model.global-form-quotient-determined}, the component $(j, k)$ carries $\Lambda^{j}\C^{2} \otimes \Lambda^{k}\C^{3}$, content $1, 2, 1$ in $j$ and $1, 3, \bar{3}, 1$ in $k$, with weight $3j - 2k$ and $Y = (3j - 2k)/6$; this uses only (ii), not Hypothesis (S). For $\pi = 0$ the even half is $(0,0) = \nu^{c}$, $(0,2) = u^{c}$, $(2,0) = e^{c}$, $(2,2) = d^{c}$, $(1,0) = (2,1)_{1/2} = \bar{L}$, $(1,2) = (2,\bar{3})_{-1/6} = \bar{Q}$. Taking it as left-handed, the conditions of Fact \claimref{standard-model.imported-anomaly-coefficients} for $Y$ are: $[SU(3)]^{2}U(1)$, $2(-\tfrac16) - \tfrac23 + \tfrac13 = -\tfrac23$; $[SU(2)]^{2}U(1)$, $3(-\tfrac16) + \tfrac12 = 0$; gravitational, $6(-\tfrac16) + 2 \cdot \tfrac12 + 3(-\tfrac23) + 3 \cdot \tfrac13 + 1 = 0$; cubic, $6(-\tfrac16)^{3} + 2(\tfrac12)^{3} + 3(-\tfrac23)^{3} + 3(\tfrac13)^{3} + 1 = \tfrac49$. The odd half is the conjugate and the sums change sign. For $\pi = 1$ the even half is $\nu^{c}, u^{c}, Q, L, e^{c}, d^{c}$ and the linear sums are $4\alpha + 6\beta + 4\gamma$ (twice) and $16\alpha + 24\beta + 16\gamma$, of rank one, vanishing at $Y$ ($\alpha = \tfrac12$, $\beta = -\tfrac13$, $\gamma = 0$), where the cubic sum also vanishes (the standard cancellation, reproduced in the check). The check computes all of these sums exactly and scans the integer generators with $|\alpha|, |\beta|, |\gamma| \le 3$. (A remark not used: the cubic colour anomaly, triplets minus antitriplets weighted by $SU(2)$ multiplicity, cited from memory as a further condition, is $0$ for $\pi = 1$ and $-4$ for $\pi = 0$, the even half holding four antitriplets and no triplet.)

(v) The model with $\pi = 0$ lives in a finite floor, so by Proposition \claimref{field-theory.no-canonical-commutation-relations-tower} it contains no pair with $[a, a^{*}] = 1$; its slot operators are tower elements, even ones, which that proposition explicitly does not exclude. (vi) Under (a) to (d) with the tower grading as chirality, (iv) shows (for slot modules beyond the two-level case the same anomaly step is treated in the result filed alongside, synthesis.anomaly-freedom-forces-slot-content) that $\pi = 0$ violates the imported conditions for $Y$; so $\pi = 1$, and by (i) to (iii) the slots are fermionic modes generating with the pairs the Fock space $\Lambda^{\bullet}(\C^{2} \oplus W)$ with $\Lambda^{\bullet}(A \oplus B)$ and chirality the parity of the total mode number, which is every clause of Hypothesis (S).
