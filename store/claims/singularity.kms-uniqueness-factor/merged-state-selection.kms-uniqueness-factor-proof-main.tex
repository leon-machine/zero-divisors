The KMS condition in finite dimensions reads $\omega(ab) = \omega\bigl(b\,\alpha_{I_4\beta}(a)\bigr) = \omega\bigl(b\,e^{-\beta K} a\, e^{\beta K}\bigr)$ for all $a, b$. Writing both sides as traces and using cyclicity, the left side is $\tr(b\rho a)$ and the right side is $\tr\bigl(e^{\beta K}\rho\, b\, e^{-\beta K} a\bigr)$, so for all $a$ and $b$,
\[
b\,\rho \;=\; e^{\beta K} \rho\, b\, e^{-\beta K},
\qquad\text{equivalently}\qquad
b\,\bigl(\rho\, e^{\beta K}\bigr) \;=\; \bigl(e^{\beta K}\rho\bigr)\, b .
\]
Taking $b = 1$ gives $\rho e^{\beta K} = e^{\beta K}\rho$, so $\rho$ commutes with $K$; the displayed identity then says that $X := \rho\,e^{\beta K}$ commutes with every $b \in \Aa$, hence lies in the centre, hence is a scalar because $\Aa$ is a factor. So $\rho = c\,e^{-\beta K}$, and normalisation fixes $c$. Conversely the Gibbs state satisfies the identity by the same computation read backwards.
