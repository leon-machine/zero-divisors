$E_k$ has range $\Aev_k$, which in the number basis is the diagonal (Theorem \claimref{state-selection.descent-parity-average}). A diagonal density matrix on a two-dimensional space is $\operatorname{diag}(p_k, 1-p_k)$, and every such matrix with $0 < p_k < 1$ is $e^{-\beta_k \omega_k N_k}/Z_k$ for the stated $\beta_k$, uniquely, since $\beta_k \mapsto (1 + e^{\beta_k\omega_k})^{-1}$ is a bijection from $\R$ onto $(0,1)$; the two boundary values are the limits $\beta_k = \pm\infty$.
