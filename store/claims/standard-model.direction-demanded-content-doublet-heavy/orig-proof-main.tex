$f = (Rb_{23} - b_{12})/(\Dl_{12} - R\Dl_{23})$ has numerator $b_{23}(R - r_{0}) < 0$, so $f > 0$ iff the denominator is negative, $\Dl_{1} - \Dl_{2} < R(\Dl_{2} - \Dl_{3})$, which rearranges to the display. Admissibility needs $f \le 1$ as well, which by Theorem \claimref{standard-model.one-threshold-exact-criterion}(iii) with $R < r_{0}$ is $r_{\Dl} \le R$. The values of $R$ and $r_{0}$ are computed exactly by the script from the inputs of Proposition \claimref{standard-model.spectrum-run}: $a_{2} = 0.2312 \times 128 = 18496/625$, $a_{1} = \tfrac35(128 - a_{2}) = 184512/3125$, $a_{3} = 500/59$.
