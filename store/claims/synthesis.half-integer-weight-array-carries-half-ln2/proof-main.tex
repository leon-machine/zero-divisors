\emph{Setting.} The array is that of Theorem \claimref{singularity.bosonisation-bridge-s-wave-sector}, with only its weights changed. By Theorem \claimref{synthesis.boundary-mode-thermal-entropy}, a mode of weight $\omega$ has entropy $s(x) = \ln(1 + e^{-x}) + x/(e^{x} + 1)$ with $x = 2\pi\omega/\kappa$, even in $x$, with $s(0) = \ln 2$. In the quasi-free state the array's state is the product of its marginals, so its entropy is the sum $S_{\delta} = \sum_{k}s(2\pi(k + \delta))$. For $\delta = \tfrac12$ the arguments are $\pm(2k + 1)\pi$, $k \geq 0$, each value twice, so $S_{1/2} = 2\sum_{k \geq 0}s((2k + 1)\pi)$; for $\delta = 0$ the argument $0$ occurs once and $\pm 2\pi k$, $k \geq 1$, twice, so $S_{0} = \ln 2 + 2\sum_{k \geq 1}s(2\pi k)$, the array sum of Theorem \claimref{synthesis.residue-from-mode-entropy}(vi). The offsets $\delta = 0$ and $\delta = \tfrac12$ are the two for which $\omega_{k_{0} - k} = -\omega_{k}$ for some integer $k_{0}$ ($k_{0} = 0$ and $k_{0} = -1$), the condition for the particle-hole map $\psi_{k} \mapsto \psi_{k_{0} - k}^{\dagger}$ to commute with the flow.

\emph{(i), (ii): rigorous bounds.} Write $u = e^{-x}$, so $s = \ln(1 + u) + xu/(1 + u)$; both terms increase with $u$, and the second increases with $x$ at fixed $u$. The script bounds $\pi$ by Machin's formula $\pi = 16\arctan\tfrac15 - 4\arctan\tfrac{1}{239}$, each arctangent bracketed by consecutive partial sums of its alternating series; bounds $e^{\pi}$ by its Taylor polynomial of degree $119$ and the remainder bound $x^{N}/N!\,(1 - x/(N + 1))^{-1}$, hence $e^{-\pi}$ and $u = e^{-n\pi}$ by powers; bounds $\ln(1 + u)$ by consecutive partial sums of its alternating series; bounds $\ln 2 = \sum_{k \geq 1}1/(k2^{k})$ with tail at most $1/((N + 1)2^{N})$; and bounds the tail of the array sum beyond $26$ terms by $s(x) \le u + xu \le (1 + x)e^{-x}$, summed explicitly over $120$ further terms with a remainder $10^{-60}$ far above the true remainder. All rounding is outward to denominators $10^{70}$. The resulting interval for $S_{1/2}$ has width below $10^{-57}$ and lies within $10^{-57}$ of the interval for $\tfrac12\ln 2$, which is (i). The interval for $S_{0}$ lies in $(0.720396698946605, 0.720396698946606)$, which is (ii), and $1/(4S_{0})$ follows. For orientation (not part of the proof): $S_{1/2} = 0.346573590279972654708616060729\ldots$, and at slopes other than the one (R) and (Q) fix the half-offset sum is not $\tfrac12\ln 2$ (at $x_{k} = (k + \tfrac12)\pi$ it is $1.0275\ldots$, at $x_{k} = 4\pi(k + \tfrac12)$ it is $0.02715\ldots$).

\emph{(iii)} Under the hypothesis of Theorem \claimref{synthesis.residue-from-mode-entropy}, $\sum s = A/4$ over the counted units, with the counted units taken to be whole arrays, each contributing $S_{\delta}$, the number of arrays is $A/(4S_{\delta})$, that is $1/(4S_{\delta})$ per Planck area per modular period. By (i), for $\delta = \tfrac12$ this is $1/(2\ln 2)$ up to a relative error below $10^{-56}$, which is twice $1/(4\ln 2)$, the capacity-convention residue, so two arrays carry $\ln 2$. For $\delta = 0$ the ratio to $1/(4\ln 2)$ is $\ln 2/S_{0} \in (0.96, 0.97)$, an interval containing no $p/q$ with $q \le 4$; the script checks this with the same bounds.

\emph{The sentence after (iii).} The flow acts by $\tau_{t}(\psi_{k}) = e^{-I_4\omega_{k}t}\psi_{k}$ (the phase in the field's unit $I_4$), so at $t = 2\pi/\kappa$ it multiplies $\psi_{k}$ by $e^{-2\pi I_4(k + \delta)}$, which is $1$ for $\delta = 0$ and $-1$ for $\delta = \tfrac12$; the general classification is clause (iv) of the result filed alongside, synthesis.q-splits-maximum-entropy-affine-weights. By Proposition \claimref{state-selection.where-fermi-dirac-comes}, one Euclidean period is the rotor $R_{2\pi} = -1$, acting as $-1$ on the odd sector. The script checks $R_{2\pi} = -1$ in $\Cl(2, 0)$ as $R(\pi)^{2} = B^{2} = -1$ for the rotation bivector $B = e_{1}e_{2}$, and, on all $16$ basis states of a four-mode window, that $e^{2\pi I_4K}$ is $(-1)^{N}$ for the weights $j + \tfrac12$ and $1$ for the weights $j$.

\emph{(i), exact value.} The classical inputs, Fact \claimref{synthesis.imported-theta-function-identities} (Whittaker and Watson, Ch.~21; Mumford, Tata Lectures on Theta I): with $q = e^{2\pi i\tau}$, $\eta = q^{1/24}\prod_{n \geq 1}(1 - q^{n})$, $\vartheta_{3} = \prod_{n \geq 1}(1 - q^{n})(1 + q^{n - 1/2})^{2}$, $\vartheta_{2} = 2q^{1/8}\prod_{n \geq 1}(1 - q^{n})(1 + q^{n})^{2}$, $\vartheta_{4} = \prod_{n \geq 1}(1 - q^{n})(1 - q^{n - 1/2})^{2}$; (a) $\vartheta_{3}(-1/\tau) = \sqrt{-i\tau}\,\vartheta_{3}(\tau)$, $\vartheta_{2}(-1/\tau) = \sqrt{-i\tau}\,\vartheta_{4}(\tau)$, $\eta(-1/\tau) = \sqrt{-i\tau}\,\eta(\tau)$; (b) $\vartheta_{3}^{4} = \vartheta_{2}^{4} + \vartheta_{4}^{4}$; (c) $\vartheta_{2}\vartheta_{3}\vartheta_{4} = 2\eta^{3}$. For $\delta = \tfrac12$ and slope $y$ (the occupations at $x_{k} = y(k + \tfrac12)$, $y = 2\pi$ here) the array is a product of modes with Boltzmann factors $e^{-y(n - 1/2)}$, $n \geq 1$, each value twice (particles above the sea, holes below), so with $\tau = iy/2\pi$ its grand-canonical partition function is $Z = \prod_{n \geq 1}(1 + q^{n - 1/2})^{2} = q^{1/24}\,\vartheta_{3}/\eta$. The entropy of a product of thermal modes is $S = (1 - y\,\partial_{y})\log Z$, and the factor $q^{1/24} = e^{-y/24}$ contributes $-y/24 + y/24 = 0$, so $S(y) = (1 - y\,\partial_{y})f(y)$ with $f(y) = \log(\vartheta_{3}/\eta)(iy/2\pi)$. By (a), $f(y) = f(4\pi^{2}/y)$; differentiating at the fixed point $y = 2\pi$ gives $f'(2\pi) = -f'(2\pi)$, so $f'(2\pi) = 0$ and $S_{1/2} = f(2\pi) = \log(\vartheta_{3}(i)/\eta(i))$. At $\tau = i$, (a) gives $\vartheta_{2}(i) = \vartheta_{4}(i)$, so (b) gives $\vartheta_{4}(i)^{2} = \vartheta_{3}(i)^{2}/\sqrt{2}$ (all three values are positive), and (c) gives $\vartheta_{3}(i)^{3}/\sqrt{2} = 2\eta(i)^{3}$, that is $\vartheta_{3}(i)/\eta(i) = \sqrt{2}$. Hence $S_{1/2} = \tfrac12\ln 2$. For $\delta = 0$ the partition function is $\vartheta_{2}/\eta$ up to the Casimir factor, which (a) carries to $\vartheta_{4}/\eta$, so no fixed-point simplification occurs.
