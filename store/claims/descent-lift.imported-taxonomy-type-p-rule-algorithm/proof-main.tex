Every zero divisor of a nondegenerate real Clifford algebra is annihilated on each side by a nontrivial idempotent; in a simple algebra the idempotent is non-central and the obstruction is type P, refined to type N exactly when the annihilating idempotent is $wv$ for a hyperbolic pair $(v, w)$ of null vectors, $vw + wv = 1$. Step 2 of the algorithm diagnoses by three tests in order: a vector of square zero is type N; a central idempotent is type C; otherwise type P, with the caution that nilpotence alone does not diagnose N. Step 3 adjoins a hyperbolic plane for type N, one generator for type C, and nothing for type P, the identity being the repair of an idempotent; a general type-P element has von Neumann pseudo-inverses, and among the idempotents with a given image the self-adjoint one is canonical exactly where a definite form is available. In the $(1,1)$ ascent the adjoined ladder pair $f, f^{*}$ and its occupation projectors are a system of matrix units, the adjoined pair is itself null, and the reflection in an adjoined direction is an automorphism of the ascent. \emph{Provenance:} \cite[Def.~3.1, Ex.~3.5, Thm.~3.9, Thm.~4.2, Rem.~5.8, Prop.~6.1, Rem.~6.6, Thm.~7.1, Prop.~7.8, Table~1]{ButlerT1} (\claimref{transport.no-transport-terminates}, \claimref{transport.rule-1-morita-trivial}, \claimref{transport.exhaustiveness-every-zero-divisor-annihilated-idempotent}, \claimref{transport.type-p-self-repairing}).
