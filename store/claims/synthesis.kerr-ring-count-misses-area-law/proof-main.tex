Read in Gauge Theory Gravity, the metric below is the derived metric $g(a,b) = \hb^{-1}(a)\cdot\hb^{-1}(b) = a\cdot b - 2H(a\cdot k)(b\cdot k)$ of the Kerr-Schild gauge field $\hb(a) = a + H(a\cdot k)k$, written in components in the source's signature (the sign of every product reversed), and induced metrics are Gram matrices of physical tangent vectors, and the displayed $\eta$ is the flat background in oblate coordinates (Fact \claimref{synthesis.imported-gtg-dictionary}, clause (i)). \emph{The metric.} Fact \claimref{interior.imported-kerr-schild-form-kerr-gauge} gives Kerr as a Kerr-Schild deformation of flat space along the null field $k$ with potential $H = Mr^3/(r^4 + a^2Z^2) = Mr/\Sigma$ in oblate coordinates. Flat space in oblate coordinates is the displayed $\eta$, and the displayed $k$ is the classical Kerr-Schild covector in these coordinates (Kerr and Schild 1965, cited from memory; the sign of $2Hk\otimes k$ is that of signature $(-,+,+,+)$). The check confirms that $k$ is $\eta$-null, that $\det g = \det\eta = -\Sigma^2$ (the Kerr-Schild property), and that $\Sigma\,g^{rr} = r^2 - 2Mr + a^2 = \Delta$, so the hypersurfaces $r = r_\pm$ are null: these are the horizons. All entries are rational in $(M, a, r, u)$, so these are identities checked in exact arithmetic at rational points.

\emph{(1)} The curvature scale of Proposition \claimref{interior.complex-scale-inverse-cube-killing-spinor} has modulus $M|z|^{-3}$, so the (C1) locus is a level set of $|z|$. The tube $|z| = \rho$ is $r^2 + a^2u^2 = \rho^2$; write $z = r - I_4au = \rho(c + I_4s)$, numbers of $\mathrm{span}\{1, I_4\}$, with $c = \cos\psi$, $s = \sin\psi$, so $r = \rho c$ and $u = -\rho s/a$, which needs $\rho \le a$. By Proposition \claimref{synthesis.kerr-ring-double-cover-data} the parameter regions $r > 0$ and $r < 0$ are the two sheets of the double cover, exchanged by $z \mapsto -z$, and $|z| = \rho$ is one circle on the cover meeting both. On it $|r| \le \rho$. Since $r_- = a^2/(M + \sqrt{M^2 - a^2}) \ge a^2/2M$ and $a^2 \ge 8M\rho_c$ gives $a^2/2M \ge 4\rho_c$, the tube $\rho = \rho_c$ lies in $|r| < r_-$. In $r_- \le r \le r_+$, $|z|^2 = r^2 + a^2u^2 \ge r_-^2 > \rho_c^2$, so $2M|z|^{-3} < 1$ there.

\emph{(2)} The tangent vectors of the tube are $\partial_t$, $\partial_\phi$ and $T_\psi = (dr/d\psi)\partial_r + (du/d\psi)\partial_u = -\rho s\,\partial_r - (\rho c/a)\,\partial_u$. On their span $\eta$ is diagonal, $\eta|_T = \mathrm{diag}(-1, \gamma, P(1 - u^2))$ with $\gamma = \Sigma\bigl(\rho^2s^2/P + \rho^2c^2/(a^2(1 - u^2))\bigr)$, and $k|_T = (-1, \rho^3 s/P, a(1 - u^2))$, using $\Sigma = \rho^2$. The rank-one update gives $\det h = \det\eta|_T\,(1 + 2H\,k_T^{\top}\eta_T^{-1}k_T)$. Now $\det\eta|_T = -\rho^4\bigl(s^2(1 - u^2) + c^2P/a^2\bigr)$, and
\[
\det\eta|_T\; k_T^{\top}\eta_T^{-1}k_T \;=\; \det\eta|_T\Bigl(-1 + \frac{a^2(1 - u^2)}{P}\Bigr) - \frac{\rho^6 s^2(1 - u^2)}{P}
\;=\; \frac{\rho^6\bigl(s^2(1 - u^2) + c^2P/a^2\bigr)}{P} - \frac{\rho^6 s^2(1 - u^2)}{P} \;=\; \frac{\rho^6c^2}{a^2},
\]
using $-1 + a^2(1 - u^2)/P = -\Sigma/P = -\rho^2/P$. With $2H = 2Mc/\rho$,
\[
\det h = -\rho^4\Bigl[s^2(1 - u^2) + \frac{c^2P}{a^2} - \frac{2M\rho c^3}{a^2}\Bigr],
\]
and $s^2(1 - u^2) + c^2P/a^2 = s^2 - \rho^2s^4/a^2 + c^2 + \rho^2c^4/a^2 = 1 + (\rho^2/a^2)(c^2 - s^2)$, which is the displayed identity since $c^2 - s^2 = \cos 2\psi$. Replacing $\partial_t$ by $\partial_t + \Omega\partial_\phi$ is a unimodular change of the tangent frame, so the determinant is unchanged. At $\rho = \rho_c$ the bracket is $1 + x$ with $|x| \le \varepsilon + \delta$; $a \le M$ and $a \ge 2\rho_c^2$ give $M \ge 32$, $\rho_c \ge 4$, $\varepsilon = \rho_c^2/a^2 \le 1/(4\rho_c^2) \le 1/64$, so $|x| \le 1/64 + 1/4 < \tfrac12$ and $\det h < 0$: the induced metric is Lorentzian. At $r = -\rho_c$, $u = 0$, $g_{\phi\phi} = P + 2H a^2 = \rho_c^2 + a^2 - 2Ma^2/\rho_c = \rho_c^2 + a^2(1 - \rho_c^2)$ by $2M = \rho_c^3$, negative since $\rho_c \ge 4$ and $a \ge \rho_c$; the $\phi$-orbit there is closed and timelike.

\emph{(3)} The volume per unit Killing time is $V' = \int_0^{2\pi}\!d\phi\int_0^{2\pi}\!d\psi\,\sqrt{|\det h|} = 2\pi\rho_c^2\int_0^{2\pi}\sqrt{1 + x(\psi)}\,d\psi$ with $x = \varepsilon\cos 2\psi - \delta\cos^3\psi$. For $|x| \le \tfrac12$: $(1 + x/2)^2 - (1 + x) = x^2/4 \ge 0$, and with $q = x/2 - x^2/2 = x(1 - x)/2$, $1 + q > 0$ and $(1 + x) - (1 + q)^2 = x^2 - q^2 = x^2\bigl(1 - (1 - x)^2/4\bigr) \ge 0$; so $1 + x/2 - x^2/2 \le \sqrt{1 + x} \le 1 + x/2$. The circle averages are $\langle\cos^n\psi\rangle = \binom{n}{n/2}2^{-n}$ for even $n$ and $0$ for odd $n$; hence $\langle x\rangle = \varepsilon(2\cdot\tfrac12 - 1) - 0 = 0$ and $\langle x^2\rangle = \varepsilon^2\langle\cos^2 2\psi\rangle + \delta^2\langle\cos^6\psi\rangle - 2\varepsilon\delta\langle\cos 2\psi\cos^3\psi\rangle = \varepsilon^2/2 + 5\delta^2/16$. So $V' = 4\pi^2\rho_c^2(1 - \eta)$ with $0 \le \eta \le \varepsilon^2/4 + 5\delta^2/32$. For Schwarzschild, Proposition \claimref{singularity.stretched-singularity-count} gives $8\pi M$ at leading order. The count rule of that proposition, $\nu$ modes per Planck cell of the (C1) locus per unit Killing time, gives $N = \nu V'\Delta t$. On one sheet ($\cos\psi > 0$, or $< 0$) the same bounds give $\int\sqrt{1 + x}\,d\psi = \pi \mp \tfrac23\delta + O(\varepsilon^2 + \delta^2)$, since $\int_{-\pi/2}^{\pi/2}\cos 2\psi\,d\psi = 0$ and $\int_{-\pi/2}^{\pi/2}\cos^3\psi\,d\psi = \tfrac43$; so a one-sheet count is $\tfrac12 V'(1 + O(\delta))$, with the same exponents.

The horizon cross-section $t = $ const, $r = r_+$ has induced metric $g_{uu} = \Sigma/(1 - u^2)$, $g_{u\phi} = 0$ (since $k_u = 0$), $g_{\phi\phi} = (1 - u^2)\bigl(P + 2Mra^2(1 - u^2)/\Sigma\bigr)$; the determinant is $\Sigma P + 2Mr_+a^2(1 - u^2) = 2Mr_+(\Sigma + a^2 - a^2u^2) = 2Mr_+(r_+^2 + a^2) = P(r_+)^2$, using $P(r_+) = 2Mr_+$. So the area is $\int_0^{2\pi}\!\int_{-1}^{1}P(r_+)\,du\,d\phi = 4\pi(r_+^2 + a^2) = 8\pi Mr_+$, and, with the Bekenstein-Hawking entropy $A_+/4$ of the Kerr horizon (Fact \claimref{synthesis.imported-kerr-surface-gravity-entropy}), $N/(A_+/4) = \nu\cdot 4\pi^2\rho_c^2(1 - \eta)\,\tau M/(2\pi Mr_+) = 2\pi\nu\tau\rho_c^2(1 - \eta)/r_+$. At fixed $a/M$, $\tau$ is fixed, $r_+ = M(1 + \sqrt{1 - a^2/M^2})$ is proportional to $M$, $\rho_c^2 = (2M)^{2/3}$ and $\eta \to 0$ (both $\varepsilon$ and $\delta$ are of order $M^{-2/3}$), so the ratio is of order $M^{-1/3}$; it reaches $1$ only if $\Delta t \propto M^{4/3}$.

\emph{(4)} With $\Delta t = 2\pi/\kappa_+ = 4\pi(r_+^2 + a^2)/(r_+ - r_-) = 4\pi Mr_+/\sqrt{M^2 - a^2}$ (the Kerr surface gravity of Fact \claimref{synthesis.imported-kerr-surface-gravity-entropy}) and $\nu = 1/16\pi$ from Proposition \claimref{scrambling.epoch-modular-period-two-unknowns-become}, $\tau = 4\pi r_+/\sqrt{M^2 - a^2}$ and $N/(A_+/4) = 2\pi\cdot\tfrac{1}{16\pi}\cdot 4\pi r_+\rho_c^2(1 - \eta)/(r_+\sqrt{M^2 - a^2}) = (\pi/2)\rho_c^2(1 - \eta)/\sqrt{M^2 - a^2}$. At $a = 0$ the same rule gives $\nu\cdot 8\pi M\cdot 8\pi M/(4\pi M^2) = 1$, the Schwarzschild statement of Proposition \claimref{scrambling.epoch-modular-period-two-unknowns-become}, there resting on $V' = 8\pi M = 2\pi/\kappa$. The check evaluates the ratio exactly (as a rational multiple of $\pi$) at the holes $(M, a) = (500, 300), (4000, 2400), (32000, 19200)$, where $\rho_c = 10, 20, 40$ and $\sqrt{M^2 - a^2} = 400, 3200, 25600$: the leading coefficient is $\pi/8$, $\pi/16$, $\pi/32$, halving each time $M$ grows by $8$, and $\eta \le 5/2592 + 1/3240000$ at the first.
