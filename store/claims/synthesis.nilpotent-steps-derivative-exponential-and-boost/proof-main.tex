\emph{(i)} $x$ is a scalar and commutes with $n$, and $n^{2} = 0$, so $(x + n)^{k} = x^{k} + kx^{k-1}n$ and $u(x + n) = u(x) + u'(x)n$ for a polynomial $u$. For $f = u/h$ with $h(x) \ne 0$, $h(x + n) = h(x) + h'(x)n$ has the inverse $h(x)^{-1} - h'(x)h(x)^{-2}n$, and multiplying gives $f(x) + (u'h - uh')(x)h(x)^{-2}n = f(x) + f'(x)n$. In $\Cl(0,0,1)$, $\rho^{2} = 0$ (Proposition \claimref{std-algebra.radical-ideal-and-quotient}: the radical generates a nilpotent ideal, here with $J^{2} = 0$). The check runs $f = (x^{3} + 3x)/(x^{2} + 1)$, with $f' = (x^{4} + 3)/(x^{2} + 1)^{2}$, at four rational points against hand-stated values.

\emph{(ii)} A radical vector anticommutes with every vector and squares to $0$, so $\rho x \rho = \pm x\rho^{2} = 0$ for every product $x$ of vectors, hence for every $x$; so $\rho x \rho = \rho$ has no solution. If $ngn = n$ then $(gn)^{2} = g(ngn) = gn$, and by (i), $g(f(x + n) - f(x)) = g\,f'(x)n = f'(x)\,gn$. Theorem \claimref{conformal.minimal-nondegenerate-completion} embeds $\Cl(p,q,r)$ in the nondegenerate $\Cl(p{+}r, q{+}r)$, in which $\rho$ spans a hyperbolic plane with a partner $m$; that algebra is regular by Lemma \claimref{transport.regularity-localises-zero-divisors-idempotents}, and for the Witt pair $nmn = n(1 - nm) = n$ (Proposition \claimref{singularity.pseudo-inverse-identities-hyperbolic-atom}; the pair obeys the relations of Proposition \claimref{std-algebra.witt-basis-car}). In $\Cl(1,1)$ the anti-automorphism $\dagger$, reversion composed with $e_{-} \mapsto -e_{-}$, exchanges $n$ and $m$, so $(mn)^{\dagger} = n^{\dagger}m^{\dagger} = mn$; another generalised inverse, $g = m + 3n + 2nm$, has $gn = mn + 2n$, idempotent but not self-adjoint. The check verifies $\rho x \rho = 0$ on every blade for each radical generator of $\Cl(0,0,1)$, $\Cl(1,1,1)$, $\Cl(1,2,1)$, $\Cl(0,0,2)$ and $\Cl(1,3,1)$, and the derivative identity for both $g$ on $2x^{3} + 5x$ at four points and on $(x^{3} + 3x)/(x^{2} + 1)$ at two, against hand-stated values.

\emph{(iii)} The $b_{i}$ commute, so the multinomial expansion of $\varepsilon^{k}$ holds, and every monomial with a repeated factor vanishes since $b_{i}^{2} = 0$; the surviving monomials are the products over $k$-element subsets, each appearing $k!$ times, so $\varepsilon^{k} = k!\,e_{k}(b)$, and $e_{N+1} = 0$. Expanding $\prod(1 + b_{i})$ gives $\sum_{k}e_{k}(b) = \sum_{k \le N}\varepsilon^{k}/k!$, and the exponential series of the nilpotent $\varepsilon$ stops at $k = N$. Realisations: $\rho_{2i-1}\rho_{2i}$ is even, so it commutes with every product of other generators, and $(\rho_{2i-1}\rho_{2i})^{2} = -\rho_{2i-1}^{2}\rho_{2i}^{2} = 0$. Mutually orthogonal null vectors anticommute and square to $0$ (Proposition \claimref{std-algebra.witt-basis-car}), so the same two computations apply to products of disjoint pairs; in $\Cl(2N,2N)$ the vectors $\tfrac12(e_{j} + e_{2N+j})$, $j = 1, \dots, 2N$, are such a family. For the Jordan-Wigner steps in $\Cl(N,N)$: $\pi_{j}^{2} = 1$, $\pi_{j}$ anticommutes with $v_{j}, w_{j}$ and commutes with $v_{i}, w_{i}$ for $i \ne j$, so $b_{i}^{2} = v_{i}^{2}(\pi_{1}\cdots\pi_{i-1})^{2} = 0$, and for $i < k$ moving $b_{i}$ past $b_{k}$ costs one sign from $v_{i}v_{k}$ and one from $v_{i}\pi_{i}$, so $b_{i}b_{k} = b_{k}b_{i}$. The check verifies the identities, and that the product of all steps is nonzero, for $N = 2, \dots, 6$ in $\Cl(0,0,2N)$, for $N = 3$ with six orthogonal null vectors of $\Cl(6,6)$, and for the Jordan-Wigner steps with $N = 2, 3$ in $\Cl(N,N)$.

\emph{(iv)} $Bl_{+} = e_{t}e_{r}e_{t} + e_{t}e_{r}e_{r} = -e_{r} - e_{t} = -l_{+}$ and $l_{+}B = e_{t}e_{t}e_{r} + e_{r}e_{t}e_{r} = e_{r} + e_{t} = l_{+}$, so $B$ anticommutes with $l_{+}$; for scalar $\alpha, \beta$, $\widetilde{R} = \alpha - \beta B$ and $l_{+}\widetilde{R} = Rl_{+}$, hence $Rl_{+}\widetilde{R} = R^{2}l_{+} = (\alpha^{2} + \beta^{2} + 2\alpha\beta B)l_{+} = (\alpha - \beta)^{2}l_{+}$, and likewise $Rl_{-}\widetilde{R} = (\alpha + \beta)^{2}l_{-}$ since $Bl_{-} = l_{-}$. For the finite boost only $R^{2} = \cosh\phi + \sinh\phi\,B$ enters, with $\cosh\phi - \sinh\phi = \tfrac54 - \tfrac34 = \tfrac12$, $\cosh\phi + \sinh\phi = 2$ and $(\tfrac54)^{2} - (\tfrac34)^{2} = 1$. For the nilpotent rapidity, $d = s\rho_{1}\rho_{2}$ is even and built from generators orthogonal to $e_{t}, e_{r}$, so it commutes with them and $d^{2} = 0$; since $d$ is central in the subalgebra generated by $e_{t}, e_{r}, \rho_{1}, \rho_{2}$ with $d^{2} = 0$, $(dB)^{2} = 0$ and the series stops: $\exp(\pm\tfrac12 dB) = 1 \pm \tfrac12 dB$, mutually inverse. Computing directly, $(1 + \tfrac12 dB)\,l_{+}(1 - \tfrac12 dB) = (1 - \tfrac12 d)^{2}l_{+} = (1 - d)l_{+}$, using $Bl_{+} = -l_{+}$, $l_{+}B = l_{+}$; likewise $(1 + d)l_{-}$. The reversion of $\Cl(1,1,2)$ fixes $dB$ (grade $4$), so $\widetilde{R} = R$, $R\widetilde{R} = 1 + dB \ne 1$, and $Rl_{+}\widetilde{R} = l_{+}$: the boost is a boost of $\Cl(1,1)$ over $\R[d]/(d^{2})$ with $\R[d]$-linear reversion, not a rotor of $\Cl(1,1,2)$. The check verifies each identity for $s = 1, -3, \tfrac25$, the reversion statements, and the finite boost.
