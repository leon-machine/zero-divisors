$W$ is maximal isotropic, so $W^{\perp} = W$ and a vector $u$ lies in $W$ if and only if $\ip{u}{\ell} = \ip{u}{m} = 0$. For $B \in \so(4,\C)$ the action is skew, $\ip{B\cdot u}{v} = -\ip{u}{B\cdot v}$ (\claimref{std-algebra.bivector-lie-algebra}), so $\ip{B\cdot\ell}{\ell} = \ip{B\cdot m}{m} = 0$ automatically and $\ip{B\cdot m}{\ell} = -\pv(B)$. Hence $B\cdot\ell \in W$ and $B\cdot m \in W$ together reduce to the single condition $\pv(B) = 0$, and the stabiliser is the kernel of a nonzero functional on a six-dimensional space. The values on the basis are the commutators $\tfrac12[e_{ab}, \ell]$ paired with $m$; for instance $\tfrac12[e_{02}, e_{0} + e_{1}] = -e_{2}$ and $\ip{-e_{2}}{e_{2} + I_{5}e_{3}} = 1$. The four real elements listed have $\pv = 0$ (the null rotations because $\tfrac12[\ell e_{2}, \ell] = 0$, $\ell$ being null and anticommuting with $e_{2}$ (\claimref{std-algebra.orthogonal-anticommute})) and are linearly independent; the two real equations $\operatorname{Re}\pv = \operatorname{Im}\pv = 0$ are independent (the script checks the rank), so their real solutions form a space of dimension exactly four, which the four elements span. That the spin action of $B$ fixes the ray of the vacuum exactly when $B$ stabilises its annihilator $W$ is the definition of the annihilator, Fact \claimref{pairing.imported-two-readings-capacities-vacuum-null}. The script verifies every value, the equivalence ``$B\cdot W \subseteq W$ if and only if $\pv(B) = 0$'' on twenty random complex bivectors, the independence, and the two null rotations about $n$.
