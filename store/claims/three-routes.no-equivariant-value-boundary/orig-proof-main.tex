First, $\hat g_\lambda$ is an isometry $(T, h_{u+\lambda}) \to (T, h_u)$: on $W \times W$ it preserves $G$ (Lemma \claimref{three-routes.base-unipotents-their-action-candidates}); on the adjoined plane it is the identity; and for the coupling, $h_u(\hat g\alpha, \nO) = \nu(g\alpha)(u) = \nu\alpha(u) + \nu\alpha(\lambda)k(u) = \nu\alpha(u + \lambda) = h_{u+\lambda}(\alpha, \nO)$, identically with $\mu$. Composing with $\Phi_\lambda^{-1} : (T, h_u) \to (T, h_{u+\lambda})$ gives $\theta_\lambda : (T, h_u) \to (T, h_u)$, an automorphism. Its restriction to $W$ is $g_\lambda$, since $\Phi_\lambda$ is the identity there, and both factors fix $k$. The induced action on vectors is dual to the action on $W$, hence is $g_\lambda$'s: translation by $-\lambda$ on candidates (Lemma \claimref{three-routes.base-unipotents-their-action-candidates}). A natural value assignment, one candidate per completed structure commuting with automorphisms, must satisfy $\hat u = \hat u - \lambda$ for every $\lambda \in \ker k$, impossible for any $\lambda \neq 0$. The script verifies $\theta_\lambda^{\mathsf{T}} h_u\, \theta_\lambda = h_u$ exactly, that $\theta_\lambda$ is not the identity, that it fixes $k$, and the translation action on two sample candidates.
