The completion $\Cl(p{+}1,q{+}1)$ of $\Cl(p,q)$ carries the null pair $\nO = \tfrac12(e_{-} - e_{+})$, $\nInf = e_{-} + e_{+}$ with $\nO \cdot \nInf = -1$, and represents the point $x$ by the null vector $X(x) = \nO + x + \tfrac12 Q(x)\nInf$, with $X(x)\cdot X(y) = -\tfrac12 Q(x - y)$. For a null vector $v$ and $u$ orthogonal to it, $R_{u} = 1 + vu$ is a rotor fixing $v$, and $u \mapsto R_{u}$ is an isomorphism of $(U, +)$ onto the group of null rotations of $v$. \emph{Provenance:} \cite[Sec.~4.3, Lem.~4.6, Thm.~4.10]{ButlerT1} (\claimref{transport.group-null-rotations}, \claimref{transport.totality}).
