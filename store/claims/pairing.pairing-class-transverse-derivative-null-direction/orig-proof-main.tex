$\nabla_{X}\ell = \tfrac12[\Omega(X), \ell] = \Omega(X)\cdot\ell$ by the defining property of $\Omega$, so the identity is the definition of $\pv$ once $\Omega$ reproduces $\nabla$, which is what the script verifies for both Schwarzschild frames. For the rescaling, $\nabla_{X}(\lambda\ell) = \lambda\nabla_{X}\ell + (X\lambda)\ell$ and $\ip{\ell}{m} = 0$; the script models the derivative term, which is nonzero along $e_{1}$, and confirms the scaling in every direction with $\lambda = F/(1+F)$. For real $X$, $\pv(\Omega(X)) = 0$ says $\nabla_{X}\ell \in W$, and $\nabla_{X}\ell$ is real, so it is a real vector of $W = \operatorname{span}\{\ell, m\}$, hence a multiple of $\ell$. (For a complex direction the equivalence fails: in Schwarzschild $\nabla_{m}\ell \propto m$ with $\pv(\Omega(m)) = 0$.)
