$G(g_\lambda\alpha, g_\lambda\alpha') = G(\alpha, \alpha') + \alpha'(\lambda)G(\alpha, k) + \alpha(\lambda)G(k, \alpha') + \alpha(\lambda)\alpha'(\lambda)G(k,k) = G(\alpha, \alpha')$, every correction term vanishing because $k$ spans the radical. $g_\lambda(k) = k + k(\lambda)k = k$. The composition law is immediate, $g_\lambda^{-1} = g_{-\lambda}$. For the dual action, $(g_\lambda^{-\mathsf{T}}u)(\alpha) = (g_\lambda^{-1}\alpha)(u) = \alpha(u) - \alpha(\lambda)k(u) = \alpha(u - k(u)\lambda)$; at $k(u) = 1$ this is translation by $-\lambda$, which is free (no fixed vector for $\lambda \neq 0$) and transitive (any two candidates differ by an element of $\ker k$).
