By Theorem \claimref{state-selection.kms-uniqueness-factor} applied to $K_{\mathrm{geo}}$, a GMC state is $\rho \propto e^{-\beta K_{\mathrm{geo}}} = \bigotimes_k e^{-\beta\omega_k K_k}$, whose $k$-th marginal is $\mathrm{Gibbs}(\beta\omega_k)$: the same $\beta$ at every mode. For the converse, the modular generator of a product state is $\log\rho = -\sum_k \beta_k\omega_k N_k + \mathrm{const}$, and this is proportional to $K_{\mathrm{geo}} = \sum_k \omega_k N_k + \mathrm{const}$ if and only if $\beta_k \omega_k = \lambda\,\omega_k$ for a single $\lambda$ and every $k$, that is if and only if $\beta_k \equiv \lambda$, the weights $\omega_k$ being nonzero.
