By Theorem \claimref{singularity.kms-uniqueness-factor} applied to $K_{\mathrm{geo}}$, a state satisfying (G) is $\varrho \propto e^{-\beta K_{\mathrm{geo}}} = \bigotimes_k e^{-\beta\omega_k K_k}$, whose $k$-th marginal is $\mathrm{Gibbs}(\beta\omega_k)$: the same $\beta$ at every mode. Conversely the modular generator of a product state is $\log\varrho = -\sum_k \beta_k\omega_k N_k + \mathrm{const}$, proportional to $K_{\mathrm{geo}} = \sum_k \omega_k N_k + \mathrm{const}$ if and only if $\beta_k\omega_k = \lambda\omega_k$ for a single $\lambda$ and every $k$ of nonzero weight (under Premise \claimref{singularity.q-joint-quasi-freeness-s-wave}'s linear assignment the $k = 0$ mode is excluded from this clause and from the converse: at $\omega_0 = 0$ the marginal is $\tfrac12\,\mathrm{id}$ for every $\beta_0$ and constrains nothing).
