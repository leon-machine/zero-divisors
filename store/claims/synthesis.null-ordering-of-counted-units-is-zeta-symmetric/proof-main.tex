\emph{(i)} For $u = e^{\kappa\tau}$ every derivative is a multiple of $u$: $u' = \kappa u$, $u'' = \kappa^{2}u$, $u''' = \kappa^{3}u$, so $\{u, \tau\} = u'''/u' - \tfrac32(u''/u')^{2} = \kappa^{2} - \tfrac32\kappa^{2} = -\kappa^{2}/2$. By the flux rule of Theorem \claimref{synthesis.collapse-in-vacuum-regular-at-future-horizon-selects-hawking-temperature} (the null energy flux of a chiral component's vacuum, normal ordered at an observer's vacuum, is $-\tfrac{1}{24\pi}$ times the Schwarzian of the map from its parameter to the observer's), the vacuum of $u$, which is the null ground state of (N$_{+}$) on the generator (Premise \claimref{synthesis.n-plus-null-ground-state}), normal ordered at the vacuum of $\tau$, which is the boost ground state, has Killing-frame energy density $-\tfrac{1}{24\pi}\cdot(-\tfrac{\kappa^{2}}{2}) = \kappa^{2}/(48\pi)$ per complex component. Independently, Proposition \claimref{synthesis.stationary-horizon-state-is-its-own-edge-scaling-limit} gives the Killing-frame density $\kappa^{2}u^{2}\langle T_{uu}\rangle = \kappa^{2}(c^{-2} - 1)/(48\pi)$ of the period-$2\pi c$ state in the null ordering, which is $0$ for the null ground state ($c = 1$) and $-\kappa^{2}/(48\pi)$ for the boost ground state ($c \to \infty$): the two routes give the same difference with opposite orderings. (A third route: the null ground state's Mellin modes are Fermi-Dirac at rapidity period $2\pi$, Theorem \claimref{synthesis.positive-null-energy-gives-r-premises}(iii), so in the boost ordering a complex component has, per unit rapidity, $\tfrac{1}{2\pi}\cdot 2\int_{0}^{\infty}w\,dw/(e^{2\pi w} + 1) = \tfrac{1}{\pi}\cdot\tfrac{1}{4\pi^{2}}\cdot\tfrac{\pi^{2}}{12} = \tfrac{1}{48\pi}$, using $\int_{0}^{\infty}x\,dx/(e^{x} + 1) = \pi^{2}/12$, cited from memory and not in the check.) A Killing-time interval of length $2\pi/\kappa$ then carries $\tfrac{\kappa^{2}}{48\pi}\cdot\tfrac{2\pi}{\kappa} = \tfrac{\kappa}{24}$, the factors of $\pi$ cancelling, so the boost ground state carries $-\kappa/24$ per window in the null ordering. The check verifies the Schwarzian, the flux coefficient, the agreement with the stored density at $c^{-2} = 0$ and $1$, and the window product exactly at $\kappa = \tfrac14, \tfrac27, 3, \tfrac12$, with affine and M\"obius maps (Schwarzian $0$, no shift of the zero) as controls.

The array as a window (the spectral identity is exact; reading the array as that component on a window of the continuum is part of the window reading): a chiral complex component on a Killing-time interval of length $L$ with the condition $\psi(\tau + L) = e^{2\pi i\delta}\psi(\tau)$ has single-particle Killing frequencies $\tfrac{2\pi}{L}(k + \delta)$, $k \in \Z$; the array's spacing $\kappa$ is $L = 2\pi/\kappa$, its real-time recurrence period (the remark of Theorem \claimref{synthesis.counted-unit-energy-at-half-offset}), and $\delta = \tfrac12$ is the antiperiodic condition, the parity automorphism at one period noted for (Q) version 3 (Premise \claimref{singularity.q-joint-quasi-freeness-s-wave}).

\emph{(ii)} For $0 < a \le 1$ put $h_{a}(\epsilon) = \sum_{n \ge 0}e^{-\epsilon(n + a)} = e^{-\epsilon a}/(1 - e^{-\epsilon})$, so $\sum_{n \ge 0}(n + a)e^{-\epsilon(n + a)} = -h_{a}'(\epsilon)$. Since $\epsilon h_{a}(\epsilon) = e^{-\epsilon a}\cdot\epsilon/(1 - e^{-\epsilon}) = \sum_{j}c_{j}\epsilon^{j}$ is a power series, $-h_{a}' = -\sum_{j}(j - 1)c_{j}\epsilon^{j - 2}$, whose finite part is $-c_{2}$; the generating function of the Bernoulli polynomials gives $c_{2} = B_{2}(1 - a)/2 = B_{2}(a)/2$, so the finite part is $-B_{2}(a)/2$, the Hurwitz value $\zeta(-1, a)$, with the rule of Theorem \claimref{synthesis.counted-unit-energy-at-half-offset}(ii) (finite part of the exponentially regulated sum). The check computes $c_{2}$ by exact power-series inversion for $a = \tfrac12, \tfrac14, \tfrac13, \tfrac23, \tfrac15, 1$.
