## formal
For $k \ge 1$ let $A_{k} = \Cl_{\Q}(k,k)$ (Theorem \claimref{synthesis.signed-directions-and-the-integer-clifford-algebra}(vii)), with generators $e_{1}, \dots, e_{k}$ of square $1$ and $f_{1}, \dots, f_{k}$ of square $-1$, so that $A_{k} \subseteq A_{k+1}$, and let $T = \bigcup_{k} A_{k}$. For a finite set $I$ of indices let $A_{I}$ be the subalgebra generated by the $e_{i}, f_{i}$ with $i \in I$. The \emph{switch} of index $i$ is $v_{i} = \tfrac12(e_{i} + f_{i})$, $w_{i} = \tfrac12(e_{i} - f_{i})$, with tests $\mathrm{on}_{i} = v_{i}w_{i}$, $\mathrm{off}_{i} = w_{i}v_{i}$. For $a \in A_{k}$ put
\[
N_{k}(a) \;=\; \frac{\dim_{\Q}(aA_{k})}{\dim_{\Q}A_{k}}, \qquad aA_{k} = \{ax : x \in A_{k}\} .
\]
\begin{enumerate}
\item[(i)] \emph{(Each rung is all maps on $k$ bits.)} There is an isomorphism $\rho_{k} : A_{k} \to \mathrm{End}_{\Q}(S_{k})$ with $\dim S_{k} = 2^{k}$, and $N_{k}(a) = \operatorname{rank}\rho_{k}(a)/2^{k}$. The values of $N_{k}$ are exactly $j/2^{k}$, $0 \le j \le 2^{k}$.
\item[(ii)] \emph{(Rules.)} $0 \le N_{k}(a) \le 1$; $N_{k}(a) = 0$ exactly when $a = 0$; $N_{k}(a) = 1$ exactly when $a$ is invertible; $N_{k}(a + b) \le N_{k}(a) + N_{k}(b)$; $N_{k}(\lambda a) = N_{k}(a)$ for $\lambda \ne 0$; $N_{k}(ab) \le N_{k}(a)$ and $N_{k}(ab) \le N_{k}(b)$; and $N_{k}(ab) + N_{k}(bc) \le N_{k}(b) + N_{k}(abc)$.
\item[(iii)] \emph{(Independence of the rung.)} $N_{k+1}(a) = N_{k}(a)$ for $a \in A_{k}$. So $N$ is a function on $T$, the \emph{size}.
\item[(iv)] \emph{(Separate switches multiply.)} If $I$, $J$ are disjoint, $a \in A_{I}$ and $b \in A_{J}$ is even, then $ab = ba$ and $N(ab) = N(a)\,N(b)$.
\item[(v)] \emph{(Null vectors and tests.)} Every nonzero vector $n$ in the span of the $e_{i}, f_{i}$ with $n^{2} = 0$ has $N(n) = \tfrac12$, and $N(\mathrm{on}_{i}) = N(\mathrm{off}_{i}) = \tfrac12$. For idempotents $e$, $f$ with $ef = fe = 0$, $N(e + f) = N(e) + N(f)$.
\item[(vi)] \emph{(Uniqueness.)} If $M : T \to \Q$ satisfies $M(0) = 0$, $M(1) = 1$, $M(a + b) \le M(a) + M(b)$, $M(ab) \le M(a)$, $M(ab) \le M(b)$ and $M(ab) + M(bc) \le M(b) + M(abc)$, then $M = N$.
\end{enumerate}

## technical
On the tower of algebras $\Cl_{\Q}(k,k)$, one switch per rung, attach to each element the fraction of the algebra it reaches by multiplication on the right. Each rung is the algebra of all linear maps on $k$ bits, and this fraction is the rank divided by $2^{k}$. It is $1$ exactly on the invertible elements, so its shortfall measures how far division by the element fails; a nonzero null vector, the element whose division the transport repairs, has size exactly one half. The size does not change when an element is carried up the tower, sizes of even elements on separate switches multiply, sizes of mutually exclusive tests add, and no other function has the same formal properties: the equal weighting of the configurations of the switches is forced.

## lay
Every element of the tower can be given a size between zero and one: the share of the whole algebra you can reach by multiplying by it. Size one means you can divide by it. The elements you cannot divide by have smaller sizes, and the simplest of them, the null directions, have size exactly one half. Two independent yes-or-no tests have sizes that multiply, like independent probabilities.

## one-liner
On $T = \bigcup_{k}\Cl_{\Q}(k,k)$ the size $N(a) = \dim(aA)/\dim A$ is the normalised rank: $1$ exactly on units, $\tfrac12$ on nonzero null vectors, independent of the rung, multiplicative for even elements on separate switches, additive on exclusive tests, and the only function obeying the rank inequalities with $N(0) = 0$, $N(1) = 1$.
