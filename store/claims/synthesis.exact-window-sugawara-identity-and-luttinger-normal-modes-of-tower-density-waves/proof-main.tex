\emph{Preliminaries.} By Theorem \claimref{std-algebra.witt-basis-car} the $v_{j}, w_{j}$ satisfy $v_{j}^{2} = w_{j}^{2} = 0$, $\{v_{j}, w_{k}\} = \delta_{jk}$ and distinct planes' generators anticommute; $n_{j} = v_{j}w_{j}$ are commuting idempotents with $[n_{l}, v_{j}] = \delta_{lj}v_{j}$ and $[n_{l}, w_{j}] = -\delta_{lj}w_{j}$, and $\hat Nw_{j} = w_{j}(\hat N - 1)$. Theorem \claimref{hawking.current-commutator-exactly-edge-split} gives, on a window, $[\rho_{q}, \rho_{q}^{*}] = \sum_{k < q}n_{k} - \sum_{k \ge L - q}n_{k}$, $[\rho_{q}, \rho_{q'}] = 0$, and for $q \ne q'$ a cross commutator $[\rho_{q'}, \rho_{q}^{*}]$ supported on the lowest and highest $\max(q, q')$ modes that annihilates every vector edge-clean at that depth (the lowest $\max(q, q')$ modes filled, the highest empty).

\emph{(i)} Moving $w_{j}$ past $v_{j'}$, $\rho_{q}^{*}\rho_{q} = \sum_{j, j'}v_{j + q}w_{j}v_{j'}w_{j' + q} = \sum_{j}n_{j + q} - \sum_{j, j'}v_{j + q}v_{j'}w_{j}w_{j' + q}$. Summed over $q \ge 1$, the first term counts each $n_{l}$ once for every $q$ with $1 \le q \le l$, giving $\sum_{l}l\,n_{l}$. In the second, write $\alpha = j + q$, $\beta = j'$, $\gamma = j$, $\delta = j' + q$: the sum over $q \ge 1$ and $j, j'$ is the sum $X$ of $v_{\alpha}v_{\beta}w_{\gamma}w_{\delta}$ over the quadruples in the window with $\alpha + \beta = \gamma + \delta$ and $\alpha > \gamma$, each once. Let $S$ be the same sum over all quadruples with $\alpha + \beta = \gamma + \delta$. Renaming $\gamma \leftrightarrow \delta$ preserves the index set and $w_{\gamma}w_{\delta} = -w_{\delta}w_{\gamma}$, so $S = -S = 0$. The part with $\alpha < \gamma$ has $\beta > \delta$, and the renaming $(\alpha, \beta, \gamma, \delta) \mapsto (\beta, \alpha, \delta, \gamma)$ maps it onto the part with $\alpha > \gamma$, with the sign $(-1)^{2} = 1$: it equals $X$. The part with $\alpha = \gamma$ (then $\beta = \delta$) is $D = \sum_{\alpha, \beta}v_{\alpha}v_{\beta}w_{\alpha}w_{\beta} = -\sum_{\alpha}v_{\alpha}\hat Nw_{\alpha} = -\sum_{\alpha}v_{\alpha}w_{\alpha}(\hat N - 1) = -\hat N(\hat N - 1)$. So $0 = 2X + D$, $X = \tfrac12\hat N(\hat N - 1)$ and $T = \sum_{l}l\,n_{l} - \tfrac12\hat N(\hat N - 1)$. With $j = k + M$, $H = \sum_{j}j\,n_{j} - (M - \tfrac12)\hat N + \tfrac12M^{2} = T + \tfrac12\hat N^{2} - M\hat N + \tfrac12M^{2} = T + \tfrac12\mathcal{Q}^{2}$. On the sea every $\rho_{q}$ vanishes (a fermion at $j + q$ would have to drop to an empty level $j < j + q$, and in the sea every level below a filled one is filled) and $\mathcal{Q} = 0$, so $H = 0$ there; $T$ is a sum of elements $\rho_{q}^{*}\rho_{q}$, nonnegative in every state, so $H \ge \tfrac12\mathcal{Q}^{2}$. If $\varepsilon_{j} = aj + b$, then $\sum_{j}\varepsilon_{j}n_{j} = aT + \tfrac{a}{2}\hat N(\hat N - 1) + b\hat N$. Conversely, on the one-particle vector $v_{j}\Omega_{0}$ ($\Omega_{0} = \prod_{l}w_{l}v_{l}$ the empty projector), $T$ acts as $j$ by the identity and $g(\hat N)$ as $g(1)$, so $\varepsilon_{j} = aj + g(1)$. The check verifies the identity as an equality of elements of $\Cl(L, L)$ for $L = 1, \dots, 6$, the sea form for even $L$, the one-particle values of $T$, and that weights $j^{2}$ are not of this form for $L \ge 3$.

\emph{(ii)} From $[n_{l}, v_{j}w_{j + q}] = (\delta_{lj} - \delta_{l, j + q})v_{j}w_{j + q}$, $[\sum_{l}\varepsilon_{l}n_{l}, \rho_{q}] = \sum_{j}(\varepsilon_{j} - \varepsilon_{j + q})v_{j}w_{j + q} = -q\rho_{q}$ for $\varepsilon_{l} = l + c$, and the adjoint gives $[H, \rho_{q}^{*}] = q\rho_{q}^{*}$. In $\Cl(L, L + 2)$, $J$ commutes with the plane generators and $J^{2} = -1$, so $e^{Jt\varepsilon n_{k}} = 1 + (e^{Jt\varepsilon} - 1)n_{k}$, the factors commute, and $(e^{JtH})^{*} = e^{-JtH}$ ($J^{*} = -J$, $H^{*} = H$). Since $J$ commutes with $H$ and $\rho_{q}^{*}$, $\operatorname{ad}(JtH)\rho_{q}^{*} = Jqt\,\rho_{q}^{*}$, and summing the exponential series of $\operatorname{ad}$ gives $e^{JtH}\rho_{q}^{*}e^{-JtH} = e^{Jqt}\rho_{q}^{*}$. The check verifies the commutators for $L = 2, 3, 4$, unitarity, and the phase $e^{Jqt}$ at the Pythagorean point $e^{Jt/2} = \tfrac35 + \tfrac45J$, and that weights $j^{2}$ give no such relation.

\emph{(iii)} In the $P$-spectral representation $h_{k}$ is $\Delta^{-1/2}$ times the indicator of $[k\Delta, (k + 1)\Delta)$, so $\ip{h_{k}}{Ph_{l}} = 0$ for $k \ne l$ (disjoint supports) and $\ip{h_{k}}{Ph_{k}} = \Delta^{-1}\int_{k\Delta}^{(k + 1)\Delta}p\,dp = \Delta(k + \tfrac12)$; tensoring with the unit vector $\eta$ changes nothing. The compression is therefore diagonal on the $g_{k}$ with these weights, and its second quantisation on the window is $\Delta\sum_{k}(k + \tfrac12)n_{k}$. By Theorem \claimref{synthesis.fluctuation-forms-of-the-tower-and-density-wave-bosons-of-the-null-vacuum}(vi) the restriction of $\omega_{0}$ (Theorem \claimref{synthesis.null-vacuum-on-a-horizon-generator}(ii), symbol $\chi_{(-\infty, 0)}(P)\otimes\id_{K}$) to the band modes is the product state with $n_{k} = 1$ for $k < 0$ and $0$ for $k \ge 0$, the sea, on which $H = 0$ and $\rho_{q} = 0$ by (i). On $\mathcal{D}$: a vector $\psi = x\Omega$ with $x$ a polynomial in modes of $[-K, K)$ is a combination of occupation vectors that agree with the sea outside $[-K, K)$. On such a vector $\rho_{q}$ acts only through terms $v_{k}w_{k + q}$ with $k \ge -K$ empty and $k + q < K$ filled, so it vanishes for $q \ge 2K$ and keeps the support in $[-K, K)$; $\rho_{q}^{*}$ acts through terms $v_{k + q}w_{k}$ with $k < K$ filled and $k + q \ge -K$ empty, so its result agrees with the sea outside $[-K - q, K + q)$. Hence on $\psi$ every operator in the display involves only modes of the window $[-3K, 3K)$ and coincides there with the window operators of (i) for $M = 3K$; $H_{\infty}\psi = H\psi$ and $\mathcal{Q}_{\infty}\psi = \mathcal{Q}\psi$ because the modes outside the window contribute $0$ to the normal-ordered sums on $\psi$. Identity (i) is an identity in the algebra of the window, so it holds in the representation of $\omega_{0}$, and gives $H_{\infty}\psi = (\tfrac12\mathcal{Q}_{\infty}^{2} + \sum_{q \ge 1}\rho_{q}^{*}\rho_{q})\psi$, the sum finite on $\psi$. The canonical relations $[\rho_{q}, \rho_{q'}^{*}] = q\delta_{qq'}$ on $\mathcal{D}$ are Theorem \claimref{synthesis.fluctuation-forms-of-the-tower-and-density-wave-bosons-of-the-null-vacuum}(vi). The check computes the band means $\Delta(k + \tfrac12)$ exactly for three widths and eight bands, the band occupations of the null vacuum, and $H = 0$, $\rho_{q} = 0$ on the window sea.

\emph{(iv)} The relabelling $k \mapsto -1 - k$ of the $L$ family maps its weights $-(k + \tfrac12)$, its sea $k \ge 0$ and its density modes $\rho_{L, q}$ to the weights, sea and density modes of an $R$ family, so the results above hold for both families. Operators of different families commute (even elements on disjoint planes). For one $q \in S$ and a vector $\psi$, compute with $[\rho^{*}_{q'}\rho_{q'}, \rho_{q}^{*}] = \rho_{q'}^{*}[\rho_{q'}, \rho_{q}^{*}]$ (as $[\rho_{q'}^{*}, \rho_{q}^{*}] = 0$) and $[\rho_{q'}^{*}\rho_{q'}, \rho_{q}] = [\rho_{q'}^{*}, \rho_{q}]\rho_{q'}$:
\[
[H, \rho_{R, q}^{*}] = q\rho_{R, q}^{*} + \sum_{q' \in S}\bigl(g_{4, q'}\rho_{R, q'}^{*}[\rho_{R, q'}, \rho_{R, q}^{*}] + g_{2, q'}[\rho_{R, q'}, \rho_{R, q}^{*}]\rho_{L, q'}\bigr),
\]
\[
[H, \rho_{L, q}] = -q\rho_{L, q} - \sum_{q' \in S}\bigl(g_{4, q'}[\rho_{L, q}, \rho_{L, q'}^{*}]\rho_{L, q'} + g_{2, q'}[\rho_{L, q}, \rho_{L, q'}^{*}]\rho_{R, q'}^{*}\bigr).
\]
On $\mathcal{D}$ the brackets are $q\delta_{qq'}$ and every operator maps $\mathcal{D}$ into itself ($S$ is finite), so $[H, \rho_{R, q}^{*}] = q(1 + g_{4, q})\rho_{R, q}^{*} + qg_{2, q}\rho_{L, q}$ and $[H, \rho_{L, q}] = -q(1 + g_{4, q})\rho_{L, q} - qg_{2, q}\rho_{R, q}^{*}$. Then $[H, \beta_{q}^{*}] = q\bigl((1 + g_{4, q}) - r_{q}g_{2, q}\bigr)\rho_{R, q}^{*} + q\bigl(g_{2, q} - r_{q}(1 + g_{4, q})\bigr)\rho_{L, q}$, which is a multiple of $\beta_{q}^{*}$ exactly when $g_{2, q} - r_{q}(1 + g_{4, q}) = r_{q}\bigl((1 + g_{4, q}) - r_{q}g_{2, q}\bigr)$, the stated quadratic. Its roots are real and distinct with product $1$ when $|g_{2, q}| < 1 + g_{4, q}$; the one of modulus less than $1$ is $r_{q} = \bigl((1 + g_{4, q}) - \sqrt{(1 + g_{4, q})^{2} - g_{2, q}^{2}}\bigr)/g_{2, q}$ ($r_{q} = 0$ if $g_{2, q} = 0$), and the multiple is $q\bigl((1 + g_{4, q}) - r_{q}g_{2, q}\bigr) = \omega_{q}$. Exchanging the roles of $R$ and $L$ gives $[H, \gamma_{q}^{*}] = \omega_{q}\gamma_{q}^{*}$. On a window, let $\psi$ be edge-clean at depth $\max S$ in both families (for $L$, in the relabelled order). The brackets in the displays act either on $\psi$, or on $\rho_{L, q'}\psi$ or $\rho_{R, q'}^{*}\psi$, which have the other family's occupations of $\psi$, or, for $[\rho_{L, q}, \rho_{L, q'}^{*}]\rho_{L, q'}\psi$, on $\rho_{L, q'}\psi$, which is still edge-clean in $L$ (a lowering density mode cannot fill an empty edge level of its own family or empty a filled one); so by the stored edge identities every bracket acts as $q\delta_{qq'}$ there and the computation above holds on $\psi$. The check verifies $[H, \beta^{*}]\psi = \tfrac65\beta^{*}\psi$ and $[H, \gamma^{*}]\psi = \tfrac65\gamma^{*}\psi$ for $S = \{1\}$, $g_{4} = \tfrac12$, $g_{2} = \tfrac{9}{10}$, $r = \tfrac13$, on all sixteen depth-one edge-clean vectors of two four-mode families, and that the relation fails on a vector that is not edge-clean.
