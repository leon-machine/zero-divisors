\emph{Setting.} $A$ and its generators are those of Theorem \claimref{tower.algebraic-limit-even-charge} and Proposition \claimref{tower.ladder-pairs-satisfy-car-vectors}; states are those of Premise \claimref{synthesis.premise-positivity-of-values}. A vector state of the Fock module (Theorem \claimref{tower.fock-module-one-qubit-per-rung}) satisfies (P). For $x$ involving only the first $n$ rungs, $\langle s_{\le m}, x\,s_{\le m}\rangle$ is the same for all $m \ge n$, since $x$ does not act on the later rungs; so $\omega_{s}$ is well defined, and it is a state.

\emph{(i).} The sign change of a set of generators preserves the defining relations, so it extends to an automorphism of each floor and of $A$, and it commutes with $\dagger$, which is defined generator by generator. The sign change of $f_{j}$ exchanges $v_{j}$ and $w_{j}$, hence $\mathrm{on}_{j}$ and $\mathrm{off}_{j}$, and fixes the other rungs' tests: it carries $\omega_{s}$ to the string state with the value at $j$ changed. Applying it at every rung where $s$ and $t$ differ, a finite set for $G_{1}$ and an arbitrary set for $G_{3}$, carries $\omega_{s}$ to $\omega_{t}$. For $G_{2}$: $e_{j}$ is an odd unitary with $e_{j}v_{j}e_{j} = w_{j}$, and it commutes with the tests of the other rungs, so conjugation by a product of $e_{j}$ over a finite set changes the values on that set. Conversely, an element of $G_{1}$ fixes every generator beyond some floor; and a unitary $u$ of the floor of the first $n$ rungs commutes with $\mathrm{on}_{j}$ for $j > n$, because $\mathrm{on}_{j}$ is an even element involving only rung $j$. In both cases the image of $\omega_{s}$ agrees with $\omega_{s}$ on the tests of all rungs beyond a floor, so if it is a string state $\omega_{t}$ then $t$ agrees with $s$ beyond that floor. Each tail class is countable and there are uncountably many strings. The step's symmetries in Theorem \claimref{synthesis.state-of-a-new-rung-unique-symmetric-extension-is-the-half-weight} are the sign changes of the two generators of one rung; $G_{3}$ is generated by these over all rungs, with infinitely many applied at once allowed. A unitary of a finite floor that is odd changes the sign of every generator beyond its floor, so it is not in $G_{1}$; it still commutes with the tests beyond its floor, which is what the argument uses. For $G_{4}$: a bijection $\pi$ of the rungs is an isometry of the quadratic space, so it induces an automorphism of $A$ commuting with $\dagger$, and it carries $\omega_{s}$ to the string state of the permuted string. Two strings with infinitely many rungs on and infinitely many off are related by a bijection matching the on rungs of one to those of the other and likewise the off rungs. A string with finitely many rungs on is carried by $G_{1}$ to the all-off string, which every permutation fixes; likewise for finitely many off. Whether the set of on rungs is finite, cofinite or neither is unchanged by permutations and by finite changes, so these are exactly three orbits. In each case, given a rung $j$ and a string in a class, changing the value at $j$ (an element of $G_{1}$, of $G_{2}$ and of $G_{3}$) stays in the class, so no single rung's value is constant on a class. The script checks the finite statements on three rungs, including a transposition of two rungs.

\emph{(ii).} $x$ is a combination of products of the $v_{i}$, $w_{i}$ of the rungs it involves; these do not change the occupation of any other rung, and occupation vectors with different occupations of a rung are orthogonal. The script verifies this for a full basis of the algebra on two rungs against all pairs of strings on four rungs. For the completed algebra: $\omega_{s}$ is the gauge-invariant quasi-free state whose operator is the diagonal projection with entries $s_{j}$, pure by clause (d) of Fact \claimref{synthesis.imported-powers-stormer-takesaki-disjointness}; the difference of two such projections is diagonal with entries $0, \pm 1$ and is Hilbert-Schmidt exactly when it has finitely many nonzero entries; clause (a) then gives quasi-equivalence exactly for strings in one tail class, and disjointness otherwise. The symmetric state is the gauge-invariant quasi-free state with operator $\tfrac12$, a factor state by clause (a); against a diagonal projection, the difference of the square roots is diagonal with every entry $\tfrac{1}{\sqrt2}$ or $\tfrac{1}{\sqrt2} - 1$, never zero, so it is not Hilbert-Schmidt and the symmetric state is disjoint from every string state. These statements apply the import and are not proved here.

\emph{(iii).} On a floor of $n$ rungs the invariant extension, iterated, is $x \mapsto \langle x\rangle_{0}$, whose density is $2^{-n}$ times $1$. A family of pairwise orthogonal idempotents with sum $1$, each with scalar part $2^{-n}$, has uniform average with density $2^{-n}\sum = 2^{-n}$: the same state. The $2^{n}$ string projectors are one such family. On two rungs the script verifies that the four stated elements are even, self-adjoint, idempotent, pairwise orthogonal, of scalar part $\tfrac14$ and sum $1$, that each gives two strings the weight $\tfrac12$, and that $\sum_{s}P_{s}\,\cdot\,P_{s}$ sends each to half the sum of two string projectors. The statement about the store is the last sentence of Proposition \claimref{singularity.p-reduced-metric-level-reading-many}: the reading that makes the joint-diagonal algebra the metric level is a choice between two assemblies, not decided there.

\emph{(iv).} With the data a string (or any fixed vector of a finite floor's module), $\omega_{\psi}(y) = \langle\psi \otimes \mathrm{data},\, y\,\psi \otimes \mathrm{data}\rangle$ on a floor containing the rungs $y$ involves, which is $a^{2}M_{00} + 2abM_{01} + b^{2}M_{11}$ with $M_{ij}$ the symmetrised values of $y$ between $\phi_{i} \otimes \mathrm{data}$ and $\phi_{j} \otimes \mathrm{data}$. Suppose $q \in \{0, 1\}$ at every rational point of the unit circle. There are infinitely many such points with pairwise different directions (from the Pythagorean triples), so one of the two values, $\nu$, is taken at infinitely many directions. On the unit circle $q - \nu = q - \nu(a^{2} + b^{2})$, a binary quadratic form that vanishes in infinitely many directions; a nonzero binary quadratic form vanishes in at most two. So $q = \nu(a^{2} + b^{2})$, constant on the circle. No continuity is used. For an automorphism $\alpha$ of $A$ and a test $E$, the weight of $E$ after $\alpha$ is $\omega_{\psi}(\alpha(E))$ with $\alpha(E) \in A$, so it is covered; a pointwise limit of quadratic forms in two variables is a quadratic form, since its three coefficients are determined by the values at three directions. Now suppose a rule assigns, for each value of the data, a definite outcome through such a value, and the data are distributed independently of $\psi$. For each value of the data the outcome is the same for all $\psi$, so the frequency of the first outcome does not depend on $\psi$; the weights of (P) for the two alternatives are $a^{2}$ and $b^{2}$, which do. The argument concerns rules whose outcome is the value of an element; a rule whose outcome is a function that is not linear of values, even of the value of one element (the rule of (v) is the sign of the value of $Y_{n} - \mathrm{on}_{1}$), is not covered. The script computes, for the four strings of a fresh pair, four couplings and five tests, the eighty forms, confirms each is the weight computed directly at seven rational directions, and that every form that is not a multiple of $a^{2} + b^{2}$ takes a value in $\{0, 1\}$ at no more than two of them (a form that is not such a multiple can do so in at most four directions, two for each value).

\emph{(v).} $Y_{n}$ is an element of $A$ with rational coefficients. In the joint state of $\psi = a\phi_{0} + b\phi_{1}$ and the string $s$, $\mathrm{on}_{d_{k}}$ has value $s_{k}$ and $\mathrm{on}_{1}$ has value $a^{2}$. The map $s \mapsto y(s) = \sum_{k}2^{-k}s_{k}$ is a bijection from the strings of $n$ values to the fractions $m/2^{n}$, $0 \le m < 2^{n}$. The number of $m$ with $m/2^{n} < a^{2}$ is $\lceil 2^{n}a^{2}\rceil$, and $a^{2} \le \lceil 2^{n}a^{2}\rceil/2^{n} < a^{2} + 2^{-n}$. The rule is the sign of the value of the one element $Y_{n} - \mathrm{on}_{1}$; its outcome is two-valued and not constant in $\psi$, so by (iv) it is not the value of any one element. The script (which numbers the rungs from $0$, the system on its rungs $0, 1$) computes both values in the Fock module for $n = 4$, all sixteen strings and four values of $a^{2}$, and the frequencies $\tfrac38$, $\tfrac{11}{16}$, $\tfrac{3}{16}$, $\tfrac14$ for $a^{2} = \tfrac{9}{25}$, $\tfrac{16}{25}$, $\tfrac{25}{169}$, $\tfrac{64}{289}$.

\emph{(vi).} The first index at which $b$ and $d$ differ is $k$ with probability $2^{-k}$, and it is then decided for the first outcome exactly when $d_{k} = 1$; so the probability is $\sum_{k}d_{k}2^{-k} = p$. The index exceeds $k$ with probability $2^{-k}$, and $\sum_{k \ge 0}2^{-k} = 2$. A function of $n$ unbiased values has probabilities with denominator $2^{n}$. Comparison with (v): if the first difference between $s$ and the digits of $a^{2}$ is at $k \le n$, then $y(s) < a^{2}$ exactly when $s_{k} < d_{k}$, since the digits before $k$ agree and, $a^{2}$ not being dyadic, the remaining digits of $a^{2}$ are neither all $0$ nor all $1$; if there is none, $y(s)$ is the truncation of $a^{2}$ to $n$ digits, which is below $a^{2}$. The script computes the twenty digits of $\tfrac{9}{25}$, confirms the period and the sum, enumerates all $4096$ prefixes of length $12$ exactly, confirms that $2^{k}\cdot\tfrac{9}{25}$ is not an integer for $k \le 40$, and confirms the agreement with the rule of (v) on all sixteen strings for the four values of $a^{2}$. That the unbiased values could be the values of unread rungs is the reading of clause (iv) of Theorem \claimref{synthesis.selector-candidates-on-the-tower-integer-states-parity-deterministic-laws}; that the tower has no clock is Proposition \claimref{tower.answers-iteration-question}; the limiting branch states with complete records are those of Theorem \claimref{synthesis.records-of-unbounded-length-on-the-tower-interference-factor-and-limit}(iii) with $c = 0$, in which branch $A$ has each pair's quantum on its second rung and branch $B$ on its first.
