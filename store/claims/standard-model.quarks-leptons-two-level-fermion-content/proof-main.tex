Write the $U(1)$ factor as $(A, B) = (\lambda^{3}a, \lambda^{-2}b)$ with $a \in SU(2)$, $b \in SU(3)$, as in Theorem \claimref{standard-model.global-form-quotient-determined}. (1) On $\C^{2} \otimes \C^{3}$ it acts as $\lambda^{3}\lambda^{-2}\,(a \otimes b) = \lambda\,(a \otimes b)$: the $SU(2) \times SU(3)$ content is $(2,3)$ and the weight is $3 - 2 = 1$, so $Y = 1/6$. (2) Under (S, \claimref{standard-model.hyp-s-slot-statistics}), $\Lambda^{\bullet}(\C^{2} \oplus W) = \bigoplus_{j,k}\Lambda^{j}\C^{2} \otimes \Lambda^{k}W$ (Fact \claimref{standard-model.imported-cauchy-decomposition-exterior-power}), and on the $(j, k)$ component the $U(1)$ factor acts by $\lambda^{3j - 2k}$. The $SU(3)$-invariant lines of $\Lambda^{\bullet}W$ are $\Lambda^{0}W$ and $\Lambda^{3}W$ (Fact \claimref{standard-model.imported-pair-systems-two-chirality-halves}), on which $b$ acts trivially; so the $(1, 0)$ component is $\lambda^{3}a \otimes 1$, content $(2,1)$, weight $3$, and the $(1, 3)$ component is $\lambda^{3}a \otimes \det(\lambda^{-2}b) = \lambda^{-3}a$, content $(2,1)$, weight $-3$. The negative clause: by Proposition \claimref{standard-model.raw-representation-content-state-space}, $(2,1)$ occurs in no degree of \eqref{eq:fock}; and the row-filling states are the image of the cubic map $v \mapsto \bigwedge_{a}(v \otimes f_{a})$, whose $SU(2)$-span is $S^{3}\C^{2} \otimes \Lambda^{3}\C^{3}$ (the map is the composite of $v \mapsto v^{\otimes 3}$ with the projection to $\Lambda^{3}$, and its image spans the symmetric cube), the $(4,1)$ of degree three, of weight $3$ since three cells are occupied. The script confirms this: with the unipotent $A(s)$ acting on the slot index, the transform of a filled row has components on four independent degree-three states with coefficients $s^{3}, s^{2}, s, 1$, so the $SU(2)$-span has rank four and is not a doublet. (3) The pair-slot factor alone acts on a single conformal spinor's pair system, $\lambda^{-2}b$ on $W = \C^{3}$ (a lone conformal spinor occupies no slot; under (S) this is the row $j = 0$, and without (S) it is the definition of the sector of a single conformal spinor); on $\Lambda^{k}W$ it acts as $\lambda^{-2k}\Lambda^{k}b$, so the content is $\Lambda^{k}\C^{3}$, which is $1, 3, \bar{3}, 1$ (Fact \claimref{standard-model.imported-cauchy-decomposition-exterior-power}, $\Lambda^{2}\C^{3} \cong \bar{3}$), with weight $-2k$. Lattice membership, $2t + 3\delta + q \equiv 0 \pmod 6$: for (1), $t = 1$, $\delta = 1$, $q = 1$: $2 + 3 + 1 = 6$; for (2), $t = 0$, $\delta = 1$, $q = \pm 3$: $3 \pm 3 \in \{0, 6\}$; for (3), $(t, \delta, q) = (0, 0, 0), (1, 0, -2), (-1, 0, -4), (0, 0, -6)$: $0, 0, -6, -6$. The script builds the generator $\mathsf{y}$ as an exact matrix on each of these spaces and reads off the weights $1$, $3$, $-3$ and $0, -2, -4, -6$, and confirms the lattice residues.
