(1) is Fact \claimref{neutrino.imported-derived-content-singlets}. (2) Write $(a, b, c, d, e, f)$ for the hypercharges of $(Q, u^{c}, d^{c}, L, e^{c}, N)$ with multiplicities $(6, 3, 3, 2, 1, 1)$. The four sums are $A_{3} = 2a + b + c$, $A_{2} = 3a + d$, $A_{g} = 6a + 3b + 3c + 2d + e + f$, $A_{c} = 6a^{3} + 3b^{3} + 3c^{3} + 2d^{3} + e^{3} + f^{3}$ (the letter $A$ for anomaly sum, local to this proof). The three linear conditions give $d = -3a$, $b + c = -2a$, $e = 6a - f$. Put $p = bc$; then $b^{3} + c^{3} = (b + c)^{3} - 3p(b + c) = -8a^{3} + 6ap$, and the cubic condition becomes $6a^{3} + 3(-8a^{3} + 6ap) - 54a^{3} + (6a - f)^{3} + f^{3} = 18a\,(8a^{2} + p - 6af + f^{2}) = 0$. With $a \neq 0$ this is $p = -8a^{2} + 6af - f^{2}$, so $b, c$ are the roots of $y^{2} + 2ay + p = 0$, whose discriminant is $4a^{2} - 4p = 4(3a - f)^{2}$: $\{b, c\} = \{2a - f, f - 4a\}$. Hence the complete solution set is $(a, 2a - f, f - 4a, -3a, 6a - f, f)$ with $a \neq 0$ and $f$ free (up to the $b, c$ swap), which is linear in $(a, f)$: it is $a\,(1, 2, -4, -3, 6, 0) + f\,(0, -1, 1, 0, -1, 1)$. The first vector is $6Y$ with $b, c$ swapped, and the second is $(B - L) - 2Y$ with $b, c$ swapped ($(\tfrac13, -\tfrac13, -\tfrac13, -1, 1, 1) - (\tfrac13, -\tfrac43, \tfrac23, -1, 2, 0) = (0, 1, -1, 0, -1, 1)$), so the solution set is exactly $\{sY + t(B - L)\}$ with $s = 6a - 2f$, $t = f$, and $Y_{Q} = a \neq 0$. Up to normalisation, $s \neq 0$ gives the family $Y + t(B - L)$ and $s = 0$ (that is $f = 3a$) gives the ray of $B - L$, which is anomaly-free with $Y_{Q} = \tfrac13 \neq 0$ and is not a rescaling of any member of the family, since $Y_{N}/Y_{Q} = 6t/(1 + 2t)$ along the family never reaches the ray's value $3$. The script verifies that every point of the closed form satisfies all four sums for several $(a, f)$, the linear decomposition, the family at $t = 1, -1, 2, \tfrac57$ with $Y_{N} = t$ (four of the six values T12 runs; $t = 0$ is the derived spectrum and $t = -\tfrac12$ has $Y_{Q} = 0$), the ray $B - L$ itself with $Y_{N}/Y_{Q} = 3$ and its non-membership of the family, and the vanishing of the two mixed cubic coefficients $\sum n_{i}Y_{i}^{2}(B - L)_{i}$ and $\sum n_{i}Y_{i}(B - L)_{i}^{2}$, so the cubic sum is identically zero along the family. Uniqueness at $Y_{N} = 0$: $f = 0$ gives $\{b, c\} = \{\tfrac13, -\tfrac23\}$, $d = -\tfrac12$, $e = 1$, Fact \claimref{neutrino.imported-derived-content-singlets}'s spectrum.
