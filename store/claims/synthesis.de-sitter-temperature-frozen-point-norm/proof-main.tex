Fix a mode $j$ and drop its index. By (P, \claimref{singularity.p-univalence}) the state is even, so it vanishes on the odd elements $v$ and $v^{*}$; the argument of Theorem \claimref{singularity.ascended-marginals-are-diagonal} is mode-level and gives that the marginal is $\operatorname{diag}(1 - n, n)$ in the number basis, $n := \omega(v^{*}v) \in [0,1]$. The static Killing flow acts on the pair by $\alpha_{t}(v) = e^{-\hat{I}t\omega}v$ and $\alpha_{t}(v^{*}) = e^{\hat{I}t\omega}v^{*}$, with $\hat{I}$ the complex unit of the boundary-mode algebra, the central unit of the odd extension of the modes' Clifford algebra (Definition \claimref{obj.synthesis.cosmological-horizon-boundary-modes}; \claimref{std-algebra.complexification-is-the-odd-extension}): by Theorem \claimref{synthesis.cosmological-horizon-completed-pair}(iii) the pair's occupation boost is the unit static boost $u$, $K = u/2 = N - \tfrac12$ and $Kv = v(K - 1)$, as recorded in Definition \claimref{obj.synthesis.cosmological-horizon-boundary-modes}.

Take $a = v^{*}$, $b = v$ in (R$_{\Lambda}$, \claimref{synthesis.r-lambda-regularity-cosmological-horizon}): $F(t) = \omega(v^{*}\alpha_{t}(v)) = e^{-\hat{I}t\omega}n$ and $\omega(\alpha_{t}(v)v^{*}) = e^{-\hat{I}t\omega}(1 - n)$, so the gluing at $p = 2\pi/\kappa_{\Lambda}$ reads
\[
e^{p\omega}\,n \;=\; 1 - n \qquad\Longleftrightarrow\qquad n \;=\; \frac{1}{e^{p\omega} + 1} .
\]
The pair $a = v$, $b = v^{*}$ gives the same equation with $n$ and $1 - n$ exchanged and $p\omega$ negated, hence the same solution, and $a = b$ gives $0 = 0$ since $Q(v) = 0$. So the marginal is $\operatorname{diag}(1, e^{-p\omega})/(1 + e^{-p\omega}) = e^{-p\omega K}/Z$, which by Theorem \claimref{singularity.descended-form-state-independent} is the Gibbs state of $K$ at $\beta = p$, and by Theorem \claimref{singularity.kms-uniqueness-factor} the only KMS state of the flow at that $\beta$. The period is $p = 2\pi/\kappa_{\Lambda}$ with $\kappa_{\Lambda} = H$ and $\kappa_{\Lambda}^{2} = B_{\Lambda}^{2} = Q(I_{\Lambda}) = \Lambda/3$ (Proposition \claimref{synthesis.de-sitter-static-boost-frozen-point}(iii)), so $T_{\Lambda} = 1/\beta = \kappa_{\Lambda}/2\pi$. Faithfulness is $0 < n < 1$: the Gibbs matrix has full rank, so the marginal is faithful on the mode factor, hence cyclic and separating, which is hypothesis (iii) of Theorem \claimref{singularity.modular-descent}. The boundary cases $n = 0$ and $n = \tfrac12$ fail the gluing for every finite $p$ and $\omega > 0$. Every mode meets the same Euclidean section with the same $\kappa_{\Lambda}$, which is one number for the whole bifurcation sphere, since its normal plane is the one ambient plane $\Pi_{\Lambda}$ at every point (Theorem \claimref{synthesis.cosmological-horizon-completed-pair}(ii)); so the temperature is the same at every mode, with no condition on the joint state.

Finally $\beta H = (2\pi/H)\,H = 2\pi$.
