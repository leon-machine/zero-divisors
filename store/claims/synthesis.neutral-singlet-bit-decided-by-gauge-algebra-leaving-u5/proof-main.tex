\emph{(i).} On the five-mode module of Theorem \claimref{standard-model.hyp-s-slot-statistics}, with $Y = \sum_{k} y_{k} n_{k}$, $y_{k} = \tfrac12$ on the slots and $-\tfrac13$ on the pairs, $[Y, a^{\dagger}_{i}a_{j}] = (y_{i} - y_{j})a^{\dagger}_{i}a_{j}$, $[Y, a^{\dagger}_{i}a^{\dagger}_{j}] = (y_{i} + y_{j})a^{\dagger}_{i}a^{\dagger}_{j}$ and $[Y, a_{i}a_{j}] = -(y_{i} + y_{j})a_{i}a_{j}$. The differences $y_{i} - y_{j}$ are $0$ and $\pm\tfrac56$; the sums $y_{i} + y_{j}$ are $1$ (two slots), $\tfrac16$ (slot and pair) and $-\tfrac23$ (two pairs). The three sets $\{0, \pm\tfrac56\}$, $\{1, \tfrac16, -\tfrac23\}$, $\{-1, -\tfrac16, \tfrac23\}$ are disjoint, so each eigenspace of $\mathrm{ad}\,Y$ on $\so(10)$ lies in $\uu(5)$, in the creation span or in the annihilation span. \emph{(ii).} Every bilinear changes $N$ by an even amount, so $(-1)^{N}$ commutes with $\so(10)$, and $\Gamma'$, which differs from it only by the projectors onto $\Omega$ and $\Omega^{\top}$ (both annihilated by every $a^{\dagger}_{i}a_{j}$ with $i \ne j$ and eigenvectors of every $n_{i}$), commutes with $\uu(5)$. Write an involution as $s(-1)^{N}$ on the thirty charged states and $\Gamma\Omega = a\Omega + c\Omega^{\top}$, $\Gamma\Omega^{\top} = b\Omega + d\Omega^{\top}$. Then $x\Omega$ is a nonzero charged state of degree two, $x\Omega^{\top} = 0$, so $[\Gamma, x]\Omega = s\,x\Omega - a\,x\Omega$ gives $a = s$. For $\varphi$ the degree-three state on the complement of $\{i, j\}$, $x\varphi = \pm c_{ij}\Omega^{\top}$ and $\Gamma x\varphi = \pm c_{ij}(b\Omega + d\Omega^{\top})$, while $x\Gamma\varphi = -s\,x\varphi$ has no $\Omega$ component; so $b = 0$ and $d = -s$. The entry $c$ is not constrained by $x$ (the involution with $c = 1$ commutes with the Standard Model and with $x$; checked). For $x^{\dagger}$, a pure annihilation element, $x^{\dagger}\Omega = 0$ and $x^{\dagger}\Omega^{\top} \ne 0$ is charged, so $[\Gamma, x^{\dagger}]\Omega = -c\,x^{\dagger}\Omega^{\top}$ gives $c = 0$. Hence $\Gamma = s(-1)^{N}$. Injectivity: for $x$ a nonzero creation element, $[\Gamma', x]\Omega = (+1 - (-1))x\Omega = 2x\Omega \ne 0$, and $x \mapsto x\Omega = \sum c_{ij}e_{i} \wedge e_{j}$ is injective; for annihilation elements use $\Omega^{\top}$; the creation and annihilation images lie in different degrees. The check solves the affine system for $(a, b, c, d)$ for every one of the ten basis pairs $x, x^{\dagger}$ and both $s$, finds rank $4$ with the solution $(s, 0, 0, -s)$, rank $3$ for $x$ alone, rank $2$ with $N$ in place of $x$ (diagonal block), rank $0$ for the Standard Model alone, and rank $20$ for the twenty columns of $[\Gamma', \cdot]$.

\emph{(iv).} The pairing $B$ of Lemma \claimref{standard-model.invariant-pairing-five-modes} pairs the state on a mode set $S$ only with the state on the complement, so $B(\psi, X\varphi) \ne 0$ needs $N(\psi) + N(X\varphi) = 5$.
