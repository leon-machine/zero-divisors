\emph{$B_k \cong \Cl(k,k)$.} The $2k$ generators are orthonormal for the split form ($e_j^2 = 1$, $f_j^2 = -1$, pairwise orthogonal), so the universal property (\claimref{std-algebra.existence-uniqueness}) gives a surjection $\Cl(k,k) \to B_k$; it is injective because the $2^{2k}$ blades in the letters $e_1, f_1, \dots, e_k, f_k$ are part of the blade basis of $T_k$ (\claimref{std-algebra.blade-basis}), hence independent. \emph{$\Cl(k,k) \cong \Mat_{2^k}(\R)$} by induction using the series' own results: $\Cl(0,0) = \R$, and $\Cl(j{+}1,j{+}1) \cong \Mat_2(\Cl(j,j))$ is Fact \claimref{transport.rule-1-morita-trivial} with base $\Cl(j,j)$, the $(j{+}1)$-st plane carrying the outer index, so $\Cl(k,k) \cong \Mat_2(\Mat_2(\cdots)) = \Mat_{2^k}(\R)$.

\emph{$A_k \cong \Cl(p,q)$.} By Lemma \claimref{tower.volume-elements-planes}, $\Omega_k$ commutes with ground generators and $\Omega_k^2 = 1$, so for ground generators $x, y$:
\[
x^{(k)} y^{(k)} + y^{(k)} x^{(k)} = x \Omega_k y \Omega_k + y \Omega_k x \Omega_k = (xy + yx)\,\Omega_k^2 = 2B(x,y) .
\]
The universal property gives an algebra map $\Cl(p,q) \to A_k$, $x \mapsto x^{(k)}$; it sends the base blade $x_I$ to $x_I\,\Omega_k^{|I| \bmod 2}$, and these images are distinct nonzero blades (times a fixed invertible even element), hence independent: the map is an isomorphism onto $A_k$.

\emph{Commutation.} For a ground generator $x$ and any plane generator $g \in \{e_j, f_j\}$: $x$ anticommutes with $g$, and $\Omega_k$ anticommutes with $g$ (Lemma \claimref{tower.volume-elements-planes}), so $x^{(k)} g = x \Omega_k g = -x g \Omega_k = g x \Omega_k = g x^{(k)}$. Generators commute, hence the subalgebras do.

\emph{Multiplication is an isomorphism.} Commutation makes $A_k \otimes B_k \to T_k$ an algebra map. It is surjective: its image contains every plane generator, contains $\Omega_k \in B_k$, and therefore contains each ground generator $x = x^{(k)} \Omega_k$. Source and target both have dimension $2^n \cdot 2^{2k} = 2^{n + 2k}$, so a surjective linear map is an isomorphism. Finally $\Cl(p,q) \otimes \Mat_{2^k}(\R) = \Mat_{2^k}(\Cl(p,q))$. Canonicity: the construction used only the ordered orthogonal planes and their volume elements, no basis choices in the ground algebra. The compatibility with $\iota_k$ is Lemma \claimref{tower.grade-twist-when-it-inner} below: under these identifications $\iota_k$ is the twisted diagonal, the twist being conjugation by $\Omega$-data that Section \ref{sec:limit} tracks.
