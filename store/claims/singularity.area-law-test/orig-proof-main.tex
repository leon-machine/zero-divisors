$N_{\mathrm{6a}} = (dN_{\mathrm{6a}}/dt)\,\Delta t = 8\pi\nu M\,\Delta t$ at leading order by Proposition \claimref{singularity.stretched-singularity-count}, so $C = 8\pi\nu M\,\Delta t\,\ln 2$, and $C = 4\pi M^{2}$ if and only if $\nu\,\Delta t\,\ln 2 = M/2$. The lifetime count uses the evaporation time $\sim M^{3}$ in place of $\Delta t$. The script verifies the calibration with $\ln 2$ carried as a formal indeterminate: under $\nu\,\Delta t = M/(2\ln 2)$ the capacity equals $4\pi M^{2}$ identically, and the alternative 1-nat convention $\nu\,\Delta t = M/2$ misses it by the factor $\ln 2$ exactly, a $31$ per cent discrepancy no ``$\approx$'' should conceal.
