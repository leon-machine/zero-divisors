$C$ is closed under products and $E_{11}$ is its unit since $E_{11}^{2} = E_{11}$. Each entry $E_{1i} b E_{j1} = E_{11}(E_{1i} b E_{j1})E_{11}$ lies in $C$. $\Phi$ is linear and unital: $\Phi(1)_{ij} = E_{1i}E_{j1} = \delta_{ij}E_{11}$. It is multiplicative: $\sum_k \Phi(a)_{ik}\Phi(b)_{kj} = \sum_k E_{1i} a E_{k1} E_{1k} b E_{j1} = E_{1i}\, a \bigl(\sum_k E_{kk}\bigr) b\, E_{j1} = \Phi(ab)_{ij}$. With $\Psi(c) = \sum_{i,j} E_{i1} c_{ij} E_{1j}$: $\Psi\Phi(b) = \sum_{i,j} E_{ii} b E_{jj} = b$, and $\Phi\Psi(c)_{kl} = \sum_{i,j} E_{1k}E_{i1}c_{ij}E_{1j}E_{l1} = E_{11}c_{kl}E_{11} = c_{kl}$. For $\Cl(1,1)$: $f^{2} = -e_1^{2}e_2^{2} = 1$, so $\varepsilon_\pm$ are orthogonal idempotents summing to $1$; $e_1$ anticommutes with $f$ (\claimref{std-algebra.orthogonal-anticommute}), so $e_1 \varepsilon_\pm = \varepsilon_\mp e_1$, and the relations follow from $e_1^{2} = 1$, e.g. $E_{12}E_{21} = \varepsilon_+ e_1 \varepsilon_- e_1 = \varepsilon_+ e_1^{2} = \varepsilon_+$. The corner $\varepsilon_+ \Cl(1,1) \varepsilon_+$ is spanned by $\varepsilon_+$ (since $\Phi$ is an isomorphism, $\dim A = m^{2} \dim C$; here $\dim \Cl(1,1) = 4$ by \claimref{std-algebra.blade-basis} and $m = 2$, so $\dim C = 1$), so $C = \R$; in $\Cl(1,1,1)$ the null generator $e_3$ commutes with $f$, $\dim C = 8/4 = 2$ by the same count, and the corner is spanned by $\varepsilon_+$ and $\varepsilon_+ e_3$, with $(\varepsilon_+ e_3)^{2} = 0$.
