Write $J_{a}$ ($a = 1, 2, 3$) for the principal $\mathfrak{su}(2)$ on $\C^{n}$ of Theorem \claimref{scrambling.principality-indifference-sphere}, irreducible of spin $j = (n-1)/2$, and $\hat{X} = \sum_{ij}X_{ij}E_{ij}$. By the $\mathfrak{gl}(n)$ relations of Proposition \claimref{scrambling.boundary-mode-space-matrix}, $[\hat{X}, \hat{Y}] = \widehat{[X, Y]}$, and $X \mapsto \hat{X}$ is injective (it restricts to $X$ on the one-particle space).

(i) By $[\hat{h}, \hat{J}_{a}] = \widehat{[h, J_{a}]}$ and injectivity, $\hat{h}$ commutes with every $\hat{J}_{a}$ exactly when $h$ commutes with every $J_{a}$, that is, when $h$ is an invariant of the adjoint action on $\Mat_{n}$. By Fact \claimref{scrambling.imported-kostant-madore-partition-data}(ii) that action is $\bigoplus_{\ell=0}^{n-1}(2\ell+1)$ with a single spin-$0$ summand, which contains $\id$; so the invariants are $\C\,\id$ and $h = \omega\,\id$, $\hat{h} = \omega N_{\mathrm{tot}}$. A gauge-invariant quasi-free state is fixed by its symbol $Q$, $\omega(\psi_{i}^{\dagger}\psi_{j}) = Q_{ji}$ (Fact \claimref{hawking.imported-quasi-free-states-car-algebra}); a rotation $u = e^{i\theta^{a}J_{a}}$ acts on the modes as a one-particle unitary and on the symbol by $Q \mapsto uQu^{\dagger}$, so invariance under all rotations makes $Q$ an adjoint invariant, $Q = q\,\id$, and the state is $\rho_{q}$. Every counted mode then has the marginal $\operatorname{diag}(1 - q, q)$; if it is KMS for $\omega N_{\mathrm{tot}}$ at $\beta = 2\pi/\kappa$, as (R) requires mode by mode, $q = 1/(e^{x} + 1)$ with the one value $x = 2\pi\omega/\kappa$, each mode carries $s(x)$ (Theorem \claimref{synthesis.boundary-mode-thermal-entropy}), $\langle s\rangle = s(x)$, and Theorem \claimref{synthesis.residue-from-mode-entropy}(i) gives $\kappa_{c} = 1/(4s(x))$. For the last sentence: $N_{\mathrm{tot}}^{2}$ commutes with the rotations and is not in $\operatorname{span}\{\id, N_{\mathrm{tot}}\}$ for $n \ge 2$; the script computes the full Fock commutant, of dimension $5$ at $n = 2$ and $8$ at $n = 3$.

(ii) $[N_{\mathrm{tot}}, E_{ij}] = \widehat{[\id, e_{ij}]} = 0$, so $N_{\mathrm{tot}}$ commutes with the algebra $\mathcal{A}_{0}$ the $E_{ij}$ generate, and it lies in $\mathcal{A}_{0}$: it is central. Hence $\operatorname{Ad}(e^{it\omega N_{\mathrm{tot}}})$ is the identity on $\mathcal{A}_{0}$ for all $t$ and $\omega$. On the Fock space $\rho_{q}$ has density matrix $D_{q} = q^{N_{\mathrm{tot}}}(1 - q)^{n - N_{\mathrm{tot}}}$ (the product state of Fact \claimref{hawking.imported-quasi-free-states-car-algebra} on a window), a function of $N_{\mathrm{tot}}$, so it commutes with $\mathcal{A}_{0}$ and $\rho_{q}(AB) = \operatorname{tr}(D_{q}AB) = \operatorname{tr}(BD_{q}A) = \rho_{q}(BA)$ for $A, B \in \mathcal{A}_{0}$: the restriction is tracial. A tracial state satisfies the KMS condition for the trivial flow at every $\beta$, since then $F_{A,B}(t) = \rho_{q}(AB)$ is constant and equals $\rho_{q}(BA)$. Finally $\rho_{q}(N_{\mathrm{tot}}) = nq$, so distinct $q$ give distinct states on $\mathcal{A}_{0}$. Thus the data on $\mathcal{A}_{0}$ (the restricted flow, trivial, and the KMS condition, satisfied by all $\rho_{q}$) leave $q$, and with it $\omega$ at fixed $\beta$, undetermined; the argument from the trivial restriction to $q = \tfrac12$ has a false premise.

(iii) In the standard basis $|j, m\rangle$, $J_{3} = \operatorname{diag}(m)$ and $(J_{+})_{m+1,m} = c(m) = \sqrt{(j - m)(j + m + 1)}$, with $c(-m-1) = c(m)$ and $J_{-} = J_{+}^{T}$. The matrix $\varepsilon_{m,m'} = (-1)^{j-m}\delta_{m,-m'}$ is a signed permutation, so an orthogonal matrix; since $(-1)^{j+m} = (-1)^{2j}(-1)^{j-m}$, $\varepsilon^{T} = (-1)^{2j}\varepsilon$, so the bilinear form it defines is symmetric for integer $j$ and symplectic for half-integer $j$, and $\varepsilon^{2} = (-1)^{2j}\id$. It satisfies $\varepsilon X + X^{T}\varepsilon = 0$ for $X = J_{3}, J_{\pm}$: for $J_{3}$ the $(m, -m)$ entry is $(-1)^{j-m}(-m + m) = 0$; for $J_{+}$ the only possibly nonzero entries are at $(a, b)$ with $a = -b - 1$, where they are $(-1)^{j+b+1}c(b) + (-1)^{j+b}c(-b-1) = 0$, and $J_{-}$ follows by transposition. Over $\C$ the identity extends to $J_{1}, J_{2}$. Set $C(\psi_{i}) = \sum_{k}\varepsilon_{ik}\psi_{k}^{\dagger}$; since $\varepsilon\varepsilon^{T} = \id$ the images satisfy the CAR, so $C$ is a Bogoliubov automorphism. Then $C(E_{ij}) = \sum_{kl}\varepsilon_{ik}\varepsilon_{jl}\psi_{k}\psi_{l}^{\dagger} = \delta_{ij} - \sum_{kl}\varepsilon_{ik}\varepsilon_{jl}E_{lk}$, so $C(\hat{X}) = \operatorname{tr}(X) - \widehat{(\varepsilon^{T}X\varepsilon)^{T}}$. For $X = J_{a}$: $\operatorname{tr}J_{a} = 0$ and $J_{a}^{T} = -\varepsilon J_{a}\varepsilon^{T}$, so $(\varepsilon^{T}J_{a}\varepsilon)^{T} = \varepsilon^{T}J_{a}^{T}\varepsilon = -J_{a}$ and $C(\hat{J}_{a}) = \hat{J}_{a}$. For $X = \id$: $C(N_{\mathrm{tot}}) = n - N_{\mathrm{tot}}$. A Bogoliubov automorphism carries quasi-free states to quasi-free states; $\rho_{q}\circ C$ has $\rho_{q}(C(\psi_{i}^{\dagger}\psi_{j})) = \sum_{kl}\varepsilon_{ik}\varepsilon_{jl}(\delta_{kl} - q\delta_{kl}) = (1 - q)\delta_{ij}$ and $\rho_{q}(C(\psi_{i}\psi_{j})) = \sum\varepsilon_{ik}\varepsilon_{jl}\rho_{q}(\psi_{k}^{\dagger}\psi_{l}^{\dagger}) = 0$, so it is gauge invariant with symbol $(1 - q)\id$: $\rho_{q}\circ C = \rho_{1-q}$ by the uniqueness clause of Fact \claimref{hawking.imported-quasi-free-states-car-algebra}. Since $C^{2}(\psi_{i}) = \sum_{k}\varepsilon_{ik}C(\psi_{k}^{\dagger}) = \sum_{l}(\varepsilon^{2})_{il}\psi_{l} = (-1)^{2j}\psi_{i}$, $C$ is an involution for integer $j$ and squares to the parity automorphism for half-integer $j$; none of the following uses $C^{2} = \id$. Hence $\rho_{q}\circ C = \rho_{q}$ if and only if $q = \tfrac12$, which under the KMS relation of (i) is $x = 0$, $\omega = 0$. By Theorem \claimref{synthesis.residue-from-mode-entropy}(ii), equality $\kappa_{c} = 1/(4\ln 2)$ holds exactly when every counted mode has zero weight, which under (i) is $q = \tfrac12$, which is $C$-invariance. The direction from $C$-invariance uses only rotation and gauge invariance: for any such state $\omega$ the two-point matrix is $q\,\id$ by the argument of (i) (which uses only invariance of the symbol), and $\omega\circ C = \omega$ gives $q = \omega(C(E_{ii})) = 1 - q$.

(iv) On $n = 2j + 1$, $h = 2J_{3}$ has spectrum $\{2m\}$, so $\kappa h/2$ has spectrum $\kappa\{-j, \ldots, j\}$, the weights of Premise \claimref{singularity.q-joint-quasi-freeness-s-wave} on a window centred at the sea level; these are $n$ distinct values, while by (i) a rotation-invariant quasi-free generator has one, and $[h, J_{\pm}] = \pm 2J_{\pm} \neq 0$.

For the closing remark: Definition \claimref{obj.hawking.boundary-mode-algebra-windows-boost-dynamics} takes $\omega_{j} > 0$; with (i) the common weight is then positive, $q < \tfrac12$, $s(x) < \ln 2$, and $\kappa_{c} = 1/(4s(x)) > 1/(4\ln 2)$.
