## formal
The flag acts on every oriented tower's modes at one strength, $\epsilon_{r} = \epsilon$ per mode (not equal mode counts or masses). A theorem for the mirror (Theorem \claimref{dark-matter.mirror-tower-copy-one}(v)), void for the odd residues (Corollary \claimref{dark-matter.which-towers-can-carry-arrow}), a premise only on the fork $r = 0$.

## technical
The Witt flag acts on the modes of every oriented tower at one strength, an asymmetry $\epsilon_{r} = \epsilon$ per mode; the premise equates the asymmetry per mode, not mode counts or masses. For the mirror tower it is a theorem, for the odd residues it is void since they cannot be oriented, and it is a genuine premise only on the fork $r = 0$.

## lay
The universe's slight excess of matter over antimatter is assumed to be imprinted equally, particle type by particle type, in every sector able to carry such an excess. For the mirror copy of our world this is proved separately, so the assumption does real work in only one remaining case.

## one-liner
Premise: the flag imprints the same asymmetry $\epsilon$ per mode on every oriented tower.
