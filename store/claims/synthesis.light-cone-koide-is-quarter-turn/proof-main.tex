\emph{(i)} $P_{s}$ and $P_{d}$ are real, symmetric, complementary projectors, so $D_{a,b}^{-1} = a^{-1}P_{s} + b^{-1}P_{d}$ and, for any $v$, $D_{a,b}\,\overline{D_{a,b}^{-1}v} = D_{a,b}(\bar{a}^{-1}P_{s}\bar{v} + \bar{b}^{-1}P_{d}\bar{v}) = (a/\bar{a})P_{s}\bar{v} + (b/\bar{b})P_{d}\bar{v} = \sigma_{a/\bar a,\,b/\bar b}\,v$. For real $v$, $C(P_{s}v, P_{d}v) = v^{\mathsf{T}}P_{s}P_{d}v = 0$, so $C(D_{a,b}v) = a^{2}C(P_{s}v) + b^{2}C(P_{d}v) = a^{2}s^{2} + b^{2}Q(d)$, with $s^{2} = C(P_{s}v)$ the square of the singlet coordinate $s = v \cdot u$ of Proposition \claimref{families.koide-nullity-condition-one-member-invariant} and $Q(d) = C(P_{d}v)$ the Euclidean square of the doublet part. \emph{(iii)} Conjugation by a unitary preserves traces, so for $A = U\,\mathrm{diag}(\lambda)\,U^{\dagger}$, $\operatorname{tr}A = \sum\lambda_{k}$ and $\operatorname{tr}A^{2} = \sum\lambda_{k}^{2}$. For the eigenvalue vector $\lambda$, $s^{2} = (\sum\lambda_{k})^{2}/3$ and $s^{2} + Q(d) = \sum\lambda_{k}^{2}$, so $\cos^{2}\theta = s^{2}/(s^{2} + Q(d)) = (\operatorname{tr}A)^{2}/(3\operatorname{tr}A^{2})$, which is the squared cosine of the Hilbert-Schmidt angle between $A$ and $1$ (as $\langle A, 1\rangle = \operatorname{tr}A$ and $\langle 1, 1\rangle = 3$). Write $\Theta(X) = -X^{\dagger} + \tfrac23\,\overline{\operatorname{tr}X}\,1$.
