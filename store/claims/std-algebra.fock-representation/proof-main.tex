(i) For $x = w + v$ with $w \in W$, $v \in W'$, the operator $c(x) = w \wedge {} + \iota_{2B(v, \cdot)}$ satisfies $c(x)^{2} = (w\wedge)^{2} + \iota^{2} + (w \wedge \iota + \iota\, w \wedge) = 0 + 0 + 2B(v, w) = Q(x)$, because $W$ and $W'$ are totally null and $Q(w + v) = 2B(v, w)$. The universal property of \claimref{obj.std-algebra.clifford-algebra} (\claimref{std-algebra.existence-uniqueness}) gives a homomorphism $\phi : \Cl(V, Q) \to \End(\Lambda W)$. Write $e_S = w_{s_1} \wedge \dots \wedge w_{s_m}$. Since $\iota_{2B(v_i, \cdot)} w_j = \delta_{ij}$, $\phi(v_i w_i)$ fixes $e_S$ for $i \notin S$ and kills it for $i \in S$; so $P = \phi(f)$ is the projection onto $\R e_\emptyset$ along the other $e_S$. Then $\phi(w_I)\, P\, \phi(v_{j_m} \cdots v_{j_1})$ is $\pm$ the elementary operator $e_J \mapsto e_I$, so $\phi$ is onto. Both sides have dimension $2^{2k}$ (\claimref{std-algebra.blade-basis}), so $\phi$ is an isomorphism, and $\End(\Lambda W) \cong \Mat_{2^{k}}(\R)$ in the basis $e_S$.

(ii) $P$ is a rank-one projection, so $f = \phi^{-1}(P)$ is an idempotent, primitive because $P \End(\Lambda W) P = \R P$. $\phi(v_i) P = 0$ since contractions kill $e_\emptyset$. The left ideal $\End(\Lambda W)\, P$ consists of the operators $\lvert \psi \rangle \langle e_\emptyset \rvert$, which is minimal and isomorphic to $\Lambda W$ by evaluation at $e_\emptyset$; transporting by $\phi^{-1}$, $\Cl(V, Q)\, f$ is a minimal left ideal and $w_I f \mapsto \phi(w_I) e_\emptyset = e_I$ is the module isomorphism. On a Witt pair $w_i, v_i$ the operators $\phi(w_i)$ and $\phi(v_i)$ are the creation and annihilation operators of \claimref{std-algebra.witt-basis-car}, so $\Lambda W$ is the Fock space of those modes.
