Since the map $A \mapsto (U \mapsto A\cdot U)$ is an isomorphism onto $\mathfrak{so}(\Lambda^{2}\CS,\varepsilon)$ (Fact \claimref{mass.imported-flat-model-twistor-chart-infinity}), it suffices to check that each displayed map acts on the six basis bivectors as the named rotation does. Throughout, $Q(n_{\infty}) = Q(n_{0}) = 0$, $\ip{n_{\infty}}{n_{0}} = 1$, and the $x$-slot is orthogonal to both.

(1) $R_{n_{\infty}\wedge n_{0}}$ sends $n_{\infty} \mapsto Q(n_{\infty})n_{0} - \ip{n_{0}}{n_{\infty}}n_{\infty} = -n_{\infty}$, $n_{0} \mapsto n_{0}$, and every $x$-slot vector to $0$. The grading map ($-\tfrac12$ on $\Som$, $+\tfrac12$ on $\Spi$) sends $e_{1}\wedge e_{2} \mapsto (-\tfrac12 - \tfrac12)e_{1}\wedge e_{2} = -n_{\infty}$, $e_{3}\wedge e_{4} \mapsto n_{0}$, and $e_{a}\wedge e_{a'} \mapsto (-\tfrac12 + \tfrac12)e_{a}\wedge e_{a'} = 0$.

(2) $R_{x\wedge n_{\infty}}$ sends $n_{\infty} \mapsto \ip{x}{n_{\infty}}n_{\infty} - Q(n_{\infty})x = 0$, a mixed bivector $y \mapsto \ip{x}{y}n_{\infty}$, and $n_{0} \mapsto \ip{x}{n_{0}}n_{\infty} - \ip{n_{\infty}}{n_{0}}x = -x$. The map $A = b_{x}$ annihilates $\Som$ and maps $e_{b'} \mapsto x^{aa'}\varepsilon_{a'b'}e_{a}$. Hence $A\cdot n_{\infty} = Ae_{1}\wedge e_{2} + e_{1}\wedge Ae_{2} = 0$. For $y = e_{c}\wedge e_{b'}$: $A\cdot y = e_{c}\wedge Ae_{b'} = x^{aa'}\varepsilon_{a'b'}\,e_{c}\wedge e_{a} = x^{aa'}\varepsilon_{a'b'}\varepsilon_{ca}\,n_{\infty}$, while by Remark \ref{rem:nullity} $\ip{x}{e_{c}\wedge e_{b'}} = -\varepsilon_{ac}\varepsilon_{a'b'}x^{aa'} = \varepsilon_{ca}\varepsilon_{a'b'}x^{aa'}$: equal. For $n_{0}$: $A\cdot(e_{3}\wedge e_{4}) = Ae_{3}\wedge e_{4} + e_{3}\wedge Ae_{4} = x^{a4}\varepsilon_{43}\,e_{a}\wedge e_{4} + x^{a3}\varepsilon_{34}\,e_{3}\wedge e_{a} = -x^{a4}e_{a}\wedge e_{4} - x^{a3}e_{a}\wedge e_{3} = -x$.

(3) $R_{x\wedge n_{0}}$ sends $n_{0} \mapsto 0$, $y \mapsto \ip{x}{y}n_{0}$, and $n_{\infty} \mapsto \ip{x}{n_{\infty}}n_{0} - \ip{n_{0}}{n_{\infty}}x = -x$. The map $A = c_{x}$ annihilates $\Spi$ and maps $e_{a} \mapsto -x^{ba'}\varepsilon_{ba}e_{a'}$. Hence $A\cdot n_{0} = 0$. For $y = e_{a}\wedge e_{c'}$: $A\cdot y = Ae_{a}\wedge e_{c'} = -x^{ba'}\varepsilon_{ba}\,e_{a'}\wedge e_{c'} = -x^{ba'}\varepsilon_{ba}\varepsilon_{a'c'}\,n_{0}$, while $\ip{x}{e_{a}\wedge e_{c'}} = -\varepsilon_{ba}\varepsilon_{a'c'}x^{ba'}$: equal. For $n_{\infty}$: $A\cdot(e_{1}\wedge e_{2}) = Ae_{1}\wedge e_{2} + e_{1}\wedge Ae_{2} = -x^{2a'}\varepsilon_{21}\,e_{a'}\wedge e_{2} - x^{1a'}\varepsilon_{12}\,e_{1}\wedge e_{a'} = -x^{2a'}e_{2}\wedge e_{a'} - x^{1a'}e_{1}\wedge e_{a'} = -x$.

Each displayed map is traceless. The script solves the linear systems $A\cdot P = R(P)$ exactly for the nine rotations displayed and confirms that the solutions are these maps, entry by entry in the chart frame.
