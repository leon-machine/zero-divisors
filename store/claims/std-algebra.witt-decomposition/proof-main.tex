(i) Since $P$ is nondegenerate and $u \ne 0$, some $x \in P$ has $B(u, x) \ne 0$; rescale so that $B(u, x) = \tfrac12$. For $w = x + t u$ we have $Q(w) = Q(x) + 2t B(u, x) = Q(x) + t$ (by \claimref{std-algebra.polarisation}), so $t = -Q(x)$ makes $w$ null, and $B(u, w) = B(u, x) = \tfrac12$. By \claimref{std-algebra.vector-squares}, $uw + wu = 2B(u, w) = 1$. $u$ and $w$ are independent since $B(u, u) = 0 \ne B(u, w)$, so they span $P$. If $w'$ is another partner, $w' - w = s u + s' w$; nullity of $w'$ and $B(u, w') = \tfrac12$ give $s' = 0$ and then $s = 0$. With $e = u + w$, $f = u - w$: $Q(e) = 2B(u, w) = 1$, $Q(f) = -1$, $B(e, f) = Q(u) - Q(w) = 0$.

(ii) By \claimref{synthesis.completion-recovers-the-real-clifford-algebras}(iii) take an orthogonal basis $e_1, \dots, e_p$, $f_1, \dots, f_q$, $z_1, \dots, z_r$ with $Q(e_i) = 1$, $Q(f_j) = -1$, $Q(z_k) = 0$. The $z_k$ are orthogonal to the whole basis, so they span $\operatorname{rad} V$. For $i \le m$ put $u_i = \tfrac12(e_i + f_i)$, $w_i = \tfrac12(e_i - f_i)$: both are null, $B(u_i, w_i) = \tfrac14(Q(e_i) - Q(f_i)) = \tfrac12$, and $H_i = \operatorname{span}(e_i, f_i)$ is a hyperbolic plane. The remaining $e_i$ or $f_j$ (only one kind remains) span a definite, hence anisotropic, $A$ of signature $(p - m, q - m, 0)$.

(iii) $N$ is totally null: the $u_i$ are null and mutually orthogonal, and the radical is orthogonal to everything. Its orthogonal complement is $N^{\perp} = N \oplus A$, since $B(w_i, u_i) \ne 0$ excludes the $w_i$ and nothing else is excluded. A null vector $x = n + a$ of $N^{\perp}$ has $Q(a) = Q(x) = 0$, so $a = 0$ and $x \in N$; hence no totally null subspace properly contains $N$. For the bound, let $T$ be totally null. $T$ meets the positive definite span $E$ of $e_1, \dots, e_p$ only in $0$, and the negative definite span $F$ of the $f_j$ only in $0$, so $\dim T \le n - p = q + r$ and $\dim T \le n - q = p + r$, that is $\dim T \le m + r$.
