The relations are computed with \claimref{std-algebra.orthogonal-anticommute}: for instance $(e_3 e_2)^{2} = -e_3^{2} e_2^{2} = -1$ and $\mathbf{i}\mathbf{j}\mathbf{k} = e_3 e_2 e_1 e_3 e_2 e_1 = -1$ (the check computes all of them). Hamilton's relations imply $\mathbf{i}\mathbf{j} = \mathbf{k} = -\mathbf{j}\mathbf{i}$ and cyclically, so $\operatorname{span}\{1, \mathbf{i}, \mathbf{j}, \mathbf{k}\}$ is closed under products, with the multiplication table of $\HH$. In (i) this span is the four-dimensional even subalgebra (\claimref{std-algebra.z2-grading}); in (ii) it is all of $\Cl(0,2)$ (\claimref{std-algebra.blade-basis}). The linear map sending $1, \mathbf{i}, \mathbf{j}, \mathbf{k}$ to the quaternion units is therefore a bijective homomorphism.
