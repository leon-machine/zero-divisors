By Wedderburn--Artin a semisimple Artinian ring is a finite product of matrix rings over division rings, and it suffices to verify regularity in $\Mat_k(D)$: any matrix $a$ of rank $r$ can be written $a = u \begin{psmallmatrix} 1_r & 0 \\ 0 & 0\end{psmallmatrix} v$ with $u, v$ invertible, and $x = v^{-1} \begin{psmallmatrix} 1_r & 0 \\ 0 & 0 \end{psmallmatrix} u^{-1}$ gives $axa = a$. (Clifford algebras of nondegenerate forms are semisimple by Theorem \claimref{transport.classification-real-clifford-algebras}.) For the consequence: $e^2 = xaxa = xa = e$, and $a(1-e) = a - axa = 0$; symmetrically for $f$. Also $ae = axa = a$ and $fa = axa = a$. If $e = 1$ then $xa = 1$, so $a$ is left-invertible, hence invertible in an Artinian ring, contradicting that $a$ is a zero divisor; if $e = 0$ then $a = ae = 0$, contradicting $a \neq 0$. The same for $f$.
