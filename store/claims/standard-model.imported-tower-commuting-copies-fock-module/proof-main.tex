The transport principle completes $\Cl(p,q)$ to $\Cl(p{+}1, q{+}1)$ by adjoining one hyperbolic pair, and iterates: the $k$-th rung is $T_{k} = \Cl(p{+}k, q{+}k)$ with adjoined null pairs $v_{j}, w_{j}$ satisfying $v_{i}v_{j} + v_{j}v_{i} = 0$, $w_{i}w_{j} + w_{j}w_{i} = 0$, $v_{i}w_{j} + w_{j}v_{i} = \delta_{ij}$. Inside $T_{k}$ the subalgebra $B_{k}$ generated by the $2k$ plane generators is $\Cl(k,k) \cong \mathrm{M}_{2^{k}}(\R)$, the twisted ground generators $x\,\omega_{1}\cdots\omega_{k}$ generate a commuting copy $A_{k} \cong \Cl(p,q)$, and multiplication $A_{k} \otimes B_{k} \to T_{k}$ is an isomorphism. The Chevalley action makes $\Lambda^{\bullet}\operatorname{span}(v_{1}, \ldots, v_{k})$ an irreducible $B_{k}$-module, one qubit per rung. On each complexified floor there is a conjugate-linear antiautomorphism $*$ under which the ladder pairs are mutually adjoint, $v_{j}^{*} = w_{j}$. \emph{Provenance:} \cite[Thms.~3.2, 4.2]{ButlerT3} (\claimref{tower.fock-module-one-qubit-per-rung}, \claimref{tower.commuting-copies}); proved there.

This restates \claimref{tower.ladder-pairs-satisfy-car-vectors}, \claimref{tower.structure-tower-c-norms}.
