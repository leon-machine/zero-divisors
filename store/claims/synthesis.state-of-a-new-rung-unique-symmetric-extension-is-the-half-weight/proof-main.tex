Throughout, $p = fe$ for the new plane, so $\mathrm{on} = vw = \tfrac12(1 + p)$ and $\mathrm{off} = wv = \tfrac12(1 - p)$; $p$ is even, $p^{2} = 1$, $p^{\dagger} = e^{\dagger}f^{\dagger} = -ef = p$, and $p$ commutes with $A_{\ell}$ (it is a product of two vectors orthogonal to the generators of $A_{\ell}$). The pair $v$, $w$ is a switch (Theorem \claimref{synthesis.set-and-clear-of-a-bit-generate-the-hyperbolic-plane}), the adjunction of the plane is the step of Fact \claimref{rungs.imported-totality-minimality-completion}, and the pairs are those of Proposition \claimref{tower.ladder-pairs-satisfy-car-vectors}.

\emph{(i).} States, positivity and reality are those of Premise \claimref{synthesis.premise-positivity-of-values}. As a vector space $A_{\ell+1} = A_{\ell} \oplus A_{\ell}e \oplus A_{\ell}f \oplus A_{\ell}p$. Every $a \in A_{\ell}$ commutes with $\mathrm{on}$ and $\mathrm{off}$; $e\,\mathrm{on} = \mathrm{off}\,e$ and $f\,\mathrm{on} = \mathrm{off}\,f$, so $\mathrm{on}\,e\,\mathrm{on} = \mathrm{on}\,f\,\mathrm{on} = 0$; and $p\,\mathrm{on} = \mathrm{on}$. Hence for $x = a + be + cf + dp$,
\[
\mathrm{on}\,x\,\mathrm{on} = E_{1}(x)\,\mathrm{on}, \qquad E_{1}(x) := a + d \in A_{\ell},
\]
and likewise $\mathrm{off}\,x\,\mathrm{off} = E_{0}(x)\,\mathrm{off}$ with $E_{0}(x) = a - d$. Put $\Omega_{1} = \omega \circ E_{1}$, $\Omega_{0} = \omega \circ E_{0}$ and $\Omega_{t} = t\,\Omega_{1} + (1 - t)\,\Omega_{0}$, that is $\Omega_{t}(x) = \omega(a) + (2t - 1)\omega(d)$. Then $\Omega_{t} = \omega$ on $A_{\ell}$, $\Omega_{t}(1) = 1$, $\Omega_{t}$ vanishes on $A_{\ell}e$ and $A_{\ell}f$, and $\Omega_{t}(a\,\mathrm{on}) = \tfrac12\omega(a) + \tfrac12(2t - 1)\omega(a) = t\,\omega(a)$, likewise for off. Reality: $\mathrm{on}$ is self-adjoint, so $E_{1}(x^{\dagger})\,\mathrm{on} = (\mathrm{on}\,x\,\mathrm{on})^{\dagger} = E_{1}(x)^{\dagger}\,\mathrm{on}$, and $\omega$ is real. Positivity: with $1 = \mathrm{on} + \mathrm{off}$,
\[
\mathrm{on}\,xx^{\dagger}\,\mathrm{on} = (\mathrm{on}\,x\,\mathrm{on})(\mathrm{on}\,x\,\mathrm{on})^{\dagger} + (\mathrm{on}\,x\,\mathrm{off})(\mathrm{on}\,x\,\mathrm{off})^{\dagger} .
\]
Since $f$ is $e\,p$ up to a sign and $p\,\mathrm{off} = -\mathrm{off}$, $\mathrm{on}\,x\,\mathrm{off} = g\,e\,\mathrm{off}$ for some $g \in A_{\ell}$ (a combination of $b$ and $c$), and $(g\,e\,\mathrm{off})(g\,e\,\mathrm{off})^{\dagger} = g\,e\,\mathrm{off}\,e\,g^{\dagger} = g\,\mathrm{on}\,g^{\dagger} = gg^{\dagger}\,\mathrm{on}$. So $E_{1}(xx^{\dagger}) = E_{1}(x)E_{1}(x)^{\dagger} + gg^{\dagger}$ and $\Omega_{1}(xx^{\dagger}) = \omega(E_{1}(x)E_{1}(x)^{\dagger}) + \omega(gg^{\dagger}) \ge 0$; the same for $\Omega_{0}$, and a convex combination of states is a state. For $t$ outside $[0, 1]$, $\Omega_{t}(\mathrm{on}\,\mathrm{on}^{\dagger}) = t$ or $\Omega_{t}(\mathrm{off}\,\mathrm{off}^{\dagger}) = 1 - t$ is negative. The script confirms positivity exactly, as positive semidefiniteness of the Gram matrix $\Omega_{t}(e_{S}e_{T}^{\dagger})$ on all blades, for $\ell = 1, 2$, two states $\omega$ and three values of $t$, and its failure for $t = -\tfrac15$ and $t = \tfrac65$. On the new rung $\Omega_{t}$ is given by the element $t\,\mathrm{on} + (1 - t)\,\mathrm{off}$, whose square is $t^{2}\mathrm{on} + (1 - t)^{2}\mathrm{off}$: idempotent exactly for $t \in \{0, 1\}$.

\emph{(ii).} A sign change of generators extends to an automorphism of the Clifford algebra; $\sigma_{e}$, $\sigma_{f}$ fix the generators of $A_{\ell}$, hence $A_{\ell}$ pointwise, and commute with $\dagger$ because $\dagger$ is defined generator by generator. $\sigma_{f}(v) = \tfrac12(e - f) = w$, so $\sigma_{f}(\mathrm{on}) = wv = \mathrm{off}$; $\sigma_{e}(v) = \tfrac12(-e + f) = -w$ and $\sigma_{e}(\mathrm{on}) = (-w)(-v) = \mathrm{off}$. On the summands: $\sigma_{e}$ negates $A_{\ell}e$ and $A_{\ell}p$, $\sigma_{f}$ negates $A_{\ell}f$ and $A_{\ell}p$. A linear functional invariant under both therefore vanishes on $A_{\ell}e \oplus A_{\ell}f \oplus A_{\ell}p$, and if it restricts to $\omega$ it is $a + be + cf + dp \mapsto \omega(a)$, which is $\Omega_{1/2}$. This uses no positivity: uniqueness holds among all linear functionals. $\Omega_{1/2}(\mathrm{on}) = \tfrac12$, not an integer; by (i) it is not sharp on the new rung; and an extension with $\Omega(\mathrm{on}) \in \{0, 1\}$ or integer valued on the tests differs from $\Omega_{1/2}$, so is not invariant. This is the one-switch case of clause (v) of Theorem \claimref{synthesis.exchange-of-set-and-clear-is-inner-and-fixed-by-no-integer-state}, here relative to a given state on the rungs below.

\emph{(iii).} The tests of different rungs commute and $\mathrm{on}_{j}\mathrm{off}_{j} = 0$, so the $P_{s}$ are orthogonal idempotents; expanding $\prod_{j}(\mathrm{on}_{j} + \mathrm{off}_{j}) = 1$ gives the sum. The sign change of $f_{j}$ exchanges $\mathrm{on}_{j}$ and $\mathrm{off}_{j}$ and fixes the other rungs' tests, so the group $(\Z/2)^{m}$ of these sign changes acts on the strings by flipping entries: simply transitively. For $i \ne j$ the element $R = f_{i}f_{j}$ is even with $R\tilde{R} = f_{i}f_{j}f_{j}f_{i} = 1$; it anticommutes with $f_{i}$ and $f_{j}$ and commutes with every other generator, so $x \mapsto Rx\tilde{R}$ is the sign change of $f_{i}$ and $f_{j}$ together. The volume element $\Gamma$ anticommutes with every generator (the dimension $2m$ is even), hence commutes with every even element and so with every rotor; $p_{j}\,\mathrm{on}_{j} = \mathrm{on}_{j}$ and $p_{j}\,\mathrm{off}_{j} = -\mathrm{off}_{j}$ give $\Gamma P_{s} = \pm(-1)^{m - |s|}P_{s}$ with the sign of the ordering of $\Gamma$. If $P_{s'} = RP_{s}\tilde{R}$ for a rotor $R$ then $\Gamma P_{s'} = R\Gamma P_{s}\tilde{R}$ has the same sign, so strings of different parity are not conjugate under rotors, and strings of equal parity differ by an even number of flips, a product of the rotors above. So there are exactly two classes.

\emph{(iv).} For two rungs each $P_{s}$ is self-adjoint with scalar part $\tfrac14$, the four are orthogonal and sum to $1$: a context of the atoms of Theorem \claimref{synthesis.no-two-valued-weights-on-the-atoms-of-two-modes-the-even-subalgebra-admits-them}, and the state $x \mapsto \langle P_{s}x\rangle_{0}/\langle P_{s}\rangle_{0}$ of a string gives it the weights $1, 0, 0, 0$. With $y = P_{s} + v_{j}P_{s}$ for a rung $j$ that is off in $s$, $\Pi = \tfrac12 yy^{\dagger}$ is a self-adjoint idempotent to which the string's state gives $\tfrac12$ (computed by the script for one string). Clause (i) of the cited theorem says no function from the atoms to $\{0, 1\}$ sums to $1$ on every context; a string determines such a function on one context and so has no extension of that kind.
