Everything is finite-dimensional, so closures are automatic. On the matrix units $a = |i\rangle\langle j| \otimes 1$: $a\Omega = \lambda_j |ij\rangle$ and $a^*\Omega = \lambda_i |ji\rangle$, so $S$ is the antilinear map $|ij\rangle \mapsto (\lambda_i/\lambda_j)\,|ji\rangle$, and since the $a\Omega$ span $H$ ($\Omega$ is cyclic), this determines $S$. Define $\Delta |ij\rangle := (\lambda_i^2/\lambda_j^2)|ij\rangle$, which is exactly $(\rho \otimes \bar\rho^{\,-1})|ij\rangle$, positive and invertible, and let $J$ be the antilinear extension of $|ij\rangle \mapsto |ji\rangle$, which is antiunitary with $J^2 = 1$. Then $J\Delta^{1/2}|ij\rangle = (\lambda_i/\lambda_j) J|ij\rangle = (\lambda_i/\lambda_j)|ji\rangle = S|ij\rangle$ (the eigenvalues are real, so antilinearity causes no conjugation), and uniqueness of the polar decomposition gives the claim. The flow: $\Delta^{I_4t}(b \otimes 1)\Delta^{-I_4t} = (\rho^{I_4t}\otimes\bar\rho^{-I_4t})(b \otimes 1)(\rho^{-I_4t}\otimes\bar\rho^{\,I_4t}) = \rho^{I_4t} b \rho^{-I_4t} \otimes 1$, interior to $M$. KMS: the reduced density matrix of $\Omega$ on the first factor is $\rho$, so $\omega(x) = \tr(\rho x)$ for $x \in \Mat_n(\C)$, and $\omega(b\,\rho a \rho^{-1}) = \tr(\rho\, b\, \rho a \rho^{-1}) = \tr(\rho\, a b) = \omega(ab)$ by cyclicity of the trace.
