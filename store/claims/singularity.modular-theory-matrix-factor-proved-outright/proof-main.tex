Everything is finite-dimensional, so closures are automatic. On the matrix units $a = |k\rangle\langle l| \otimes 1$: $a\Omega = \lambda_l |kl\rangle$ and $a^*\Omega = \lambda_k |lk\rangle$, so $S$ is the antilinear map $|kl\rangle \mapsto (\lambda_k/\lambda_l)\,|lk\rangle$, and since the $a\Omega$ span $H$ ($\Omega$ is cyclic), this determines $S$. Define $\Delta |kl\rangle := (\lambda_k^2/\lambda_l^2)|kl\rangle$, which is exactly $(\rho \otimes \bar\rho^{\,-1})|kl\rangle$, positive and invertible, and let $J$ be the antilinear extension of $|kl\rangle \mapsto |lk\rangle$, which is antiunitary with $J^2 = 1$. Then $J\Delta^{1/2}|kl\rangle = (\lambda_k/\lambda_l) J|kl\rangle = (\lambda_k/\lambda_l)|lk\rangle = S|kl\rangle$ (the eigenvalues are real, so antilinearity causes no conjugation), and uniqueness of the polar decomposition gives the claim. The flow: $\Delta^{I_4t}(b \otimes 1)\Delta^{-I_4t} = (\rho^{I_4t}\otimes\bar\rho^{-I_4t})(b \otimes 1)(\rho^{-I_4t}\otimes\bar\rho^{\,I_4t}) = \rho^{I_4t} b \rho^{-I_4t} \otimes 1$, interior to $M$. KMS: the reduced density matrix of $\Omega$ on the first factor is $\rho$, so $\omega(x) = \tr(\rho x)$ for $x \in \Mat_n(\C)$, and $\omega(b\,\rho a \rho^{-1}) = \tr(\rho\, b\, \rho a \rho^{-1}) = \tr(\rho\, a b) = \omega(ab)$ by cyclicity of the trace.
