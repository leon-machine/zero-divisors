Writing out the covariance condition on $\psi \circ \Lambda_{R}^{-1}$ and cancelling the field, it is equivalent to $R^{-1}A^{\mu}R = M(R)^{\mu}{}_{\nu}A^{\nu}$ for every rotor, where $M(R)$ is the vector matrix defined by $R^{-1}\gamma^{\mu}R = M(R)^{\mu}{}_{\nu}\gamma^{\nu}$. This is a linear condition on the $64$-dimensional space of quadruples $(A^{0}, \dots, A^{3})$. Two solutions are known: $A^{\mu} = \gamma^{\mu}$, by the definition of $M(R)$; and $A^{\mu} = \gamma^{\mu}I$, because $I$ commutes with every even element (\claimref{std-algebra.pseudoscalar-commutation}), so $R^{-1}\gamma^{\mu}IR = R^{-1}\gamma^{\mu}R\,I$. For the converse it suffices to show that finitely many rotors already cut the solution space down to the span of these two, since the space of solutions for all rotors is contained in the space of solutions for any subset. The script imposes the condition for six rational rotors, the boosts $\tfrac54 + \tfrac34\gamma_{0}\gamma_{1}$, $\tfrac{13}{12} + \tfrac{5}{12}\gamma_{0}\gamma_{2}$, $\tfrac{17}{15} + \tfrac{8}{15}\gamma_{0}\gamma_{3}$ and the rotations $\tfrac35 + \tfrac45\gamma_{1}\gamma_{2}$, $\tfrac{5}{13} + \tfrac{12}{13}\gamma_{1}\gamma_{3}$, $\tfrac{8}{17} + \tfrac{15}{17}\gamma_{2}\gamma_{3}$ (each of unit norm, $R\tilde{R} = 1$, exactly), and computes the kernel of the stacked $384 \times 64$ system over the Gaussian rationals: it is two-dimensional and contains the two known solutions, so it equals their span. Finally $\gamma^{\mu}(a + bI) = (a - bI)\gamma^{\mu}$ because $I$ anticommutes with vectors, and $(a - bI)(a + bI) = a^{2} + b^{2}$ because $I^{2} = -1$ in $\Cl(1,3)$; the script checks the anticommutation on all four generators, the identity $\gamma^{\mu}(a+bI) = (a-bI)\gamma^{\mu}$ on instances, and the norm identity.
