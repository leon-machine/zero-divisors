\emph{(1).} By Theorem \claimref{synthesis.rung-field-d-term-action-and-tree-masses-on-the-lift-locus}(2), on $L$ the D-term potential is $V_{D} = \tfrac12\bigl(\tfrac{g^{2}}{4}(N^{2} - H^{4}) + g'^{2}(\tfrac{m}{2} - \zeta)^{2}\bigr)$, increasing in $N$ at fixed $m$, so its minimum over the orbit space lies on the boundary $N^{2} - H^{4} = m^{2}$. There $V_{D} = \tfrac12\bigl(\tfrac{g^{2}}{4}m^{2} + g'^{2}(\tfrac{m}{2} - \zeta)^{2}\bigr)$, a quadratic in $m$ with no $H$; its derivative $\tfrac{g^{2}}{4}m + \tfrac{g'^{2}}{2}(\tfrac{m}{2} - \zeta)$ vanishes at $m^{*} = g'^{2}\xi/(g^{2} + g'^{2})$, and $V_{D}(m^{*} + \delta) - V_{D}(m^{*}) = \tfrac18(g^{2} + g'^{2})\delta^{2}$. Then $N^{*2} = m^{*2} + H^{4}$, and $N^{*} - |m^{*}| = H^{4}/(N^{*} + |m^{*}|) \le H^{4}/(2|m^{*}|)$. The check verifies the orbit-space form against rung coordinates at three family points, the absence of $H$ on the boundary, the minimum and its excess at four displacements, and the same vacuum value at four values of $H^{2}$ ($5, 9, 16, 35$ with $m^{*} = 12$, so $N^{*} = 13, 15, 20, 37$), with $g = \tfrac23$, $g' = \tfrac12$.

\emph{(2).} The gauge masses are $M_{W}^{2} = \tfrac12 g^{2}N^{*}$ and $M_{Z}^{2} = \tfrac12(g^{2} + g'^{2})N^{*}$ (stored (3)), and $v^{2}$ is proportional to $N^{*}$ with a coupling-independent factor. With $G$, $g$, $g'$, $\xi$ constants of the action, $\xi G$ and $m^{*}G = g'^{2}\xi G/(g^{2} + g'^{2})$ are constants of the laws, and $M_{W}^{2}G = \tfrac12 g^{2}N^{*}G$ varies over the solution set only through $N^{*}$, by the relative amount $(N^{*} - |m^{*}|)/|m^{*}| \le H^{4}/(2m^{*2})$. On the other hand $N^{*}/H^{2} = \sqrt{1 + m^{*2}/H^{4}}$ with $m^{*}$ fixed is strictly decreasing in $H$, so $v/H$ is not constant on the solution set, which contains every $\Lambda > 0$ (Theorem \claimref{synthesis.einstein-route-makes-n-initial-data}(i), (ii)); the check certifies $N^{*}/H^{2} = \tfrac{13}{5}, \tfrac53, \tfrac54, \tfrac{37}{35}$ at the four sample values and the bound on $N^{*} - m^{*}$. In the terms of Theorem \claimref{synthesis.einstein-route-makes-n-initial-data}(iii) this is the branch in which $v/M_{P}$ is held as the parameter and $v/H = (v/M_{P})N$ is initial data. $N^{*}/H^{2}$ is a function of $m^{*}/H^{2}$ alone, so it is constant on the solution set if and only if $m^{*}/H^{2}$ is, that is, if and only if $\xi = \hat{\xi}\Lambda$ with $\hat{\xi}$ a constant; the check verifies the constant ratio $\tfrac{13}{5}$ at three values of $H^{2}$ with $m^{*} = \tfrac{12}{5}H^{2}$.

\emph{(3).} $Gv^{2}N^{2} = v^{2}M_{P}^{-2}M_{P}^{2}H^{-2} = (v/H)^{2}$, and $G\Lambda = 3H^{2}M_{P}^{-2} = 3N^{-2}$ (Proposition \claimref{synthesis.smallness-monomials-exact-hierarchy-casimir}(i)), so $Gv^{2}N^{2} = \tfrac13 G\Lambda N^{2}(v/H)^{2}$ is $(v/H)^{2}$ times an identity. Being equal to $(v/H)^{2}$ on every solution, its left side is constant on the solution set exactly when $v/H$ is; read as a statement that it is a constant of the laws, it is the $v/H$ branch itself and cannot decide between the branches. The check verifies it for three values of $v$ at two pairs $(M_{P}, H)$.

Reading (argued, not part of the statement). Read under the promotion, the stored D-term action is a dynamics of the rung component under which $v/H$ is initial data, which is the refutation condition of \claimref{synthesis.rung-unit-second-free-number} (version 2). The register can be made consistent in two ways. Restating the rung-unit premise to the held $v/M_{P}$ keeps the stored action and makes $v/H$ initial data, the same kind as $N$. Keeping $v/H$ as the law needs the level written as $\hat{\xi}\Lambda$, a coupling of the rung action to the promoted $\Lambda$ that the stored action does not have; under the promotion the rung's moment map would then enter the equation of the variable conjugate to $\Lambda$. With an added invariant $W(N)$ whose constants do not involve $\Lambda$, the vacuum equation on the boundary involves $H$ only through $N = \sqrt{m^{2} + H^{4}}$, so the same conclusion holds to relative order $H^{4}/m^{*2}$ (argued, not checked).
