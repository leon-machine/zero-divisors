\emph{(i).} By Proposition \claimref{scrambling.boundary-mode-space-matrix} the mode operators obey the canonical anticommutation relations, so $[N_{i}, v_{j}] = -\delta_{ij}v_{j}$ and $[N_{i}, v_{j}^{*}] = \delta_{ij}v_{j}^{*}$; the central shift in $K_{j} = N_{j} - \tfrac12$ does not change the adjoint action. Lemma \claimref{scrambling.clock-inventory-boundary-modes}(ii) calls a hyperbolic intrinsic flow a clock when the nonzero eigenvalues on the modes it moves have one magnitude, which the normalisation to rapidity sets to one, and Lemma (iii) records that a diagonal generator with unequal nonzero $|c_{i}|$ has no common rapidity.
