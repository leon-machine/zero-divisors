In both cases the algebra is two-dimensional with basis $1, u$ where $u = e_1$ (with $e_1^{2} = -1$) or $u = e_1 e_2$, for which $u^{2} = -e_1^{2}e_2^{2} = -1$ by \claimref{std-algebra.orthogonal-anticommute}. The linear bijection $a + bu \mapsto a + b\,\mathrm{i}$ is multiplicative because both sides multiply by $(a + bu)(c + du) = (ac - bd) + (ad + bc)u$. $\Cl^{+}(2,0)$ is the span of the even blades by \claimref{std-algebra.z2-grading}. For the rotation and scaling: $e_1 e_1 e_2 = e_2$, so $e_1(a + b\, e_1e_2) = a e_1 + b e_2$, the vector $e_1$ turned by the angle of $a + b\,\mathrm{i}$ and stretched by $\sqrt{a^{2} + b^{2}}$.
