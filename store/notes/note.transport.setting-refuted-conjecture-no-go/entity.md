## formal
An exact inverse being impossible (Lemma \claimref{transport.noinverse}), the standard weakening is a \emph{von Neumann pseudo-inverse}: an element $\sigma(v)$ with $v\,\sigma(v)\,v = v$. Pseudo-inverses of null vectors exist in abundance, since any null partner $w$ with $v \cdot w = \tfrac12$ supplies one by \eqref{eq:hyperbolicpair}, so the substantive question is not existence but \emph{canonicity}: can a pseudo-inverse be \emph{chosen}, one for each null vector, respecting the symmetries of the original algebra in the sense of Definition \claimref{obj.transport.equivariance}?
