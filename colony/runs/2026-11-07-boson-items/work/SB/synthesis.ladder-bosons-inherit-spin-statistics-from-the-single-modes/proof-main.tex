\emph{Preliminaries.} By Theorem \claimref{tower.ladder-pairs-satisfy-car-vectors} the $v_{j}, w_{j}$ satisfy $\{v_{i}, w_{j}\} = \delta_{ij}$, $\{v_{i}, v_{j}\} = \{w_{i}, w_{j}\} = 0$, so $n_{j}^{2} = v_{j}(w_{j}v_{j})w_{j} = v_{j}(1 - v_{j}w_{j})w_{j} = n_{j}$, and the $n_{j}$ commute pairwise (each is even and built from one plane). Directly, $n_{j} = \tfrac14(e_{j} + f_{j})(e_{j} - f_{j}) = \tfrac14(e_{j}^{2} - e_{j}f_{j} + f_{j}e_{j} - f_{j}^{2}) = \tfrac12(1 - \omega_{j})$, since $f_{j}e_{j} = -e_{j}f_{j}$. By Theorem \claimref{tower.volume-elements-planes}, $\omega_{j}^{2} = 1$, $\omega_{j}$ anticommutes with $e_{j}, f_{j}$, commutes with the generators of the other planes and with $g_{1}, g_{2}$, and the $\omega_{j}$ commute pairwise. $J^{2} = g_{1}g_{2}g_{1}g_{2} = -g_{1}^{2}g_{2}^{2} = -1$; $J^{*} = (g_{2}g_{1})(-1)^{2} = g_{2}g_{1} = -J$; and $J$ commutes with every plane generator, which anticommutes with each of $g_{1}, g_{2}$. Hence $J$ commutes with every element of the algebra of the planes. The adjoint is an antiautomorphism with $v_{j}^{*} = w_{j}$, $n_{j}^{*} = n_{j}$.

\emph{(i).} The summands $\theta Js_{j}n_{j}$ commute pairwise, so $e^{\theta JL_{s}} = \prod_{j}e^{\theta Js_{j}n_{j}}$. Since $n_{j}$ is an idempotent commuting with $J$, $(\theta Js_{j}n_{j})^{k} = (\theta Js_{j})^{k}n_{j}$ for $k \ge 1$, so $e^{\theta Js_{j}n_{j}} = 1 - n_{j} + n_{j}e^{\theta Js_{j}}$, with $e^{\varphi J} = \cos\varphi + J\sin\varphi$ by Theorem \claimref{std-algebra.bivector-exponential} ($J$ is a simple bivector of square $-1$). The group law follows from the exponential form, since all factors commute. Unitarity: $U_{s}(\theta)^{*} = \prod_{j}(1 - n_{j} + n_{j}e^{-\theta Js_{j}}) = U_{s}(-\theta)$ because $J^{*} = -J$ and $J$ commutes with $n_{j}$; so $U_{s}(\theta)^{*}U_{s}(\theta) = 1$. Commutation with $J$ is clear. For the action on modes, $[n_{j}, w_{j}] = v_{j}w_{j}w_{j} - w_{j}v_{j}w_{j} = -(1 - v_{j}w_{j})w_{j} = -w_{j}$ and $[n_{k}, w_{j}] = 0$ for $k \ne j$; so $[L_{s}, w_{j}] = -s_{j}w_{j}$, hence $L_{s}w_{j} = w_{j}(L_{s} - s_{j})$ and $U_{s}(\theta)w_{j} = w_{j}e^{\theta J(L_{s} - s_{j})} = e^{-\theta Js_{j}}w_{j}U_{s}(\theta)$; similarly $[L_{s}, v_{j}] = s_{j}v_{j}$ and $U_{s}(\theta)v_{j}U_{s}(\theta)^{*} = e^{\theta Js_{j}}v_{j}$. At $\theta = 2\pi$, $e^{2\pi Js_{j}} = \cos 2\pi s_{j} = (-1)^{2s_{j}}$, so the factor of plane $j$ is $1$ for integer $s_{j}$ and $1 - 2n_{j} = \omega_{j}$ for half-integer $s_{j}$. This gives the product formula. The script checks the product formula, the group law $U_{s}(\pi)^{2} = U_{s}(2\pi)$, unitarity, commutation with $J$ and the action on $v_{j}, w_{j}$ (with $e^{m\pi Js}$ in $\{\pm1, \pm J\}$) for $N = 1, 2, 3$ and all $5^{N}$ assignments with $s_{j} \in \{-\tfrac12, 0, \tfrac12, 1, \tfrac32\}$.

\emph{(ii).} Let $S$ be the set of half-integer modes, so $U_{s}(2\pi) = \prod_{j \in S}\omega_{j}$. For a mode $j$, $\omega_{k}$ commutes with $v_{j}, w_{j}$ for $k \ne j$ and anticommutes for $k = j$. So $\operatorname{Ad}U_{s}(2\pi)$ negates $v_{j}, w_{j}$ for $j \in S$ and fixes them for $j \notin S$, while $\operatorname{Ad}\Gamma$ negates every mode. The two automorphisms agree on the generators $v_{j}, w_{j}$, hence on the algebra of the planes, exactly when $S$ is every mode; then $U_{s}(2\pi) = \prod_{j}\omega_{j} = \Gamma$. $\operatorname{Ad}\Gamma$ fixes products of an even number of modes and negates products of an odd number, so an element of definite spin has half-integer spin exactly when it is odd. Monomials in the modes of two disjoint sets of planes commute or anticommute according to the product of their parities, since modes of distinct planes anticommute; by linearity two odd elements on disjoint sets anticommute and every other pair commutes. Hopping elements $v_{i}w_{j}$, pairing elements $w_{i}w_{j}$, their sums and the density modes are even, so they have integer spin, and those on disjoint blocks commute, at every $N$. The script checks, for $N = 1, 2, 3$ and all $5^{N}$ assignments, that $\operatorname{Ad}U_{s}(2\pi)$ and $\operatorname{Ad}\Gamma$ agree on every mode exactly for the $3^{N}$ all-half-integer assignments ($39$ in all), that $U(2\pi) = \Gamma$ when every weight is $\tfrac12$, and then that all products of two modes are fixed and all modes negated.

\emph{(iii).} If $s_{j}$ is an integer, $j \notin S$, so $\operatorname{Ad}U_{s}(2\pi)w_{j} = w_{j}$ by (ii), while $w_{j}$ anticommutes with every $v_{k}, w_{k}$, $k \ne j$, by the anticommutation relations. For the blocks, $\operatorname{Ad}U_{s}(2\pi)$ negates $v_{\mathrm{lower},i}$ and fixes $w_{\mathrm{upper},i}$, so it negates $b_{i}$. Elements of distinct blocks are even and supported on disjoint planes, so they commute by (ii). The relation $[B, B^{*}] = N_{b}^{-1}\sum_{i}(n_{\mathrm{lower},i} - n_{\mathrm{upper},i})$ and its value $1 - 2k/N_{b}$ on $(B^{*})^{k}P_{\mathrm{pol}}$, with $(B^{*})^{N_{b}+1}P_{\mathrm{pol}} = 0$, are Theorem \claimref{synthesis.fluctuation-forms-of-the-tower-and-density-wave-bosons-of-the-null-vacuum}(ii), which uses only the anticommutation relations and so holds whatever spin is assigned; $B$, a sum of elements of half-integer spin, has half-integer spin. On vectors $(B^{*})^{k}P_{\mathrm{pol}}$ of bounded $k$ the commutator tends to $1$. The script checks all of this for $N_{b} = 1, 2, 3$, with $P_{\mathrm{pol}} = \prod_{i}n_{\mathrm{lower},i}(1 - n_{\mathrm{upper},i})$ as the polarised vector of the left regular representation.

\emph{(iv).} By the preliminaries $J$ commutes with every plane generator, so $e^{\varphi J}$ commutes with the algebra of the planes and $\operatorname{Ad}e^{\varphi J}$ fixes it. For $L$: $v_{0}w_{1} = \tfrac14(e_{0}e_{1} - e_{0}f_{1} + f_{0}e_{1} - f_{0}f_{1})$ and $v_{1}w_{0} = \tfrac14(e_{1}e_{0} - e_{1}f_{0} + f_{1}e_{0} - f_{1}f_{0})$; using anticommutation of distinct generators the mixed terms cancel and $L = \tfrac12(e_{0}e_{1} - f_{0}f_{1})$. $B_{1} = e_{0}e_{1}$ and $B_{2} = f_{0}f_{1}$ commute (they share no generator and are even) and $B_{1}^{2} = -e_{0}^{2}e_{1}^{2} = -1$, $B_{2}^{2} = -f_{0}^{2}f_{1}^{2} = -1$. From the relations, $[L, w_{0}] = -w_{1}$ and $[L, w_{1}] = w_{0}$, so $[L, w_{0} \pm Jw_{1}] = -w_{1} \pm Jw_{0} = \pm J(w_{0} \pm Jw_{1})$: weights $\pm1$. By Theorem \claimref{std-algebra.bivector-exponential}, $e^{\pi L} = e^{\pi B_{1}/2}e^{-\pi B_{2}/2} = B_{1}(-B_{2}) = -e_{0}e_{1}f_{0}f_{1} = e_{0}f_{0}e_{1}f_{1} = \omega_{0}\omega_{1}$, which negates $v_{0}, w_{0}, v_{1}, w_{1}$, and $e^{2\pi L} = (\omega_{0}\omega_{1})^{2} = 1$. The script checks each identity.

\emph{Reading.} By (ii) and (iii), spin and statistics agree on the whole algebra (and so for all collective modes) if and only if every $s_{j}$ is half-integer, that is if and only if they agree for the single modes. By (iv) neither the kernel rotors nor the real rotations of modes supply half-integer weights; the assignment $s$ is extra data. That the attached free fields' CAR modes are spinors is the locality result cited in the statement, which is not used in the proof.
