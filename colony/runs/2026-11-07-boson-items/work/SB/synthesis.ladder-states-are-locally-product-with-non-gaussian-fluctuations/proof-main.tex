\emph{Preliminaries.} By Theorem \claimref{tower.ladder-pairs-satisfy-car-vectors}, $\{v_{i}, w_{j}\} = \delta_{ij}$ and modes of distinct planes anticommute, so each $n_{j}$ is an idempotent, the $n_{j}$ commute, and even elements supported on distinct blocks commute. The adjoint $*$ (reversion with a sign per generator of square $-1$) maps each basis blade $e_{S}$ to $\pm e_{S}$ with $e_{S}^{*}e_{S} = 1$ (each generator $g$ has $g^{*}g = Q(g)^{2} = 1$, and reversion reverses the order), so $\langle x, y\rangle = \langle x^{*}y\rangle_{0} = \sum_{S}x_{S}y_{S}$ is the Euclidean inner product of blade coefficients: positive definite, with $\langle x, Xy\rangle = \langle X^{*}x, y\rangle$ because $\langle a\rangle_{0} = \langle a^{*}\rangle_{0}$. Hence each $\omega_{k}$ is a state (a normalised vector state of the left regular representation) and self-adjoint idempotents act as orthogonal projections. The number $\mathcal{N}_{u} = \sum_{i}n_{u_{i}}$ is self-adjoint, $[\mathcal{N}_{u}, K^{*}] = K^{*}$ and $[\mathcal{N}_{u}, K] = -K$ (from $[n_{u}, v_{u}] = v_{u}$, $[n_{u}, w_{u}] = -w_{u}$), and $\mathcal{N}_{u}P = 0$, so $\mathcal{N}_{u}\psi_{k} = k\psi_{k}$; vectors with different eigenvalues are orthogonal. In particular $\omega_{k}(b_{i}) = 0$ and $\omega_{k}((B^{*})^{a}B^{c}) = 0$ for $a \ne c$, since $(B^{*})^{a}B^{c}\psi_{k}$ has eigenvalue $k + a - c$.

\emph{(i).} By Theorem \claimref{synthesis.fluctuation-forms-of-the-tower-and-density-wave-bosons-of-the-null-vacuum}(ii), $[K, K^{*}] = \sum_{i}(n_{l_{i}} - n_{u_{i}})$, and on $\psi_{j}$ this equals $N - 2j$ (each block holds one particle on $\psi_{j}$: $n_{l_{i}} + n_{u_{i}}$ commutes with $K^{*}$ and is $1$ on $P$). $KP = 0$ because $w_{u_{i}}(1 - n_{u_{i}}) = w_{u_{i}}w_{u_{i}}v_{u_{i}} = 0$ and $w_{u_{i}}$ commutes past the factors of the other blocks up to sign. Then $K\psi_{k} = \sum_{j=0}^{k-1}(K^{*})^{j}[K, K^{*}](K^{*})^{k-1-j}P + (K^{*})^{k}KP = \sum_{j=0}^{k-1}(N - 2(k - 1 - j))\psi_{k-1} = (kN - k(k - 1))\psi_{k-1} = k(N - k + 1)\psi_{k-1}$. Also $\langle\psi_{k}, \psi_{k}\rangle = \langle K^{*}\psi_{k-1}, \psi_{k}\rangle = \langle\psi_{k-1}, K\psi_{k}\rangle = k(N - k + 1)\langle\psi_{k-1}, \psi_{k-1}\rangle$, positive for $1 \le k \le N$, and $\langle P, P\rangle > 0$. Iterating, $K^{m}\psi_{k} = c_{k,m}\psi_{k-m}$ with $c_{k,m} = \prod_{i=0}^{m-1}(k - i)(N - k + i + 1) = (k)_{m}(N - k + 1)^{(m)}$ (zero for $m > k$), and $\langle\psi_{k}, \psi_{k}\rangle = c_{k,m}\langle\psi_{k-m}, \psi_{k-m}\rangle$ for $m \le k$. So $\omega_{k}((B^{*})^{m}B^{m}) = N^{-m}\langle K^{m}\psi_{k}, K^{m}\psi_{k}\rangle/\langle\psi_{k}, \psi_{k}\rangle = N^{-m}c_{k,m}^{2}/c_{k,m} = N^{-m}c_{k,m}$ for $m \le k$, and $0$ for $m > k$. The script checks the ladder relations, the norms and these moments for $N = 1, 2, 3$, all $k \le N$ and $m \le N + 1$, and $\omega_{k}(B) = \omega_{k}(B^{2}) = 0$, after checking that the blades are orthonormal for $N = 1, 2$.

\emph{(ii).} Write $f_{i} = b_{i}^{*}$ (it flips block $i$). Since the $f_{i}$ commute and $f_{i}^{2} = 0$, $(K^{*})^{k} = k!\sum_{|A| = k}\prod_{i \in A}f_{i}$, so $\psi_{k} = k!\sum_{|A|=k}\phi_{A}$ with $\phi_{A} = \prod_{i\in A}f_{i}P$. The $\phi_{A}$ are pairwise orthogonal (they are eigenvectors of the $n_{u_{i}}$ with different eigenvalues) and have equal norms: $f_{i}^{*}f_{i} = b_{i}b_{i}^{*} = n_{l_{i}}(1 - n_{u_{i}})$ by the relations, which acts as $1$ on a vector in which block $i$ is polarised, so $\langle\phi_{A}, \phi_{A}\rangle = \langle P, P\rangle$ by induction on $|A|$. Hence $\omega_{k}$ is the uniform average over the $\binom{N}{k}$ sets $A$ in its diagonal part: $\omega_{k}(P_{m})$ is the fraction of $k$-sets avoiding the first $m$ blocks, $\binom{N - m}{k}/\binom{N}{k} = \prod_{i=0}^{k-1}(1 - m/(N - i))$; when $km/(N - k + 1) < 1$ each factor is at least $1 - m/(N - k + 1) \ge 0$ and $(1 - x)^{k} \ge 1 - kx$ gives $\omega_{k}(P_{m}) \ge 1 - \varepsilon_{m}$, and otherwise the bound is trivial. Likewise $\omega_{k}(n_{u_{i}}) = \binom{N-1}{k-1}/\binom{N}{k} = k/N$, $\omega_{k}(n_{u_{i}}n_{u_{j}}) = \binom{N-2}{k-2}/\binom{N}{k} = k(k - 1)/(N(N - 1))$, and $b_{i}^{*}b_{j}\phi_{A} = \phi_{A \setminus\{j\} \cup \{i\}}$ when $j \in A$, $i \notin A$ (and $0$ otherwise, the even factors commuting and $b_{j}f_{j}$ acting as $1$ on the polarised block), so $\omega_{k}(b_{i}^{*}b_{j}) = \binom{N-2}{k-1}/\binom{N}{k} = k(N - k)/(N(N - 1))$. \emph{Minimality.} For one plane, $n e n = n(v + w)n = 0$, $n f n = n(v - w)n = 0$ and $n(ef)n = n(1 - 2n)n = -n$ (as $ef = 1 - 2n$), and likewise with $1 - n$; a blade of the first $m$ blocks is, up to sign, a product of one factor per plane, and each idempotent factor of $P_{m}$ commutes with the factors of the other planes (it is even), so $P_{m}XP_{m} = \lambda(X)P_{m}$ for every $X$ there, with $\lambda(X) = \langle P_{m}X\rangle_{0}/\langle P_{m}\rangle_{0} = \omega_{0}(X)$. \emph{The bound.} With $\psi = \psi_{k}/\|\psi_{k}\|$ and $\varepsilon = 1 - \omega_{k}(P_{m}) \le \varepsilon_{m}$, $X - P_{m}XP_{m} = (1 - P_{m})X + P_{m}X(1 - P_{m})$, and by the Cauchy-Schwarz inequality $|\langle\psi, (1 - P_{m})X\psi\rangle| \le \|(1 - P_{m})\psi\|\,\|X\psi\| \le \sqrt{\varepsilon}\,\|X\|$, and the same for the second term; and $|\omega_{k}(P_{m}XP_{m}) - \omega_{0}(X)| = |\omega_{0}(X)|\varepsilon \le \varepsilon\|X\|$. The script checks the marginals, the off-diagonal moments $\omega_{k}((K^{*})^{a}K^{c}) = 0$ for $a \ne c \le 2$, and the pair values for $N = 1, 2, 3$, and minimality on all sixteen blades of one block.

\emph{(iii).} At fixed $k$, $\omega_{k}((B^{*})^{a}B^{c}) = \delta_{ac}(k)_{a}(N - k + 1)^{(a)}/N^{a} \to \delta_{ac}(k)_{a}$, since $(N - k + 1)^{(a)}/N^{a} \to 1$. In the $k$-boson number state $|k\rangle$ of a canonical mode, $a^{m}|k\rangle = \sqrt{(k)_{m}}\,|k - m\rangle$, so $\langle k|(a^{*})^{m}a^{m}|k\rangle = (k)_{m}$ and off-diagonal moments vanish: the limits are these. A quasi-free state of one mode with $\langle a\rangle = \langle a^{2}\rangle = 0$ assigns to $(a^{*})^{m}a^{m}$ the sum over pairings of each $a^{*}$ with an $a$ (pairings of two $a^{*}$ or two $a$ give $\langle a^{2}\rangle = 0$ or its adjoint), $m!$ pairings each contributing $x^{m}$. At $m = 2$, $k(k - 1) = 2k^{2}$ only for $k = 0$ or $k = -1$; at $m = k + 1$, $(k)_{k+1} = 0 < (k + 1)!\,k^{k+1}$. For $k = 0$ all moments with $a + c > 0$ vanish, which is the vacuum, quasi-free with $x = 0$. The script checks these integer facts for $k = 1, \dots, 40$.

\emph{(iv).} By (ii), for each fixed $k$ the marginals of $\omega_{k}$ on any fixed set of blocks tend in norm to those of $\omega_{0}$ (the bound is uniform over the $m$ blocks used, and any finite set of blocks can be moved to the first $m$ by the permutation symmetry of $\psi_{k}$). By (iii) the limits of $\omega_{k}((B^{*})^{k}B^{k})$ are $k!$, pairwise different. So no rule that assigns a limit fluctuation state to a local limit state can hold for these sequences; the product structure at each $N$ (under which $\omega_{0}$ gives the vacuum) is used.
