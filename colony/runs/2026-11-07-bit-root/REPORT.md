## Corrections to the source document (recorded in the entities)
- "Only signs survive in R": true in any Euclidean field; completeness is not what makes directions +-1.
- Frobenius needs odd-degree roots, which any real closed field supplies; completeness proper is needed only for limits.
- c is not the unique non-trivial central involution for odd n with p - q = 1 mod 4 (the volume element is one).
- The qubit (Witt/Fock) reading needs 1/2, so it belongs to the rationals, not the integers.
- The spinor's 2 pi sign and continuous rotation need the completion; the bare sign -1 is step 2.
