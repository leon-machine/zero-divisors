## 1. synthesis.premise-the-bit: SOUND

- Exact: "1 + 1 = 0" is stated as the addition of F_2, with the product given separately, and "independent" is
  defined as the direct power (subsets of {1..n} under symmetric difference). The count C(n,k) follows.
- Minimal: the product of F_2 is used later (q and b are F_2-valued forms, and Arf's classification uses the field), so
  it is not surplus. Consistent (F_2^n exists). Labelled a mathematical primitive at every level, and the reading that
  physics is built on it is marked argued.
- Prior art (from memory, not web-checked): Spencer-Brown's law of crossing does match "making it again returns to
  nothing". Optional: add that the other law, calling, is idempotent (juxtaposition is Boolean OR, 1 + 1 = 1), so Laws of
  Form is a Boolean algebra and not F_2. Only crossing is the analogue.

## 2. synthesis.premise-minimal-non-commutativity: SOUND WITH FIXES

Re-derived:
- c^2 = 1 is forced for n >= 2: e_1e_2 = c e_2e_1 = c^2 e_1e_2. Centrality is not used. Correct.
- c^2 = 1 is independent at n = 1: Z_{2m} with c = e_1^2, m >= 2 (also the infinite cyclic group). Correct; the
  check confirms m = 2..7.
- Centrality is redundant. The quotient G/<c> presupposes that <c> is normal, and a normal subgroup of order 2 is
  central. So for n >= 2 the whole of (S1) follows from (S2) and (S3). At n = 1, c^2 = 1 with |G/<c>| = 2 gives |G| = 4,
  which is abelian. So "c is central" never adds anything once c^2 = 1 holds and <c> is normal. Without c^2 = 1 it is
  not implied at n = 1: the dihedral group D_m (m >= 3, c a rotation, e_1 a reflection) satisfies (S2) and (S3) with c
  not central; I verified this for m = 3..7.
- **Defect, n = 1.** The formal statement says "The directions e_1, ..., e_n generate a group G". At n = 1 that makes G
  cyclic, so c^2 = 1 and c != 1 give G = Z_4 and e_1^2 = c. Signature (1,0), where G is the Klein group, is excluded,
  which contradicts "every choice, the signature, is allowed". The result's own formulation, with no generation clause,
  does not have this defect.

Required fixes:
1. Formal, technical and one-liner: replace "the directions generate a group G" with "G is generated by the directions
   e_1, ..., e_n and the bit c". For n >= 2 nothing changes, since c is a commutator.
2. Status paragraph: add that "c central" is implied by the rest once c^2 = 1 holds (<c> is normal of order 2), so (S1)
   is kept only for n = 1, and only its order clause carries content there. Alternatively, drop "central" from (S1) and
   state it as a consequence.
3. The claim "every choice, the signature, is allowed" asserts consistency for each sign vector. It needs the existence
   argument that is missing from the result (Section 4, fix 1). Once that argument is added, the extraction note should
   say where it is proved.

Optional: the lay level's "the possibility of rotation" is a reading. Mark it as such, or drop it.

## 3. synthesis.premise-superposition-over-the-integers: SOUND WITH FIXES

- Exact: A = Z[G]/(c + 1), with a two-sided ideal and integer coefficients. It fixes the ring to Z cleanly: Z is the
  initial ring, and nothing finer is assumed.
- "The other possibility, c acting as +1": Z[G]/(c - 1) = Z[F_2^n], which is commutative, correct. Strictly, c - λ for
  an integer λ with λ^2 != 1 gives a quotient of positive characteristic, or 0. Optional: write "the only other integer
  of square 1".
- Required fix (lay): "With this step the full algebra of directions used throughout the series appears" contradicts
  the sentence before it (fractions and reals come later). Replace with "the whole-number form of the algebra of
  directions used throughout the series appears".
- Optional: "Configurations can be added" should be "signed configurations (elements of G)".

## 4. synthesis.signed-directions-and-the-integer-clifford-algebra: SOUND WITH FIXES

I checked every proof step.
- (i) Normal form, |G| = 2^{n+1}, and the presentation argument (|Γ| <= 2^{n+1}, onto G): correct for a given G.
- (ii) Rewriting gives f(S,T). f(S,S) = C(|S|,2) + |S ∩ N|, and f(S,T) + f(T,S) ≡ |S||T| + |S ∩ T|. c is a
  square and a commutator for n >= 2, including the case n = 2 with mixed signs. Correct.
- (iii) The centre is {1, c} for n even, and {1, c, e_full, c e_full} for n odd (S central iff b(S,{i}) = 0 for all i).
  For n even, G is extraspecial: centre = commutators = squares = {1, c}, and this subgroup is the Frattini subgroup. The
  volume element is a central involution exactly when n is odd and p - q ≡ 1 mod 4, because q(full) = C(n,2) + q.
  Independent recomputation, using a group built from the bilinear cocycle and not by rewriting: all 35 standard
  signatures with n <= 7 agree.
- (iv) Classification of the groups by q: correct in both directions. For n >= 2 every isomorphism fixes c, since c is
  the only nontrivial commutator. At n = 1 the clause about c is rightly excluded (V_4 has automorphisms that move c).
- (v) The ideal is (1 + c)Z[G] because c is central, and c(1 + c) = 1 + c. The unimodular basis change gives a free
  module of rank 2^n. Correct.
- (vi) v^2 = Q(v) because e_ie_j + e_je_i = (1 + c)e_je_i maps to 0. No 1/2 is used. Correct.
- (vii) Universal property over every commutative ring: anticommutation follows from Q(ε_i + ε_j) (Q is diagonal);
  ψ: G → B^× comes from the presentation, with ψ(c) = -1; it extends R-linearly and kills c + 1; uniqueness holds by
  generation. Characteristic 2 gives R[F_2^n]. Correct, including 2 = 0.
- (viii) All five directions are proved: (a)⇔(b) by (iv); (b)⇒(c); (c)⇒(d) with R = Z; (d)⇒(e) by the trace form. The
  invariance argument (the largest positive-definite subspace has dimension P, by the dimension count against U_-) needs
  only an ordered field, with no square roots. (e)⇒(a) is a self-contained proof of Arf's classification for these forms:
  a symplectic basis, H/P planes, P⊥P ≅ H⊥H (I checked u = u_1 + u_2 and w = w_1 + u_2: q(u) = q(w) = 0 and b(u,w) = 1),
  and in odd n the radical shift u → u + z. So the classification over Z is proved in every direction, through Z → Q.
  I recomputed that the Gauss sum is constant on, and separates, the classes {0,2}, {4,6}, {1}, {5}, {3,7} for all
  signatures with n <= 9. Example over Z: f_1 → e_1, f_2 → e_1e_2 gives Cl_Z(1,1) ≅ Cl_Z(2,0). This is consistent with
  note.one-relation.two-presentations-differ-over-the-integers (the diagonal (1,1) order, not Mat_2(Z)).
- What is derived relative to the Fact: Fact (a) is derived over every commutative ring. Fact (b) is derived for
  Clifford twisting functions over R, every ordered field and Z, not for general bilinear twisting functions. Fact (c)
  is cited, not derived. The note states this accurately.

Defects:
- **Existence is never proved.** The proof always starts from a given G. Nothing shows that a group of signed
  directions exists for every sign vector, that is, that the presentation does not collapse below 2^{n+1}. Clauses (vii)
  and (viii) ("their groups of signed directions", Cl_R(p,q) for every signature) and the consistency of Premise (S)
  need it. The check gives evidence only for n <= 5: associativity of the rewriting for n <= 3, and agreement with GA.py.
  The fix is three lines and already appears in synthesis.division-gives-the-rationals: f is F_2-bilinear, hence a
  2-cocycle, so (a,S)(b,T) = (a + b + f(S,T), S △ T) is a group with the required relations. I verified associativity of
  that product for every sign vector with n <= 4.
- **The cone contradicts the foundation.** The only uses edge, synthesis.blade-square-signs-f2-quadratic-form@2, has a
  past cone of 37 entities. That cone includes transport.classification-real-clifford-algebras,
  primer.classification-real-clifford-algebras, std-algebra.sylvester-inertia, std-algebra.periodicity and the imported
  Fact itself (through its standard-route derivation). The clauses actually used are clause (iii), the radical of b
  (two lines of counting), and the Gauss-sum values of clause (iv) (a computation in span{1, j}, which is Cl_Z(0,1)).
  Neither needs real coefficients. As filed, though, the store will show the integer algebra, and "Fact clause (a)
  derived here", resting on the real classification and on the Fact.
- Overclaims: the extraction says "New here:" before a list of classical results. The lay level says integer
  combinations give "with no further assumption, exactly the algebra of directions used throughout the series", but the
  series works over R.

Required fixes:
1. Add the existence step to the proof of (i), as in the "The ring" paragraph of the division proposal: f is bilinear
   over F_2, so the cocycle product on {0,1} × F_2^n is associative and realises the relations for every sign vector.
   State in (i) that a group of signed directions exists for every (p,q) and is unique up to isomorphism fixing c and
   the e_i.
2. Inline the radical computation and the Gauss-sum evaluation (over Z[j], with j = e_1 of Cl_Z(0,1)). Then turn the
   uses edge to synthesis.blade-square-signs-f2-quadratic-form into lineage (motivated_by) or a comparison. If the
   maintainer prefers to keep the edge, the extraction note must say that the cone runs through the real classification
   and the Fact, and that "derived" then holds only at the level of the proof text.
3. Extraction note: change "New here:" to "New to the store (all classical, restated):".
4. Lay: change "exactly the algebra of directions used throughout the series" to "the whole-number form of the algebra
   of directions used throughout the series, which becomes that algebra once the coefficients are extended".

## 5. synthesis.division-gives-the-rationals: SOUND WITH FIXES

- Setup: the bilinearity of f gives associativity. Correct, and this is the existence argument the previous proposal
  lacks.
- (i) Re-derived. The forward direction is immediate. For the converse, the inverse is unique in Cl_Q, so v/Q(v) has
  coefficients in R, and the gcd/Bezout argument gives 1/Q(v) ∈ R. Correct. A shorter route, valid for every
  commutative ring R and every v ∈ V_R: v invertible ⇒ v^2 = Q(v)·1 invertible ⇒ Q(v)·w_∅ = 1, so Q(v) is a unit of R.
- (ii) Correct. Note that the Clifford structure does no work here: m e_1 only inverts m^2, so (ii) is the elementary
  fact that Z[1/m^2 : m >= 1] = Q.
- (iii) Re-derived by signature. Null vectors exist iff p, q >= 1. Zero divisors:
  - (1,0) and (3,0), indeed every p >= 1: (1 + e_1)(1 - e_1) = 0.
  - (0,3), and every q >= 3: w = e_1e_2e_3 has w^2 = +1.
  - (0,0), (0,1), (0,2): x x̄ = Σ x_S^2, so these are division rings. I recomputed this on 200 random rational elements
    of Cl_Q(0,2).

  So (0,0), (0,1) and (0,2) are exactly the zero-divisor-free signatures over Q, the same as over R (Cl_Q ⊂ Cl_R also
  gives the "no zero divisor" half from transport.exceptional-division-algebras). I recomputed the count of
  Z-invertible vectors in Cl(1,2) on the box {-3..3}^3: 10 + 44 = 54, matching the check.

Defects:
- Formal (iii), second sentence: "It contains zero divisors if and only if (p,q) ∉ {...}". Grammatically "It" is V_Q.
  For V_Q the statement is false: in Cl_Q(3,0) every nonzero vector is invertible, and (1 + e_1) is not a vector.
- One-liner: "null vectors and zero divisors remain except in Cl_Q(0,0), Cl_Q(0,1), Cl_Q(0,2)" says that null vectors
  remain in, for example, Cl_Q(3,0) and Cl_Q(0,3), which is false.
- Proof (iii): "Q is a sum of squares or minus one on V_Q" is garbled.
- Foundation framing: the statement quantifies over subrings R ⊆ Q, so Q is assumed as the ambient field. The title and
  lay level ("the fractions are what division makes of the whole numbers") read as if Q were produced.
- Both uses edges (std-algebra.orthogonal-anticommute@1, std-algebra.inverse-of-vector@1) are propositions about the
  real Cl(V,Q), whose cones rest on std-algebra.blade-basis and std-algebra.vector-squares. The proof does not need
  them: it defines the product and proves the inverse directly. As in Section 4, this puts real results in the cone of
  the integer and rational layer.

Required fixes:
1. Formal (iii): write "$\Cl_{\Q}(p,q)$ contains zero divisors if and only if ...".
2. One-liner: "...; null vectors remain exactly in the indefinite signatures (p, q >= 1), and zero divisors in all but
   $\Cl_{\Q}(0,0)$, $\Cl_{\Q}(0,1)$, $\Cl_{\Q}(0,2)$."
3. Proof (iii): write "Q is plus or minus a sum of squares on V_Q".
4. Either say at the technical and lay levels that Q is taken as the field of fractions and the theorem shows that
   inverting vectors already generates all of it, or (preferred) restate (i) and (ii) for every commutative ring R using
   the one-line converse above. Then Q is the initial ring in which every non-null integer vector is invertible, and
   Cl_Q is the localisation of Cl_Z at the nonzero integers. That does derive Q, and it removes the gcd detour.
5. Turn the two uses edges into comparisons ("the same rule as", "the same formula as") or lineage, as in Section 4,
   fix 2.

The check runs and fails on every perturbation I tried:
