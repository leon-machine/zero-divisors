# Pre-registration 2: is there a selection mechanism on the tower?

Written before computing, 12 November 2026. Leon: look for other ideas building on the rung-state result, from the
graph or not; see if there is a mechanism; if not, say so. A mechanism must do two things: end interference between
outcomes, and select one. The rung-state result showed iteration of the transport supplies two-state systems but no
values. Candidates, each with what would count as success and its kill condition.

C1. Integer states (the foundation before 1/2). If values must be integers, are states forced to be definite?
    Success: under (P), integer-valued states are exactly the strings of on/off values, for a natural integer form.
    Then definiteness is automatic there. Kill for "this is a mechanism": if definiteness comes only by removing
    superposition altogether (no state with a weight strictly between 0 and 1 survives), it explains no experiment
    with interference; and it selects nothing. Two integer forms to compare: the switch form (generated by v, w)
    and the ladder form (generated by e, f). Prediction: switch form gives strings only; ladder form gives more
    (weights 0, 1/2, 1).
C2. Parity (univalence). The descent is a parity average, an exact one-way map. Could the parity sectors be the
    exactly superselected record sectors, turning the recorded-sectors premise into a theorem?
    Success: an allowed (even) record coupling writes outcomes into different parity sectors.
    Kill: the even subalgebra has exactly two sectors, an even coupling conserves parity so both branches lie in
    one sector, and an explicit even observable sees the interference between the branches; a coupling that does
    change parity is not even and sends an even state to a state that is not even. Prediction: killed.
C3. A deterministic law on an actual string (a hidden-variable selector with no fresh bits). Suppose one string
    of values is actual and a law moves it. Success: a deterministic law reproduces the weights of (P) under an
    even rotor. Kill: an even rotor takes a string state to a state with weights strictly between 0 and 1 on two
    strings (say 9/25 and 16/25); a deterministic law takes one string to one string. Prediction: killed, so any
    selector on a fixed finite set of rungs is stochastic and needs fresh bits.
C4. Fresh bits from unread rungs (Leon's idea, restated with the rung-state result). The one symmetric extension
    gives k new rungs the uniform weight 2^-k on each string. Read as ignorance of an actual string, that is a
    supply of unbiased bits. Success for "the graph already contains this": some stored premise makes the string
    actual. Kill: none does (the rung-state result (iii): strings are labels); it would be a new premise, and a
    law reading the bits is another. Record what the two premises would be and which stored premises they meet.
Outside the graph, to place the candidates: stochastic collapse (GRW, CSL), gravity-induced collapse
(Diosi, Penrose), pilot-wave and Bell's beables for fermion number. From memory unless checked.

Overall prediction: no mechanism in the stored content; C1 to C3 killed; C4 is available only as two new premises.
If any of C1 to C3 succeeds, the no-collapse result needs restating.
