## 3. synthesis.trace-anomaly-leaves-no-exact-radiation-field-at-a-tame-wall

**Verdict: SOUND WITH FIXES.**

Power-law statement (iv). Rederived by hand: with H = p/t, R = 6p(2p-1)/t^2, the b-bracket of rho is
p^2(2p-1)[-12 - 3(2p-1) + 6p] t^-4 = -9 p^2 (2p-1) t^-4, so the t^-4 order is 6 alpha p^4 - 9 b p^2 (2p-1), i.e.
q(p) = 2 alpha p^2 - 6 b p + 3 b = 0. q convex, q(0) = 3b, q(1/2) = alpha/2 > 0, q(1) = 2 alpha - 3b; b < 0 gives one
root in (0, 1/2) (product of roots 3b/(2 alpha) < 0), b > 2 alpha/3 one root in (1/2, 1) and one above 1, 0 < b <
2 alpha/3 a negative discriminant 12b(3b - 2 alpha), b = 0 the root 0, b = 2 alpha/3 the double root 1. Correct,
including "one for each such b" (p(b) = 2 alpha p^2/(3(2p-1)) is monotone on each branch). Numerical scan over b
(exploration) agrees. Also rechecked rho_A = 3 alpha/8, P_A = 5 alpha/8, trace -3 alpha/2 = alpha E on t^(1/2).
