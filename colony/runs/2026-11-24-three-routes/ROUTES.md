# The eighteen routes (Leon, 24 November: file as attack items in the maintainer pass)

Each line: the route, then what would end it. Literature named here is from memory and is prior art to be
read before any import. Routes run in this run are marked RUN; their attack items are written from the
results, not from this text.

## op.gravitational-field-at-null-momentum
1a (RUN). A canonical pair on polynomials for the two transverse trace-free directions, as for the photon;
   repeat the lattice tests with the constraint structure of spin two and a dressed detection. Ends if no
   dressing commutes at every spacelike event.
1b. The pair as a bilinear current of the light-ray fermions on the generators, the canonical commutator
   arising as a Schwinger term in the continuum. Ends if that term vanishes in the trace-free channel.
1c. Test whether the recording premises turn the source into a number before a first-order signal builds.
   Ends if they give no rate, or if it removes the registered entangling phase.

## op.descent-state-and-spectrum
2a. A negative settlement by two models: two deposits satisfying every stored premise, (HD) included,
   with different band data.
2b. The spectrum as a response, the inverse of the wall modes' stress two-point function (holographic
   cosmology, McFadden and Skenderis). Ends if the count it needs matches no stored count; counts only
   with the amplitude from the same structure.
2c. A junction rule for the slice datum from the forcing-half wall data: a scale-invariant spectrum is a
   slice curvature spectrum linear in k. Ends if the rule gives a flat slice.

## op.einstein-from-the-field-theory (with op.derive-loc-and-r-loc)
3a. If the two null directions carry states, Lorentz covariance of a helicity-two mode's coupling forces
   the whole conserved stress as source with one coupling (Weinberg 1964): the whole-stress clause and
   the one-coupling clause of (Loc) together. Ends if op.gravitational-field-at-null-momentum is met
   without states.
3b. Deser's self-coupling iteration (1970) in Gauge Theory Gravity, from the stored first-order bilinear,
   with no imported action. Ends if it cannot close without a premise equivalent to (FS).
3c. The whole-stress clause as a theorem on the Clausius route: the heat is modular energy, which the
   imported null-plane first law equates with the flux T(k,k). Ends if defining T already needs variation
   off the Weyl-flat class.

## op.deposit-state-is-hadamard
4a. Necessity (Fewster and Verch 2013): finite fluctuations of Wick polynomials force the Hadamard form,
   so (HD) follows from requiring the source to exist. Ends if the hypotheses do not reach Dirac fields
   on a Robertson-Walker collar.
4b (RUN). The mirror as the far side of the radical-normal wall and CPT invariance of the state across it
   (Boyle, Finn and Turok 2018). Ends if the profile has a power-law tail or no state is selected.
4c. The trace anomaly's Euler term (t^-4) against the density (t^-2) near the wall: it bounds the
   radiation-type hypothesis or shows where the chain breaks.

## op.positivity-of-values
5a (RUN). Records: every self-adjoint rational projector can label a record ((RP), a named hypothesis).
   Outcome: (RP) with non-negative additive weights is (P) on projectors, so it relocates (P); the sum of four
   recorded correlators is bounded with no assumption on the value of the CHSH element. The extension of
   additivity past two modes is stored on main from another run (the size-four theorem); what this run adds
   to it is the parity-even form from three modes on. Open: the flag-sector form of (RP), an exact test at
   three modes. Needs Leon's reading.
5b. Polarisation: the split from the positive-energy half of the null translations, states as the vacuum
   conjugated by elements. Ends if the Krein sector's indefinite form reaches physical values.
5c. Macroscopic locality (Navascues and Wunderlich 2010): if the recording premises make coarse counts
   classical, the bound 2 sqrt 2 follows without (P); if the functional of value 4 survives them, that is
   the independence model.

## op.the-number-n (with op.rung-unit, op.non-gaussian-completion)
6a. Freedom by two models over the registered premises for N and v/H, replacing the pattern search.
6b. One non-Gaussian frozen vacuum for two numbers: the rule that selects it for the 207 also gives, if
   that state is deposited, the non-Gaussian modulator op.descent-state-and-spectrum leaves open. Ends if
   the state has no long-range order.
6c. The global pair: under the promotion N is the state of one pair (Lambda and its conjugate time); ask
   whether the selection of route 4b fixes it. Pinning the time leaves N free for a structural reason;
   pinning Lambda derives it.
