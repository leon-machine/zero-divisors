\emph{Setting.} The Kerr gauge field, its derived metric $g = \eta + 2H\,k\otimes k$ in oblate coordinates $(t, r, u, \phi)$ and the source's signature $(-,+,+,+)$, and the curvature scale of modulus $M|z|^{-3}$, $|z|^{2} = \Sigma = r^{2} + a^{2}u^{2}$, are those of Fact \claimref{interior.imported-kerr-schild-form-kerr-gauge} and Proposition \claimref{interior.complex-scale-inverse-cube-killing-spinor}. Throughout $\rho \le M/3$ and $0 < a \le \tfrac45\rho$.

\emph{(1).} $|z| = \rho$ with $r > 0$ is $r = R(u) = \sqrt{\rho^{2} - a^{2}u^{2}}$. Since $a^{2}u^{2} \le a^{2} \le \tfrac{16}{25}\rho^{2}$, $R \ge \tfrac35\rho$, and $R \le \rho \le M/3 < M \le r_{+}$. The horizon loci are the roots of $r^{2} - 2Mr + a^{2}$ (Fact \claimref{synthesis.imported-kerr-surface-gravity-entropy}), so $r_{+}r_{-} = a^{2}$ and $r_{-} = a^{2}/r_{+} \le a^{2}/M \le \tfrac{16}{25}\rho^{2}/M \le \tfrac{16}{75}\rho < \tfrac35\rho$. The surface is closed because $R > 0$ on all of $[-1, 1]$. For $\rho = \rho_{c}$, $\rho_{c} \le M/3$ reads $27\cdot 2M \le M^{3}$, that is $M^{2} \ge 54$, which holds for $M \ge 8$.

\emph{(2).} The tangent vectors of the surface are $\partial_{t}$, $\partial_{u} + R'\partial_{r}$ with $R' = -a^{2}u/R$, and $\partial_{\phi}$. In Boyer-Lindquist coordinates $(t_{B}, r, u, \phi_{B})$, which differ from the Kerr-Schild ones by $t = t_{B} + f_{1}(r)$, $\phi = \phi_{B} + f_{2}(r)$, the derived metric has no cross terms between $(t_{B}, \phi_{B})$ and $(r, u)$, its $(t_{B}, \phi_{B})$ block has determinant $-\Delta\,(1 - u^{2})$, $\Delta = r^{2} - 2Mr + a^{2}$, and $g_{rr} = \Sigma/\Delta$, $g_{uu} = \Sigma/(1 - u^{2})$. On the surface the change from $(t_{B}, u, \phi_{B})$ to $(t, u, \phi)$ is a shear, of unit Jacobian, as is the change $\partial_{t} \to \partial_{t} + \Omega\partial_{\phi}$; so
\[
\det h = -\Delta(1 - u^{2})\Bigl[\frac{\Sigma}{1 - u^{2}} + \frac{\Sigma}{\Delta}R'^{2}\Bigr] = -\Sigma\bigl[\Delta(R) + (1 - u^{2})R'^{2}\bigr] = \rho^{2}\Bigl[2MR - R^{2} - a^{2} - \frac{(1 - u^{2})a^{4}u^{2}}{R^{2}}\Bigr],
\]
using $\Sigma = \rho^{2}$ on the surface. The check computes the Gram determinant directly from the Kerr-Schild components at 25 rational points and finds this value, for $\partial_{t}$ and for $\partial_{t} + \Omega\partial_{\phi}$; with $R = \rho\cos\psi$, $au = \rho\sin\psi$ it is the determinant of Theorem \claimref{synthesis.kerr-ring-count-misses-area-law}(2) multiplied by $(du/d\psi)^{2}$, an identity of rational functions which does not use $\rho \le a$. Upper bound: $R(\rho - R) = R\,a^{2}u^{2}/(\rho + R) \le a^{2}u^{2} \le a^{2}$, so $R(2M - R) - a^{2} \le R(2M - \rho)$, and the last term of $B$ is not positive; hence $B \le R(2M - \rho)$. Lower bound: $R(2M - R) \ge R(2M - \rho)$, and, with $u^{2}(1 - u^{2}) \le \tfrac14$ and $R^{2} \ge \tfrac{9}{25}\rho^{2} \ge \tfrac{9}{16}a^{2}$, $a^{2} + (1 - u^{2})a^{4}u^{2}/R^{2} \le a^{2}(1 + \tfrac49) = \tfrac{13}{9}a^{2}$; dividing by $R(2M - \rho) \ge \tfrac35\rho(2M - \rho)$ gives $B \ge R(2M - \rho)(1 - \tfrac{65}{27}a^{2}/(\rho(2M - \rho))) \ge (1 - \delta)R(2M - \rho)$. Finally $\delta \le \tfrac52\cdot\tfrac{16}{25}\rho/(2M - \rho) \le \tfrac85\cdot\tfrac15 < 1$ because $2M - \rho \ge 5\rho$, so $B > 0$ and $\det h > 0$: the induced metric is positive definite, since a nondegenerate three-plane of a metric of signature $(-,+,+,+)$ has signature $(+,+,+)$ or $(-,+,+)$ and only the first has positive determinant.

\emph{(3).} $V' = 2\pi\int_{-1}^{1}\rho\sqrt{B}\,du$, the $\phi$ integral giving $2\pi$. By (2), with $\sqrt{1 - \delta} \ge 1 - \delta$,
\[
(1 - \delta)\,2\pi\rho\sqrt{2M - \rho}\int_{-1}^{1}R^{1/2}du \;\le\; V' \;\le\; 2\pi\rho\sqrt{2M - \rho}\int_{-1}^{1}R^{1/2}du ,
\]
and $\int_{-1}^{1}R^{1/2}du = \rho^{1/2}\int_{-1}^{1}(1 - \varepsilon u^{2})^{1/4}du = 2\rho^{1/2}G(\varepsilon)$, so $V'$ lies between $(1 - \delta)G(\varepsilon)$ and $G(\varepsilon)$ times $4\pi\rho^{3/2}\sqrt{2M - \rho}$, which is $V'(M, 0, \rho)$ ($B = \rho(2M - \rho)$ at $a = 0$). For $0 \le x \le 1$: $(1 - x/4)^{4} - (1 - x) = x^{2}(\tfrac38 - \tfrac{x}{16} + \tfrac{x^{2}}{256}) \ge 0$, so $(1 - x)^{1/4} \le 1 - x/4$; and $(1 - x)^{1/4} \ge 1 - x$. With $x = \varepsilon u^{2}$ and $\int_{-1}^{1}u^{2}du = \tfrac23$: $1 - \varepsilon/3 \le G(\varepsilon) \le 1 - \varepsilon/12$. On $\rho^{3} = 2M$, $4\pi\rho^{3/2}\sqrt{2M - \rho} = 4\pi\sqrt{2M}\sqrt{2M}\sqrt{1 - \rho/2M} = 8\pi M\sqrt{1 - \rho/2M}$, the slice volume of Proposition \claimref{singularity.stretched-singularity-count}.

\emph{(4).} The count rule is that of Proposition \claimref{singularity.stretched-singularity-count}, $\nu$ modes per Planck cell of the surface per unit Killing time, and the epoch is the modular period of Theorem \claimref{scrambling.epoch-modular-period-two-unknowns-become}, read on Kerr with the outer surface gravity. By Fact \claimref{synthesis.imported-kerr-surface-gravity-entropy}, $\kappa_{+} = \sqrt{M^{2} - a^{2}}/(2Mr_{+})$ and $A_{+}/4 = 2\pi Mr_{+}$, so $N/(A_{+}/4) = \nu V'\cdot(4\pi Mr_{+}/\sqrt{M^{2} - a^{2}})/(2\pi Mr_{+}) = 2\nu V'/\sqrt{M^{2} - a^{2}}$, and $Q(M, a)/Q(M, 0) = (V'(M, a, \rho)/V'(M, 0, \rho))\cdot M/\sqrt{M^{2} - a^{2}} \le (1 - \varepsilon/12)/\sqrt{1 - a^{2}/M^{2}}$ by (3); $\nu$ cancels. Strictness: as $\varepsilon \le \tfrac{16}{25}$, $\varepsilon^{2}/144 \le \varepsilon/225$, so $(1 - \varepsilon/12)^{2} \le 1 - \varepsilon(\tfrac16 - \tfrac1{225})$, while $a^{2}/M^{2} = \varepsilon\rho^{2}/M^{2} \le \varepsilon/9 < \varepsilon(\tfrac16 - \tfrac1{225})$; hence $(1 - \varepsilon/12)^{2} < 1 - a^{2}/M^{2}$. If a density $\nu$ and a level set $\rho(M)$, both independent of $a$, gave $Q(M, 0) = 1$ and $Q(M, a) = 1$ for some $0 < a \le \tfrac45\rho(M)$, the ratio would be $1$, against the strict inequality. At $a = \tfrac45\rho_{c}$, $1 - \varepsilon/12 = 1 - \tfrac{16}{300} = \tfrac{71}{75}$.
