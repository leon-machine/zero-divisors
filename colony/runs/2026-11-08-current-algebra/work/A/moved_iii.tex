\emph{(iii)} Write $K = \sum_{x,k}k\,n_{x,k}$, $\hat N = \sum n_{x,k}$, so $H = K + \tfrac12\hat N$, and $T_{\gl} = \sum_{q \ge 1}\sum_{x,y}(j^{xy}_{q})^{*}j^{xy}_{q}$, $T_{N} = \sum_{q \ge 1}N_{q}^{*}N_{q}$, $G_{0} = \sum_{x,y}j^{xy}_{0}j^{yx}_{0}$, with $(j^{xy}_{q})^{*} = j^{yx}_{-q}$. Moving $c_{x,k}$ past $c^{*}_{x,k'}$,
\[
(j^{xy}_{q})^{*}j^{xy}_{q} = \sum_{k}n_{y,k+q} - \sum_{k,k'}c^{*}_{y,k+q}c^{*}_{x,k'}c_{x,k}c_{y,k'+q}, \qquad N_{q}^{*}N_{q} = \sum_{x,k}n_{x,k+q} - \sum c^{*}_{x,k+q}c^{*}_{y,k'}c_{x,k}c_{y,k'+q} .
\]
Summed over $q \ge 1$ (and $x$, $y$), the number terms give $nK$ and $K$ (each $n_{y,l}$ is counted once for each $q \le l$, and $n$ times in $T_{\gl}$). Label a quartic term $c^{*}_{\alpha}c^{*}_{\beta}c_{\gamma}c_{\delta}$ by four modes; both quartic sums run over the quadruples in the window with $k_{\alpha} + k_{\beta} = k_{\gamma} + k_{\delta}$ and $k_{\alpha} > k_{\gamma}$, each once, the first with $x_{\alpha} = x_{\delta}$, $x_{\beta} = x_{\gamma}$, the second with $x_{\alpha} = x_{\gamma}$, $x_{\beta} = x_{\delta}$. So $T_{\gl} + T_{N} = (n + 1)K - X$, $X = \sum_{k_{\alpha} > k_{\gamma}}w\,c^{*}_{\alpha}c^{*}_{\beta}c_{\gamma}c_{\delta}$ with $w = [x_{\alpha} = x_{\delta}][x_{\beta} = x_{\gamma}] + [x_{\alpha} = x_{\gamma}][x_{\beta} = x_{\delta}]$. Let $S$ be the same sum over all quadruples with $k_{\alpha} + k_{\beta} = k_{\gamma} + k_{\delta}$. Exchanging $\gamma$ and $\delta$ preserves the index set and $w$ (its two terms are exchanged) and reverses the sign of $c_{\gamma}c_{\delta}$, so $S = 0$. The part with $k_{\alpha} < k_{\gamma}$ (so $k_{\beta} > k_{\delta}$) is mapped onto the part with $k_{\alpha} > k_{\gamma}$ by $(\alpha, \beta, \gamma, \delta) \mapsto (\beta, \alpha, \delta, \gamma)$, which preserves $w$ and the product (two transpositions): it equals $X$. The part with $k_{\alpha} = k_{\gamma}$, $k_{\beta} = k_{\delta}$ is $D = D_{1} + D_{2}$ with the two terms of $w$; and $G_{0} = n\hat N - D_{1}$, $N_{0}^{2} = \hat N - D_{2}$, by the same reordering. So $0 = 2X + D$ and
\[
T_{\gl} + T_{N} = (n + 1)K + \tfrac12\bigl((n + 1)\hat N - G_{0} - N_{0}^{2}\bigr),
\]
which is the display. For $n = 1$ both $T$'s are the stored $T$ and $G_{0} = N_{0}^{2} = \hat N^{2}$, giving $K = T + \tfrac12\hat N(\hat N - 1)$. For any basis $M_{A}$ of $\gl(n)$ with trace-dual basis $M^{A}$, $\sum_{x,y}E_{yx}\otimes E_{xy} = \sum_{A}M^{A}\otimes M_{A}$, and splitting off $\tfrac1n 1\otimes 1$ gives $T_{\gl} = T_{\su(n)} + \tfrac1n T_{N}$, $G_{0} = Z_{\su(n)} + \tfrac1n N_{0}^{2}$; with $\sum_{x,y}[E_{yx}, [E_{xy}, X]] = 2nX - 2\operatorname{tr}(X)1$, $\lambda_{\su(n)} = 2n$ and the display reads $H = H_{\su(n)} + H_{N}$. The check verifies the identity on every basis state for $(n, L) = (1, 4), (2, 3), (3, 3)$, on three states of sixteen channels, and that the coefficient $n$ in place of $n + 1$ fails.
